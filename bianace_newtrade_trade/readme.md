# 币安新币精准做空系统

## 项目简介

本项目是一个基于 Python 的币安新币做空策略系统，通过多维度交叉验证，识别高确定性的做空机会，实现"一击必中"的精准做空策略。

## 核心策略

放弃高频交易，追求高确定性的一次机会。通过以下四个维度进行交叉验证：

| 维度 | 权重 | 核心作用 |
| :--- | :--- | :--- |
| **合约数据** | **35%** | 排除陷阱 & 寻找对手盘 |
| **项目基本面** | **30%** | 评估下跌空间 |
| **K线/交易量** | **25%** | 确认进场时机 |
| **市场情绪** | **10%** | 寻找情绪拐点 |
