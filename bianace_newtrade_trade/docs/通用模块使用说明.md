# 新币做空系统 - 通用模块使用说明

## 📦 已提取的通用模块

### 1. 通知服务模块

**原位置**: `short_selling_system/core/notifier.py`  
**通用服务**: `common_service/notification_service`  
**改造后**: `short_selling_system/core/notifier_v2.py` (已替换为 v2 版本)

**调用方式**:
```python
from short_selling_system.core.notifier_v2 import FeishuNotifier

notifier = FeishuNotifier()

# 发送交易信号通知
notifier.send_signal_notification(signal)

# 发送风险警告
notifier.send_risk_warning("BTCUSDT", "价格波动过大", 65000)

# 发送每日汇总
notifier.send_daily_report(signals, trades)
```

**API 端点**: `http://43.156.242.184:8766/api/v1/send`  
**项目标识**: `new_coin`

**优势**:
- ✅ 统一管理飞书 webhook
- ✅ 支持异步发送（消息队列）
- ✅ 频率限制防止轰炸
- ✅ 统一日志记录
- ✅ 向后兼容，接口不变
