# 新币种监控优化计划

## 📋 项目概述

**目标**：优化新币种监控和评分系统，解决 CFGUSDT 等币种被遗漏的问题，增强日志记录和通知机制。

**当前问题**：
- CFGUSDT 已上线但未被评分
- 已处理币种被永久跳过，即使上线时间<24 小时
- 缺少评分日志记录
- 缺少评分汇总通知

---

### 需求 2：优化新币检测逻辑（方案 B）
**目标**：修改 `listing_detector.py`，增加二次评分机制，避免遗漏

**实施方案**：

#### 2.1 修改状态文件结构
**当前结构**：
```json
{
  "processed_symbols": ["CFGUSDT", "XXXUSDT", ...]
}
```

**新结构**：
```json
{
  "processed_symbols": {
    "CFGUSDT": {
      "first_detected": "2026-03-16T21:00:00",
      "listing_time": "2026-03-16T21:00:00",
      "scoring_count": 0,
      "last_scored": null,
      "last_score": null,
      "signal_generated": false
    }
  }
}
```

#### 2.2 实现二次评分机制
**核心逻辑**：
```python
# 对于已处理但上线时间<24 小时的币种
if symbol in processed_symbols:
    coin_data = processed_symbols[symbol]
    hours_since_listing = get_hours_since_listing(coin_data['listing_time'])
    
    # 如果上线<24 小时且评分次数<3 次，进行二次评分
    if hours_since_listing < 24 and coin_data['scoring_count'] < 3:
        should_rescore = True
```

**新增配置**：
- `max_rescore_attempts`: 最大二次评分次数（默认 3 次）
- `rescore_interval_minutes`: 二次评分间隔（默认 30 分钟）
- `rescore_enabled`: 是否启用二次评分（默认 True）

#### 2.3 修改检测器方法
**新增方法**：
- `should_rescore(symbol, hours)`: 判断是否需要进行二次评分
- `update_scoring_record(symbol, score, signal_generated)`: 更新评分记录
- `get_rescore_candidates()`: 获取待二次评分的币种列表

**修改方法**：
- `detect_new_listings()`: 增加二次评分逻辑

**交付物**：
- 修改后的 `core/listing_detector.py`
- 新的状态文件结构
- 单元测试

## 🔧 技术细节

### 配置文件更新
在 `config/settings.py` 中新增：

```python
# 二次评分配置
rescore_enabled: bool = True
max_rescore_attempts: int = 3
rescore_interval_minutes: int = 30

# 评分日志配置
scoring_report_retention_days: int = 7
scoring_log_dir: str = "logs/scoring_reports"

# 汇总通知配置
send_summary_notification: bool = True
summary_notification_threshold: int = 6.0
```

### 数据库迁移
需要迁移现有的 `processed_symbols.json` 文件：

```python
# 迁移脚本
def migrate_processed_symbols():
    old_data = load_old_format()  # ["CFGUSDT", ...]
    new_data = {
        symbol: {
            "first_detected": datetime.now().isoformat(),
            "listing_time": get_listing_time(symbol),
            "scoring_count": 0,
            "last_scored": None,
            "last_score": None,
            "signal_generated": False
        }
        for symbol in old_data
    }
    save_new_format(new_data)
```

### 兼容性保证
- 向后兼容旧的 JSON 格式
- 自动检测并迁移
- 迁移失败时回退到旧逻辑
