# 报告存档功能实施计划

## 需求分析

在现有评分系统的基础上，增加报告存档功能：
1. 每次分析新币时，自动生成详细的评分报告
2. 报告保存到 `reports/` 文件夹
3. 报告格式：JSON + Markdown（便于阅读和分析）
4. 在服务器上更新部署
5. 更新本地文档说明

---

## 实施步骤

### 阶段一：创建报告生成模块

#### 1.1 创建报告管理器模块
- 文件：`short_selling_system/core/report_manager.py`
- 功能：
  - 生成详细评分报告（包含所有维度的评分和原因）
  - 保存为 JSON 格式（便于程序读取）
  - 保存为 Markdown 格式（便于人工阅读）
  - 自动创建 `reports/` 目录
  - 按币种和日期组织报告文件

### 阶段二：集成到现有系统

#### 2.1 修改评分引擎
- 文件：`short_selling_system/core/scoring_engine.py`
- 修改：
  - 在 `calculate_score()` 方法中调用报告生成
  - 每次评分后自动保存报告

#### 2.2 修改主程序
- 文件：`short_selling_system/main.py`
- 修改：
  - 导入报告管理器
  - 在评分完成后调用报告保存

#### 2.3 配置管理
- 文件：`short_selling_system/config/settings.py`
- 新增配置：
  - `REPORTS_DIR`: 报告保存目录（默认：`reports/`）
  - `SAVE_REPORTS`: 是否保存报告（默认：`True`）
  - `REPORT_FORMAT`: 报告格式（默认：`["json", "markdown"]`）
