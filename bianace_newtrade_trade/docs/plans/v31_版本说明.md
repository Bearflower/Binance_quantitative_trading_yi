## 🎯 核心改进

### 1. 调整评分触发条件

**v3.0**:
- 每 30 分钟评分一次
- 评分时间不固定

**v3.1**:
- ✅ **取消每 30 分钟评分**
- ✅ **改为每小时第 1 分钟评分**（例如 10:01, 11:01, 12:01...）
- ✅ **评分仅基于刚刚收盘的那根 1 小时 K 线**

**优势**:
- 评分时间更规律，便于监控
- 基于完整 K 线，避免盘中波动干扰
- 减少无效评分，提高系统效率

---

### 2. 三次冲顶判断逻辑优化

**v3.0**:
- 需要等待多根 K 线
- 判断逻辑不够清晰

**v3.1**:
- ✅ **跨 K 线判断**：记录最近 3-5 根已收盘的 1 小时 K 线的最高点
- ✅ **高点逐次降低**：若出现高点逐次降低（或同一水平受阻三次），则满足条件
- ✅ **不需要等待当前 K 线收盘**：已收盘的 K 线数据是完整的

**判断规则**:
```python
# 1. 同一水平受阻（容忍 2% 误差）
if 3 个高点在同一价格水平（±2%）:
    形成三次冲顶

# 2. 高点逐次降低（每次至少降低 0.5%）
if high1 > high2 > high3:
    if (high1 - high2) / high1 > 0.5% and (high2 - high3) / high2 > 0.5%:
        形成三次冲顶
```

**优势**:
- 更灵活，适应不同形态
- 判断更准确，基于完整 K 线
- 提前识别顶部形态

---

### 3. 成交量比较基准调整

**v3.0**:
- 成交量比较基准不明确
- 缺乏量化标准

**v3.1**:
- ✅ **用前 5 根已收盘的 1 小时 K 线的平均成交量作为基准**
- ✅ **当前 K 线成交量 > 1.5 倍基准** → 放量
- ✅ **价格未创新高** → 滞涨
- ✅ **放量 + 滞涨** → 放量滞涨信号

**判断公式**:
```python
avg_volume = (vol[-6] + vol[-5] + vol[-4] + vol[-3] + vol[-2]) / 5
current_volume = vol[-1]

if current_volume >= 1.5 * avg_volume:
    放量
    
if current_high <= max(high[-6:-1]):
    价格未创新高

if 放量 and 价格未创新高:
    放量滞涨 ✓
```

**优势**:
- 量化标准，客观判断
- 识别主力出货行为
- 提高做空信号准确性

---

### 4. 信号冷却机制

**v3.0**:
- 无冷却机制
- 可能重复开仓

**v3.1**:
- ✅ **如果某个币种在连续 2 个整点评分中都满足条件，只开仓一次**
- ✅ **开仓后立即标记该币种为"已交易"**
- ✅ **2 小时冷却期内不再评分**

**冷却规则**:
```python
cooldown_hours = 2  # 冷却时间

def is_in_cooldown(symbol):
    if symbol in cooldown_records:
        hours_since_trade = (now - last_trade_time).hours
        if hours_since_trade < 2:
            return True  # 冷却期内
    return False
```

**优势**:
- 避免重复开仓
- 降低交易风险
- 提高资金利用率

---

### 5. 时间窗口限制

**v3.0**:
- 新币上线 72 小时内
- 时间窗口较长

**v3.1**:
- ✅ **新币上线 48 小时内才参与评分**
- ✅ **超过 48 小时自动移除**

**规则**:
```python
listing_hours_max = 48

if hours_since_listing > 48:
    不参与评分
    从监控列表移除
```

**优势**:
- 聚焦新币最佳交易时机
- 避免老币流动性不足风险
- 提高资金周转效率

### 技术面评分 v3.1

**评分公式**:
```
技术面评分 = 趋势评分 (4 分) + RSI 评分 (3 分) + 波动率评分 (3 分) 
           + 形态加分 (0-1 分) + 量价加分 (0-1 分)

满分：10 分
```

**评分细则**:

| 指标 | 条件 | 评分 |
|------|------|------|
| **趋势** | downtrend | 4.0 |
| | sideways | 2.0 |
| | uptrend | 0.0 |
| **RSI** | RSI < 30 | 3.0 |
| | 30 ≤ RSI < 50 | 2.0 |
| | 50 ≤ RSI < 70 | 1.0 |
| | RSI ≥ 70 | 0.0 |
| **波动率** | ATR/Price > 5% | 3.0 |
| | 3% < ATR/Price ≤ 5% | 2.0 |
| | 1% < ATR/Price ≤ 3% | 1.0 |
| | ATR/Price ≤ 1% | 0.5 |
| **形态** | 三次冲顶 | +1.0 |
| **量价** | 放量滞涨 | +1.0 |
