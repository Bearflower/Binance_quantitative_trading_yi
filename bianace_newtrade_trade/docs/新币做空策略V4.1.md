# 新币做空策略 V4.1：OI/总交易量替代方案

## 1. 版本更新说明

V4.1 是 V4.0 的优化版本，主要变更如下：

### 1.1 核心变更

| 变更项 | V4.0 | V4.1 |
|--------|------|------|
| 合约数据指标 | OI/市值比 | **OI/上线以来总交易量** |
| 市值数据来源 | CoinGecko API | **不再依赖市值数据** |
| 合约评分构成 | 单一指标 | **双指标：OI/交易量比率(30%) + OI排名(15%)** |
| 技术面最低分 | 6分 | **4分** |

### 1.2 变更原因

1. **市值数据获取困难**：CoinGecko API 只能获取 1.5% 新币的市值数据
2. **OI/交易量比率逻辑更扎实**：
   - OI 代表市场中沉淀的"存量"杠杆
   - 总交易量则是"增量"热钱的累积
   - 高比率意味着市场活跃度下降但存量杠杆高企，是理想的做空时机

---

## 2. 策略概述

- **目标**：针对币安新上线的永续合约币种，**每个币种只做一次空单**，捕捉上线后第一波明确的衰竭下跌行情。
- **核心理念**：通过**合约数据（OI/总交易量比率 + OI排名）+ 价格行为形态（三次冲顶、长上影线、放量滞涨）+ 资金费率**三维筛选，找到高概率下跌机会。
- **策略优势**：不依赖市值数据、使用真实资金费率、评分阈值基于实际数据分布。

---

## 3. 币种预筛选（必须全部满足）

| 筛选维度 | 条件 | 数据源 | 一票否决 |
|---------|------|--------|----------|
| 时间窗口 | 上线时间 < 48小时 | 币安公告 | ✅ 是 |
| 合约数据 | 无硬性要求（但影响评分） | 币安API | ❌ 否 |

**注意**：V4.1 移除了 OI/市值比的一票否决，因为该指标已改为评分项。

## 4. 信号评分系统（满分10分，开仓需总分 ≥ 6.5）

### 4.1 合约数据（权重45%）

合约数据评分分为两个子项：

#### 4.1.1 OI/总交易量比率（权重30%）

**计算方式**：
```
比率 = OI(USD) / 上线以来总交易量(USD)
```

**评分标准**（基于实际数据分布）：

| 比率区间 | 分位数 | 得分 | 说明 |
|---------|--------|------|------|
| > 0.06 | 95%分位 | 10 | 极高，存量杠杆远超增量热钱 |
| > 0.045 | 90%分位 | 7 | 高，市场脆弱 |
| > 0.025 | 75%分位 | 4 | 中等 |
| ≤ 0.025 | - | 1 | 低，市场活跃度高 |

**实际数据分布**（262个币种）：
- 最小值: 0.000715
- 最大值: 0.264610
- 平均值: 0.023214
- 中位数: 0.015030

#### 4.1.2 OI绝对值排名（权重15%）

与前10个新币的OI对比，OI越大说明市场关注度越高，做空价值越大。

| 排名分位数 | 得分 | 说明 |
|-----------|------|------|
| 前20% | 10 | OI排名前20% |
| 前40% | 7 | OI排名前40% |
| 中等 | 4 | OI排名中等 |
| 较低 | 1 | OI排名较低 |

### 4.2 技术面（权重35%）

基于 **1小时K线**，每根K线收盘后判断。**纯形态评分，不使用 RSI、MACD 等传统指标**。

| 条件 | 分值 | 量化标准 |
|------|------|----------|
| 三次冲顶 | 0~4 | 最近3-5根K线，高点逐次降低（高点差≥0.2%）或同一水平受阻≥3次 |
| 长上影线 | 0~3 | 上影线长度 ≥ 实体长度 × 2，且实体为阴线或十字星 |
| 放量滞涨 | 0~3 | 当前K线成交量 ≥ 前5根平均成交量 × 1.5，且收盘价低于前一根K线高点 |
| **技术面总分** | **0~10** | 三项得分直接相加 |

**最低要求**：技术面总分 ≥ 4 且 "三次冲顶" 得分 ≥ 2，否则即使总分达标也不开仓。

### 4.3 情绪面（权重20%）

使用当前资金费率（年化），取最近一次结算前的实时费率。

| 资金费率（年化） | 得分 | 说明 |
|----------------|------|------|
| > 150% | 10 | 资金费率极高 |
| 100% ~ 150% | 7 | 资金费率较高 |
| 50% ~ 100% | 4 | 资金费率中等 |
| 0% ~ 50% | 1 | 资金费率较低 |
| < 0% | 0 | 资金费率为负 |

**实际数据分布**（262个币种）：
- 最小值: -0.005476
- 最大值: 0.002620
- 平均值: 0.000059
- 中位数: 0.000050

### 4.4 总分计算与开仓条件

```
总分 = (合约得分 × 0.45) + (技术得分 × 0.35) + (情绪得分 × 0.20)
```

**开仓必须同时满足**：
- 总分 ≥ **6.5**
- 技术面：三次冲顶得分 ≥ 2 且 技术总分 ≥ 4
- 无任何一票否决项
- 该币种尚未开仓过（一币一单）

## 9. 总结

V4.1 版本通过使用 **OI/上线以来总交易量** 替代 **OI/市值比**，解决了市值数据获取困难的问题，同时保持了策略的核心逻辑：

- **高OI/交易量比率** = 存量杠杆高 + 增量热钱少 = 市场脆弱 = 理想做空时机
- **真实资金费率** = 情绪面指标
- **纯形态技术分析** = 三次冲顶 + 长上影线 + 放量滞涨

该版本更适合实盘部署，数据获取简单可靠。
