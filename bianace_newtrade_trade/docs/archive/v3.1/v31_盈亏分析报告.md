## 📊 附录：详细数据

### A. 盈亏计算公式

```
单笔盈亏 = (出场价 - 入场价) / 入场价 × 100%

总盈亏 = Σ(单笔盈亏)

胜率 = 盈利交易数 / 总交易数 × 100%

盈亏比 = 平均盈利 / 平均亏损
```

### B. 评分估算模型

```python
# 基于评分和形态估算胜率
base_win_rate = (score - 6.0) / 4.0  # 6 分=0%, 10 分=100%

if three_tops:
    base_win_rate += 0.10  # 三次冲顶 +10%

if volume_divergence:
    base_win_rate += 0.15  # 量价背离 +15%

# 估算盈亏
if random() < win_rate:
    pnl = random(1%, 5%)  # 盈利
else:
    pnl = random(-3%, -1%)  # 亏损
```
