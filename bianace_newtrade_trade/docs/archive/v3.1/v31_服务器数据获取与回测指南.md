本文档说明如何从服务器获取最近 100 个新上线永续合约的 1 小时 K 线数据，并进行回测。

## 🚀 快速开始

### 第一步：从服务器获取数据

```bash
cd /Users/yl/vscode/bianace_newtrade_trade/short_selling_system

# 获取最近 100 个新上线永续合约的 1 小时 K 线
python scripts/fetch_new_coins_klines.py \
    --count 100 \
    --limit 500 \
    --output data/new_coins_backtest.json
```

**参数说明**:
- `--count`: 获取多少个新币（默认 100）
- `--limit`: 每个币获取多少根 1 小时 K 线（默认 500）
- `--output`: 输出文件路径

**预计耗时**:
- 100 个币 × 500 根 K 线 ≈ 5-10 分钟
- 每 10 个币会暂停 1 秒，避免请求过快

### 第二步：运行回测

```bash
# 使用获取的数据进行回测
python backtesting/backtest_v31_simple.py \
    --data data/new_coins_backtest.json \
    --days 90 \
    --output results/backtest_v31_newcoins.json
```

**参数说明**:
- `--data`: 回测数据文件（第一步获取的数据）
- `--days`: 回测天数（默认 90）
- `--output`: 输出文件路径

## 🔧 故障排查

### 问题 1：获取数据失败

**错误信息**:
```
❌ 获取合约信息失败：HTTPSConnectionPool...
```

**解决方案**:
1. 检查网络连接
2. 检查币安 API 是否可访问
3. 增加超时时间（修改脚本中的 timeout 参数）

### 问题 2：K 线数据不足

**错误信息**:
```
⚠️  BTCUSDT 获取 K 线失败，跳过
```

**原因**:
- 该币种是新上线的，还没有足够的 1 小时 K 线
- 网络请求失败

**解决方案**:
1. 减少 `--limit` 参数
2. 检查网络连接
3. 稍后重试

### 问题 3：回测没有交易

**错误信息**:
```
✅ 回测完成，共 0 笔交易
```

**可能原因**:
1. 开仓阈值太高（默认 6.0）
2. 时间窗口太短（默认 48 小时）
3. K 线数据质量差

**解决方案**:
```python
# 修改回测脚本中的配置
config = {
    'signal_threshold': 5.5,  # 降低阈值
    'listing_hours_max': 72,  # 延长时间窗口
    'min_klines': 10          # 减少最少 K 线数
}
```
