#### 2.2 合约数据评分规则对比（🔴 核心差异）

**现有系统 (v3.1)**：
```python
# OI/市值比评分（泡沫越大，评分越高）
if oi_ratio > 1.0: score = 10.0  # 严重泡沫，强烈做空信号
elif oi_ratio > 0.5: score = 8.0  # 高泡沫
elif oi_ratio > 0.3: score = 6.0  # 中等泡沫
elif oi_ratio > 0.1: score = 4.0  # 低泡沫
else: score = 2.0  # 极低泡沫
```

**新规则 (v4.0)**：
```
# OI/市值比评分（越低越安全）
< 0.3: 10分（优秀，无主力控盘风险）
0.3 ~ 0.5: 7分（良好，可接受）
0.5 ~ 0.8: 3分（偏高，不推荐）
> 0.8: 一票否决
```

**差异分析**：
- 🔴 **评分逻辑完全相反**！
  - 现有系统：OI/市值比越高，评分越高（认为泡沫大，做空机会好）
  - 新规则：OI/市值比越低，评分越高（认为无主力控盘风险，更安全）
- ⚠️ **一票否决阈值不同**：
  - 现有系统：OI/市值比 > 1.0
  - 新规则：OI/市值比 > 0.8（更严格）

**这是最核心的差异！需要重点理解：**
- 现有系统认为：OI/市值比高 = 泡沫大 = 做空机会好
- 新规则认为：OI/市值比高 = 主力控盘风险 = 危险，应该避免

#### 2.3 技术面评分规则对比

**现有系统 (v3.1)**：
```python
技术面评分 = 趋势评分 (4分) + RSI评分 (3分) + 波动率评分 (3分) 
           + 形态加分 (0-1分) + 量价加分 (0-1分)
满分：10分

# 已实现三次冲顶、放量滞涨检测（作为加分项）
three_tops, resistance_level = self.detect_three_tops(klines, lookback=5)
if three_tops: pattern_bonus = 1.0

divergence, divergence_reason = self.check_volume_price_divergence(klines)
if divergence: divergence_bonus = 1.0
```

**新规则 (v4.0)**：
```
技术面评分 = 三次冲顶 (0-4分) + 长上影线 (0-3分) + 放量滞涨 (0-3分)
满分：10分

# 三项直接相加，不是加分项
```

**差异分析**：
- ⚠️ **评分逻辑完全不同**：
  - 现有系统：趋势+RSI+波动率为主，形态为辅（加分项）
  - 新规则：形态为主（三次冲顶、长上影线、放量滞涨），去掉技术指标
- ✅ 现有系统**已经实现**三次冲顶和放量滞涨检测
- ⚠️ 新规则将形态识别作为**主要评分项**，而非加分项

#### 2.4 情绪面评分规则对比

**现有系统 (v3.1)**：
```python
# 新币宽松评分标准（年化费率）
if annual_rate > 200: sentiment_score = 10.0
elif annual_rate > 100: sentiment_score = 8.0
elif annual_rate > 50: sentiment_score = 6.0
elif annual_rate > -100: sentiment_score = 5.0
elif annual_rate > -500: sentiment_score = 4.0
else: sentiment_score = 3.5
```

**新规则 (v4.0)**：
```
# 资金费率年化
> 150%: 10分
100% ~ 150%: 7分
50% ~ 100%: 3分
< 50% 或负费率: 0分
```

**差异分析**：
- ✅ 新规则更简单直接，只关注高资金费率
- ⚠️ 新规则对负资金费率给0分（现有系统给3.5-5分）
- ⚠️ 新规则对低资金费率（<50%）给0分（现有系统给5-6分）
