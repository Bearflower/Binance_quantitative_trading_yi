# 交易结果跟踪系统 - 实现总结

## 一、实现完成情况

### ✅ 已完成的功能

#### 1. 数据库表结构（3 张新表）

**closed_positions（平仓记录表）**
- 按订单级别记录平仓信息
- 包含：开仓价、平仓价、数量、盈亏、收益率、平仓原因、持仓时长
- 记录最大浮盈和最小浮亏

**tp_sl_triggers（止盈止损触发记录表）**
- 记录止盈止损触发事件
- 包含：触发时间、触发价格、触发时盈亏率

**trade_statistics（交易统计表）**
- 按周期统计（周/月）
- 包含：交易次数、胜率、盈亏比、连续盈亏次数

#### 2. 核心功能模块

**平仓检测模块** (`services/close_detector.py`)
- 检测已完成的订单
- 计算已实现盈亏（毛盈亏、手续费、净盈亏）
- 计算收益率
- 判断平仓原因（止盈/止损/手动）
- 从监控日志中获取最大浮盈/浮亏

**交易统计模块** (`services/trade_statistics.py`)
- 计算本周/本月统计数据
- 胜率计算
- 盈亏比计算
- 连续盈利/亏损次数统计

**周报生成模块** (`services/weekly_report.py`)
- 生成每周交易报告
- 格式化为飞书消息
- 自动推送到飞书

#### 3. 集成到监控系统

修改 `services/position_monitor.py`：
- 在定时监控任务中添加平仓检测
- 平仓后自动更新统计数据
- 每周日自动发送周报

## 二、功能特性

### 2.1 跟踪指标

✅ **已实现盈亏** - 精确计算每笔交易的净盈亏（扣除手续费）
✅ **收益率** - 基于保证金计算收益率百分比
✅ **持仓时长** - 从开仓到平仓的秒数
✅ **平仓原因** - 自动识别（止盈/止损/手动平仓）
✅ **最大浮盈/浮亏** - 从监控日志中获取持仓期间的极端值

### 2.2 统计分析

✅ **胜率** - 盈利交易数 / 总交易数
✅ **盈亏比** - 平均盈利 / 平均亏损
✅ **连续盈利/亏损次数** - 最大连胜和连败记录
✅ **按周统计** - 每周一到周日
✅ **按月统计** - 每月 1 号到月末

### 2.3 周报推送

✅ **触发次数** - 本周触发多少次交易
✅ **完成次数** - 本周完成多少次交易
✅ **胜率** - 本周胜率百分比
✅ **收益率** - 本周平均收益率
✅ **总盈亏** - 本周总盈亏 USDT
✅ **飞书推送** - 每周日自动发送

## 四、使用方法

### 4.1 数据库表已创建

系统会自动创建以下表：
- `closed_positions` - 平仓记录
- `tp_sl_triggers` - 止盈止损触发记录
- `trade_statistics` - 交易统计

### 4.2 自动运行

平仓检测和统计更新已集成到现有监控系统：
- 每 15 分钟执行一次监控任务
- 检测是否有订单已平仓
- 如果有新平仓，自动更新统计数据
- 每周日自动发送周报到飞书

### 4.3 查询平仓记录

```python
from models.database import get_db_manager

db = get_db_manager()

# 查询最近 10 笔平仓
closed = db.get_closed_positions(limit=10)

# 查询指定交易对的平仓
btc_closed = db.get_closed_positions(symbol='BTCUSDT', limit=10)

# 查询本周平仓
from datetime import datetime, timedelta
week_ago = datetime.now() - timedelta(days=7)
week_closed = db.get_closed_positions(start_time=week_ago)
```

### 4.4 查询统计数据

```python
from models.database import get_db_manager

db = get_db_manager()

# 查询最近 4 周统计
weekly_stats = db.get_weekly_statistics(weeks=4)

# 查询最近 6 个月统计
monthly_stats = db.get_monthly_statistics(months=6)
```

### 4.5 手动生成周报

```python
from services.weekly_report import get_report_generator

generator = get_report_generator()

# 生成报告
report = generator.generate_weekly_report()

# 发送飞书通知
generator.send_weekly_report(report)
```

## 七、注意事项

### 7.1 数据库迁移

首次运行时需要创建新表：
```python
# 系统会自动创建表结构
from models.database import get_db_manager
db = get_db_manager()  # 会自动初始化所有表
```

### 7.2 手续费计算

当前假设 taker 费率为 0.04%（币安标准费率）
如需精确计算，可以调用币安 API 获取实际佣金费率

### 7.3 平仓原因识别

当前识别逻辑：
- TAKE_PROFIT_MARKET/TAKE_PROFIT 订单 → 止盈平仓
- STOP_LOSS_MARKET/STOP_LOSS 订单 → 止损平仓
- 其他订单 → 手动平仓

### 7.4 周报发送时间

每周日会自动检测并发送周报
发送条件：
- 配置了 LARK_WEBHOOK_URL 环境变量
- 当天是周日（weekday() == 6）
