# 币安自动化交易系统 - 技术架构设计

## 1. 系统概述

### 1.1 系统定位

基于 traderule.txt 规则引擎的币安合约自动化交易系统，支持 PM 账户（投资组合保证金账户），实现从信号检测、仓位计算、风险管理到订单执行的全流程自动化。

### 1.2 核心目标

- ✅ **自动化交易** - 每小时整点自动分析行情并执行交易
- ✅ **规则驱动** - 基于 traderule.txt 的规则引擎决策
- ✅ **风险控制** - 多层风控机制（止损止盈、频率控制、资金管理）
- ✅ **量化评分** - v6.12 多维度信号评分系统
- ✅ **动态仓位** - v6.13 根据可用保证金自动调整仓位
- ✅ **实时监控** - 飞书通知、交易日报、异常告警

### 3.3 量化评分引擎 (core/scoring_engine.py) - v6.12 核心

**职责**：对交易信号进行多维度量化评分

**评分维度**（总分 100 分）：

| 维度 | 权重 | 评分方式 |
|------|------|----------|
| **趋势强度** | 40 | EMA21 斜率归一化 + 价格与 EMA21 距离 |
| **形态质量** | 35 | K 线形态识别 + 突破质量 |
| **动量背离** | 25 | MACD 柱线背离程度 |

**核心算法**：
```python
class ScoringEngine:
    def score(self, symbol: str, data: Dict[str, Any]) -> ScoreResult:
        # 1. 前置过滤（一票否决）
        if not self._pre_filter(data):
            return ScoreResult(score=0, grade='F')
        
        # 2. 多维度评分
        trend_score = self._calculate_trend_score(data)  # 40 分
        pattern_score = self._calculate_pattern_score(data)  # 35 分
        momentum_score = self._calculate_momentum_score(data)  # 25 分
        
        total_score = trend_score + pattern_score + momentum_score
        
        # 3. 等级映射
        grade = self._score_to_grade(total_score)
        
        return ScoreResult(
            score=total_score,
            grade=grade,
            position_ratio=self._grade_to_position_ratio(grade),
            leverage=self._grade_to_leverage(grade)
        )
```

**信号等级映射**：
- **S 级**（≥85 分）：仓位 50%，杠杆 5 倍
- **A 级**（≥75 分）：仓位 30%，杠杆 4 倍
- **B 级**（≥65 分）：仓位 15%，杠杆 3 倍
- **C 级**（≥55 分）：仓位 5%，杠杆 2 倍
- **<55 分**：过滤，不开仓

### 3.4 仓位计算模块 (core/position_calculator.py)

**职责**：根据信号等级和可用保证金计算仓位

**核心接口**：
```python
class PositionCalculator:
    def calculate_position(
        self,
        symbol: str,
        entry_price: Decimal,
        stop_loss_price: Decimal,
        direction: int,
        signal_grade: str,
        available_balance: Optional[Decimal] = None  # v6.13 新增
    ) -> PositionResult
```

**计算逻辑**：
1. **基础仓位**（v6.12）：
   ```python
   base_notional = account_balance * risk_percentage
   position_coefficient = grade_coefficient[signal_grade]  # S:50%, A:30%, B:15%, C:5%
   actual_notional = base_notional * position_coefficient
   margin = actual_notional / leverage
   ```

2. **动态调整**（v6.13）：
   ```python
   # 1. 计算可用保证金（保留 20% 安全垫）
   usable_balance = available_balance * 0.8
   
   # 2. 资金充足？不调整
   if usable_balance >= required_margin:
       return position_params  # 全额执行
   
   # 3. 资金不足？计算调整系数
   adjustment_ratio = usable_balance / required_margin
   adjusted_margin = required_margin * adjustment_ratio
   
   # 4. 检查最小阈值
   if adjusted_margin < 5U:
       return None  # 跳过交易
   
   # 5. 应用调整（等比缩放）
   adjusted_position['quantity'] = original_quantity * adjustment_ratio
   ```

### 3.6 频率控制模块 (services/frequency_controller.py) - v6.12 新增

**职责**：控制交易频率，避免过度交易

**限制规则**：
- ✅ 每日最大总交易数：4 笔（所有等级合计）
- ✅ 单品种每日最大交易数：2 笔
- ✅ 同品种冷却期：12 小时
- ✅ 连续亏损暂停：5 笔亏损暂停 1 天
- ✅ 每日最大亏损限额：25U（500U × 5%）

**技术实现**：
```python
class FrequencyController:
    def __init__(self, db_manager):
        self.db = db_manager
        self.cache = Redis()  # 缓存当日统计
    
    def check_trading_allowed(self, symbol: str) -> Tuple[bool, str]:
        # 1. 检查当日总交易数
        if self._get_daily_trade_count() >= 4:
            return False, "达到每日最大交易数"
        
        # 2. 检查单品种交易数
        if self._get_symbol_daily_trade_count(symbol) >= 2:
            return False, f"{symbol} 达到每日最大交易数"
        
        # 3. 检查冷却期
        if not self._check_cooldown_period(symbol, hours=12):
            return False, f"{symbol} 处于冷却期"
        
        # 4. 检查连续亏损
        if self._get_consecutive_losses() >= 5:
            return False, "连续亏损达到限额"
        
        # 5. 检查当日亏损
        if self._get_daily_loss() >= Decimal('25'):
            return False, "达到每日最大亏损"
        
        return True, "允许交易"
```

### 3.7 订单生成模块 (core/order_generator.py)

**职责**：生成币安 API 订单参数

**订单类型**：
1. **开仓单**（MARKET/LIMIT）
2. **止损单**（STOP_MARKET）
3. **止盈单**（TAKE_PROFIT_MARKET）- 支持多笔

**订单模板**：
```python
def generate_order_template(
    symbol: str,
    direction: int,
    entry_price: Decimal,
    stop_loss_price: Decimal,
    take_profit_levels: List[Decimal],
    position_data: PositionResult
) -> OrderTemplate:
    return {
        'entry': {
            'symbol': symbol,
            'side': 'BUY' if direction == 1 else 'SELL',
            'type': 'MARKET',
            'quantity': position_data['quantity']
        },
        'stop_loss': {
            'symbol': symbol,
            'side': 'SELL' if direction == 1 else 'BUY',
            'type': 'STOP_MARKET',
            'stopPrice': stop_loss_price,
            'quantity': position_data['quantity']
        },
        'take_profits': [
            {
                'symbol': symbol,
                'side': 'SELL' if direction == 1 else 'BUY',
                'type': 'TAKE_PROFIT_MARKET',
                'stopPrice': tp_level,
                'quantity': position_data['quantity'] * Decimal('0.25')
            }
            for tp_level in take_profit_levels
        ]
    }
```

### 8.3 回测指标

| 指标 | 计算公式 | 说明 |
|------|---------|------|
| **总收益率** | (最终资金 - 初始资金) / 初始资金 | 总收益百分比 |
| **年化收益** | (1 + 总收益率)^(365/天数) - 1 | 年化收益率 |
| **最大回撤** | max(历史最高值 - 当前值) / 历史最高值 | 最大亏损幅度 |
| **夏普比率** | (年化收益 - 无风险利率) / 收益标准差 | 风险调整后收益 |
| **胜率** | 盈利交易数 / 总交易数 | 盈利概率 |
| **盈亏比** | 平均盈利 / 平均亏损 | 盈利效率 |
