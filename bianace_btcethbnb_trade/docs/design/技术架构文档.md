# 币安自动化交易系统 - 技术架构文档

## 1. 系统概述

### 1.1 系统简介

币安自动化交易系统是一个基于规则引擎的量化交易系统，支持 PM 账户（投资组合保证金账户）。系统基于 `traderule.txt` 规则，实现从信号检测、仓位计算、风险管理到订单生成的全流程自动化。

**系统版本**: v6.13.1 (2026-04-12)

**核心特性**:
- ✅ 多时间框架技术分析（日线 +4 小时 +1 小时）
- ✅ 量化评分系统（v6.12 多维度评分）
- ✅ 动态仓位管理（v6.13 智能降仓）
- ✅ ATR 动态止损止盈（v6.13.1 优化）
- ✅ 频率控制与风险管理
- ✅ 飞书通知与交易日报
- ✅ Docker 容器化部署

### 1.2 设计原则

1. **规则驱动**: 严格遵循 traderule.txt 规则引擎
2. **风险优先**: 多层风控机制，确保资金安全
3. **模块化**: 核心模块解耦，便于维护和扩展
4. **可回测**: 完整的历史数据回测系统
5. **可观测**: 详细日志 + 飞书通知 + 数据库记录

**核心流程**:

```
   └─ ATR% 区间：2.0% ~ 4.5%

   ├─ 形态质量 (35 分): K 线形态 + 突破识别
   └─ 动量背离 (25 分): MACD 柱线背离
   
   ↓
   
3. 一票否决
   ├─ 资金费率 > 0.08%
   ├─ 波动率 > 阈值 (币种差异化)
   ├─ 24h 涨跌幅超限
   └─ 数据完整性不足
   
   ↓
   
4. 信号分级
   ├─ S 级 (≥85 分): 仓位 50%, 杠杆 5x
   ├─ A 级 (≥75 分): 仓位 30%, 杠杆 4x
   ├─ B 级 (≥65 分): 仓位 15%, 杠杆 3x
   └─ C 级 (≥55 分): 仓位 5%, 杠杆 2x
```

#### 3.2.5 仓位计算模块 (core/position_calculator.py)

**职责**: 根据信号等级和止损距离计算仓位大小

**核心公式**:
```python
# 1. 计算基础名义价值
risk_distance = abs(entry_price - stop_loss_price)
base_notional_value = (single_position_margin * leverage) / risk_distance

# 2. 应用仓位系数 (v5.3)
position_coefficient = get_position_coefficient(grade)  # S:0.5, A:0.3, B:0.15, C:0.05
actual_notional_value = base_notional_value * position_coefficient

# 3. 计算实际仓位
quantity = actual_notional_value / entry_price
margin = actual_notional_value / leverage
```

**v6.13 动态仓位调整**:
```python
# services/position_adjuster.py
def adjust_position(
    symbol: str,
    position_params: Dict,
    available_balance: Decimal
) -> Optional[Dict]:
    """
    1. 计算可用保证金 = 可用余额 × 0.8 (保留 20% 安全垫)
    2. 如果 可用保证金 >= 预设保证金：不调整
    3. 如果 可用保证金 < 预设保证金:
       - 计算调整系数 = 可用保证金 / 预设保证金
       - 调整后保证金 = 预设保证金 × 调整系数
       - 如果 调整后保证金 < 5U：跳过交易
       - 否则：等比缩放仓位
    """
```
