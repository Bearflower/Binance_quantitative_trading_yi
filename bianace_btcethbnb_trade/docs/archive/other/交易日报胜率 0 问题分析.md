## 🔧 问题根源

### 问题 1: 盈亏统计逻辑缺失 ⭐⭐⭐

**现象**: `daily_execution_stats.win_count` 和 `loss_count` 始终是 0

**原因**: 
- 代码中只有开仓逻辑，没有平仓后的统计更新
- `_record_daily_stats()` 只记录 `signals_count` 和 `executed_count`
- 没有函数在平仓后更新 `win_count` 和 `loss_count`

**影响**:
- 交易日报胜率始终为 0%
- 无法评估策略效果
- 无法统计盈利/亏损交易数量

---

### 问题 2: 交易记录状态未更新 ⭐⭐

**现象**: `trade_records.status` 始终是 'OPEN'

**原因**:
- `frequency_controller.record_trade()` 只记录开仓
- 没有平仓时更新状态的逻辑
- 没有关闭交易记录的函数

**影响**:
- 无法区分已平仓和未平仓交易
- 无法计算实际盈亏
- 频率控制可能不准确

---

### 问题 3: 订单编号可能未正确保存 ⭐

**现象**: 虽然代码中有 `entry_order_id`，但可能未保存到数据库

**原因**:
- `save_trade()` 函数保存的是完整的订单数据
- `record_trade()` 函数（频率控制器）只记录简单信息
- 两个表可能没有正确关联

**影响**:
- 无法追踪订单状态
- 无法查询历史订单
- 无法进行订单级别的分析

## 📋 解决方案

### 方案 A: 快速修复（1-2 小时） ⭐⭐⭐

**目标**: 让交易日报显示正确的胜率

**步骤**:

1. **添加盈亏更新函数** (`scheduler_new.py`)
   ```python
   def _update_trade_statistics(self, symbol: str, close_price: Decimal, 
                                 entry_price: Decimal, quantity: Decimal, 
                                 direction: str):
       """更新交易统计"""
       # 计算盈亏
       if direction == 'BUY':
           pnl = (close_price - entry_price) * quantity
       else:
           pnl = (entry_price - close_price) * quantity
       
       # 判断盈亏
       is_win = pnl > 0
       
       # 更新 daily_execution_stats
       today = datetime.now().date()
       if is_win:
           update_query = """
               UPDATE daily_execution_stats
               SET win_count = win_count + 1,
                   updated_at = CURRENT_TIMESTAMP
               WHERE stat_date = %s
           """
       else:
           update_query = """
               UPDATE daily_execution_stats
               SET loss_count = loss_count + 1,
                   updated_at = CURRENT_TIMESTAMP
               WHERE stat_date = %s
           """
       self.db._execute_query(update_query, (today,))
       
       logger.info(f"交易统计已更新：{symbol} {'盈利' if is_win else '亏损'} {abs(pnl):.2f} USDT")
   ```

2. **在平仓时调用更新函数** (`position_monitor.py` 或其他平仓逻辑)
   ```python
   # 平仓成功后
   if close_result.get('status') == 'FILLED':
       close_price = Decimal(close_result.get('avgPrice'))
       self.scheduler_instance._update_trade_statistics(
           symbol=symbol,
           close_price=close_price,
           entry_price=entry_price,
           quantity=quantity,
           direction=direction
       )
   ```
