### 3. 新增数据库表

#### `trade_records` 表
```sql
CREATE TABLE IF NOT EXISTS trade_records (
    id SERIAL PRIMARY KEY,
    symbol VARCHAR(20) NOT NULL,          -- 交易对
    direction VARCHAR(4),                 -- 方向（多/空）
    open_time TIMESTAMP NOT NULL,         -- 开仓时间
    close_time TIMESTAMP,                 -- 平仓时间
    pnl DECIMAL(20, 8),                   -- 盈亏金额
    pnl_percent DECIMAL(10, 4),           -- 盈亏比例
    entry_price DECIMAL(20, 8),           -- 开仓价
    close_price DECIMAL(20, 8),           -- 平仓价
    quantity DECIMAL(20, 8),              -- 数量
    leverage INTEGER,                     -- 杠杆倍数
    signal_grade VARCHAR(2),              -- 信号等级
    status VARCHAR(20) DEFAULT 'OPEN',    -- 状态
    order_id BIGINT,                      -- 订单 ID
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 索引
CREATE INDEX idx_trade_records_symbol ON trade_records(symbol);
CREATE INDEX idx_trade_records_open_time ON trade_records(open_time);
CREATE INDEX idx_trade_records_status ON trade_records(status);
CREATE INDEX idx_trade_records_symbol_time ON trade_records(symbol, open_time);
```

## 📝 技术细节

### 频率控制器工作流程
```
每小时整点触发
    ↓
检测信号
    ↓
执行交易前检查
    ├─ 每日总交易数 < 4? ❌ → 拒绝
    ├─ 单品种交易数 < 2? ❌ → 拒绝
    ├─ 冷却期已过？ ❌ → 拒绝
    ├─ 连续亏损 < 5? ❌ → 拒绝
    └─ 每日亏损 < 25U? ❌ → 拒绝
    ↓
所有检查通过 ✅
    ↓
执行交易
    ↓
记录交易到数据库
```

### 数据库查询优化
- **索引设计**：
  - `idx_trade_records_symbol` - 按币种查询
  - `idx_trade_records_open_time` - 按时间查询
  - `idx_trade_records_symbol_time` - 组合查询（最常用）
  
- **查询性能**：
  - 单币种查询：< 1ms

  - 统计聚合查询：< 10ms
