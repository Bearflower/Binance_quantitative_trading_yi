## 问题描述

### 原始错误
```
检查已平仓订单失败：'DatabaseManager' object has no attribute '_execute_all'
```

### 影响
- 胜率统计功能完全失效
- 无法检查已平仓订单
- 无法更新交易记录状态
- 每次小时级分析任务都会报错

## 修复过程

### 第一次修复：数据库 API 调用错误

**问题**: `scheduler_new.py` 第 489 行调用了不存在的 `_execute_all` 方法

**修复**:
```python
# 修改前
open_positions = self.db._execute_all(query)

# 修改后
open_positions = self.db._execute_query(query)
```

**结果**: ✅ 成功 - 数据库 API 调用正常

### 第二次修复：SQL 字段名错误

**问题**: SQL 查询使用了错误的字段名
- `position_qty` → 实际应为 `quantity`
- `entry_order_id` → 实际应为 `order_id`

**数据库表结构** (`schema_bianace.trade_records`):
```sql
CREATE TABLE trade_records (
    id           INTEGER PRIMARY KEY,
    symbol       VARCHAR(20),
    direction    VARCHAR(4),
    quantity     NUMERIC(20,8),      -- 不是 position_qty
    entry_price  NUMERIC(20,8),
    order_id     BIGINT,             -- 不是 entry_order_id
    status       VARCHAR(20),
    ...
);
```

**修复**:
```python
# 修改前
query = """
    SELECT id, symbol, direction, entry_price, position_qty, entry_order_id
    FROM trade_records
    WHERE status = 'OPEN'
    ORDER BY created_at DESC
"""

# 修改后
query = """
    SELECT id, symbol, direction, entry_price, quantity, order_id
    FROM trade_records
    WHERE status = 'OPEN'
    ORDER BY created_at DESC
"""
```

**结果**: ✅ 成功 - SQL 查询正常执行
