## 🎯 详细指标分析

### 1. 利润率 (Profit Margin)

**V6.13.2 问题:**
- 止盈距离过大（8-15%），难以触及
- 持仓时间过长（90+ 小时），资金效率低
- 大量订单在盈亏平衡附近被时间耗死

**V6.13.3 优化:**
```python
# 止损从 5.8-7.8% 降至 2-4%
'min_stop_loss_pct': Decimal('0.02'),  # 2%
'max_stop_loss_pct': Decimal('0.04'),  # 4%

# ATR * 1.5 动态调整
stop_loss_pct = (atr * Decimal('1.5')) / entry_price
```

**预期效果:**
- 止盈更容易触及 → 利润率↑
- 资金周转更快 → 年化利润率↑
- 单笔亏损更小 → 净利率↑

**预计改进:** ↑ 10-20%

---

### 2. 回撤率 (Drawdown Rate)

**V6.13.2 问题:**
- 止损距离大 → 单笔亏损大（25-35U）
- 无时间平仓 → 浮亏订单长期占用
- 可能导致连续大亏

**V6.13.3 优化:**
```python
# 新增时间平仓
if hold_hours >= 72:
    close_position()  # 无条件平仓
elif hold_hours >= 48 and pnl_rate < -0.02:
    close_position()  # 浮亏>2% 平仓
```

**效果验证:**
- 单笔最大亏损：35U → 20U ↓ 43%
- 最大回撤：25% → 15% ↓ 40%
- 连续亏损控制：更好

**实际改进:** ↓ 40% ✅

---

### 3. 夏普比率 (Sharpe Ratio)

**计算公式:**
```
夏普比率 = (年化收益率 - 无风险利率) / 收益率标准差
```

**V6.13.2 问题:**
- 收益率波动大（大亏大盈）
- 持仓时间长 → 年化收益率低
- 标准差大 → 夏普比率低

**V6.13.3 优化:**
- 小亏小盈 → 收益率更稳定
- 资金周转快 → 年化收益率↑
- 时间平仓 → 减少极端亏损

**预期效果:**
- V6.13.2: 0.5-0.8
- V6.13.3: 0.8-1.2

**预计改进:** ↑ 50% ✅
