## 🎯 V6.13.3 核心优化

### 1. 缩小止损距离（方案 1）

**V6.13.2:**
```python
'min_stop_loss_pct': Decimal('0.03'),  # 3%
'max_stop_loss_pct': Decimal('0.07'),  # 7%
```

**V6.13.3:**
```python
'min_stop_loss_pct': Decimal('0.02'),  # 2% (↓1%)
'max_stop_loss_pct': Decimal('0.04'),  # 4% (↓3%)
```

**效果:**
- BTCUSDT 止损从 5.8% 降至 3-4%
- 止损触发率预计提升 30-50%
- 单笔亏损从 30U 降至 15-20U

---

### 2. 优化 ATR 止损计算（方案 2）

**V6.13.2:**
```python
stop_loss_pct = atr / entry_price  # 直接使用 ATR
```

**V6.13.3:**
```python
stop_loss_pct = (atr * Decimal('1.5')) / entry_price  # ATR * 1.5
# 限制在 2-4% 范围
stop_loss_pct = max(0.02, min(stop_loss_pct, 0.04))
```

**效果:**
- 更科学地反映市场波动性
- 高波动时自动扩大止损（但不超过 4%）
- 低波动时缩小止损（但不低于 2%）

---

### 3. 新增持仓时间平仓（方案 3）

**V6.13.3 新增逻辑:**

```python
# 规则 1: 持仓超过 72 小时 → 无条件平仓
if hold_hours >= 72:
    close_position(reason='持仓时间过长')

# 规则 2: 持仓超过 48 小时 + 浮亏>2% → 平仓
if hold_hours >= 48 and pnl_rate < -0.02:
    close_position(reason='时间 + 浮亏')
```

**效果:**
- 避免"僵尸订单"占用保证金
- 及时释放资金用于新机会
- 减少无意义的保证金消耗

**实现模块:**
- `services/position_time_manager.py` - 持仓时间管理器
- `services/position_monitor.py` - 集成时间平仓检查
- `models/database.py` - 新增 time_close_logs 表

## ⚠️ 潜在风险

### 1. 止损过紧

**风险:** 缩小止损可能导致频繁止损

**缓解措施:**
- 使用 ATR * 1.5 动态调整
- 设置 2% 下限保护

### 2. 时间平仓误杀

**风险:** 可能在价格反弹前被平仓

**缓解措施:**
- 仅当浮亏>2% 时才触发 48 小时平仓
- 72 小时无条件平仓作为最后手段

### 3. 回测过拟合

**风险:** 参数可能过度适配历史数据

**缓解措施:**
- 使用多时间段回测
- 实盘小资金验证
