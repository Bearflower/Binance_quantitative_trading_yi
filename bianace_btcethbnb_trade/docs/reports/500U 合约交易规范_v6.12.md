# 虚拟货币合约交易系统化操作规范 v6.12（全仓自动化版·500U 阶段一专用）

**【核心指令】**

请严格遵循以下规则，基于 BTC/USDT、ETH/USDT、BNB/USDT 的日线、4 小时、1 小时 K 线、交易深度、资金费率等数据，给出全仓操作建议。

---

## 一、核心交易原则（全仓模式）

- **单笔最大亏损 ≤ 总资金的 2%**（500U × 2% = 10U）。
- **总保证金占用 ≤ 总资金的 30%**（≤150U）。
- **统一杠杆倍数：5 倍**（方案 4：保持分级仓位，统一杠杆）。
- **分级仓位比例**：S 级 20%，A 级 15%，B 级 10%，C 级 5%。
- 同时持仓 ≤ 2 个品种，单品种名义价值 ≤ 总资金 × 3 倍。
- 亏损时禁止加仓、禁止提高杠杆。

---

## 500U 微型账户特规（阶段一·全仓版）

- 总资金：500U，单笔风险固定 10U（可波动率调整）。
- 最大总保证金占用：150U。
- 允许同时持仓 ≤ 2 个品种。
- 信号等级：S、A、B、C（B/C 级为新增）。
- 强制利润提取：账户创新高时，提取盈利的 50% 至储蓄账户。

## 三、多时间框架入场系统（v6.12 最终版）

### 3.1 数据与指标计算标准

使用 TA-Lib 或精确算法，基于日线、4 小时、1 小时 K 线计算以下指标：

| 指标 | 参数 | 用途 |
|------|------|------|
| EMA | 21, 55 | 趋势判断 |
| MACD | 12,26,9 | 动能与背离 |
| RSI | 14 | 辅助过滤 |
| ATR | 14 | 波动率、止损止盈 |
| ADX | 14 | 趋势强度过滤（前置条件） |
| 成交量 | 1h | 信号确认 |

### 3.2 趋势过滤器（硬性条件）

**多头方向**（必须同时满足）：
- 日线收盘价 > EMA55。
- 日线 EMA21 斜率 > 0.05%（最近 5 根日线线性回归）。
- 4 小时价格回调至 EMA21 附近（价差 ≤ 1.5×ATR14）。
- 1 小时收盘价 > EMA21。

**空头方向**：对称。

**禁止入场**：
- 日线 EMA21 斜率绝对值 < 0.03%。
- ATR/价格 > 4.5% 或 < 2%。
- 最近 6 小时内出现单根 1h K 线涨跌幅 > 5%。
- 资金费率绝对值 > 0.05%。

### 3.3 前置过滤器（保持不变，已验证有效）

- **ADX ≥ 20**（日线级别，14 周期）。
- **成交量放大**：S 级 ≥ 1.8 倍，A 级 ≥ 1.5 倍，B/C 级 ≥ 1.2 倍（均相对于过去 20 小时平均）。
- **ATR% 区间**：2.0% ~ 4.5%（ATR14/价格）。

### 3.4 评分系统（简化 3 维度）

总分 0-100，由以下三个维度加权求和：

| 维度 | 权重 | 评分方式 |
|------|------|----------|
| 趋势强度 | 40 | EMA21 斜率归一化 + 价格与 EMA21 距离 |
| 形态质量 | 35 | 阳包阴/阴包阳/突破回踩/背离，连续得分 |
| 动量背离 | 25 | MACD 柱线背离程度 |

### 3.5 信号等级与仓位配置（核心变更）

| 等级 | 总分要求 | 仓位系数 | 统一杠杆 | 说明 |
|------|----------|----------|----------|------|
| S | ≥85 | 20% | 5 倍 | 高质量信号，重仓 |
| A | ≥75 | 15% | 5 倍 | 中高质量，中仓 |
| B | ≥65 | 10% | 5 倍 | 中等质量，轻仓 |
| C | ≥55 | 5% | 5 倍 | 边缘信号，极轻仓 |
| <55 | - | 不开仓 | - | 放弃 |

**仓位计算示例**（S 级）：
- 止损幅度 3%，基础名义价值 = 10 / 0.03 = 333U。
- 实际名义价值 = 333 × 20% = 66.6U。
- 合约数量 = 66.6 / 开仓价。
- 保证金 = 66.6 / 5 = 13.32U（占资金 2.7%）。

**技术说明**：由于币安合约账户不支持同一交易对同时持有多个不同杠杆倍数的仓位，因此采用"方案 4：保持分级仓位，统一杠杆"，通过仓位比例而非杠杆倍数来控制风险。

### 3.6 止盈止损策略（v6.12 稳健版）

- **止损** = 1.5 × ATR14（多头：开仓价 - 1.5×ATR，空头相反）。
- **TP1** = 开仓价 ± 4.0×ATR，平仓 **25%**。
- **TP2** = 开仓价 ± 6.0×ATR，平仓 **25%**。
- **吊灯止损**：当价格突破 2.5×ATR 后启动，回撤 1.5×ATR 时平仓剩余 50% 仓位。

**注意**：v6.14 中尝试收紧止损至 1.4×ATR 导致净利润下降，故维持 1.5×ATR。

### 3.7 频率控制（v6.12 稳健版）

- **每小时执行一次**：**每小时整点执行**（00:00, 01:00, ..., 23:00）。
- **每日最大总交易数**：**4 笔**（所有等级合计）。
- **单品种每日最大交易数**：2 笔。
- **同品种冷却期**：12 小时。
- **连续亏损暂停**：连续 **5 笔**亏损（不分等级）暂停 1 天。
- **每日最大亏损限额**：5% 总资金（25U），触及则当日停止交易。
- **飞书通知**：只发送规则引擎分析结果（检测信号、信号详情），不发送交易执行结果。

## 四、风险管理强化

### 4.1 波动率目标仓位

- 单笔风险金额 = 10U × (中位数 ATR% / 当前 ATR%)，限制在 [5U, 15U] 区间。
- 中位数 ATR% 取各币种过去 30 天的历史中位数（BTC 2.8%，ETH 3.2%，BNB 5.0%）。

### 4.2 强平预防

- 保证金率 = 账户权益 / 占用保证金。
- 预警线：保证金率 ≤ 1.5 → 减仓 50%。
- 紧急线：保证金率 ≤ 1.2 → 全部平仓。

### 4.3 双重止损

- 平台硬止损单设置在止损价。
- 幽灵止损设在硬止损更近 0.2% 处，用于手动干预（自动化系统可监控）。

## 五、自动化执行流程

### 5.1 订单类型

- 开仓：限价单（建议挂单，降低手续费）。
- 止损：止损市价单。
- 止盈：限价单（分批）。
- 移动止损：程序动态调整（吊灯止损）。

### 5.2 订单参数计算（示例：BTC 多头 S 级）

```python
# 输入参数
entry_price = 60000
atr = 800
stop_loss = entry_price - 1.5 * atr       # 58800
tp1 = entry_price + 4.0 * atr             # 63200
tp2 = entry_price + 6.0 * atr             # 64800
risk_amount = 10  # 固定风险
stop_percent = (entry_price - stop_loss) / entry_price
base_notional = risk_amount / stop_percent
actual_notional = base_notional * 0.5      # S 级仓位系数 50%
quantity = actual_notional / entry_price
leverage = 5
margin = actual_notional / leverage
```

### 5.3 吊灯止损实现

- 维护最高价（多头）或最低价（空头）。
- 当价格从最高点回撤 ≥ 1.5×ATR 时，提交市价平仓单。
- 启动条件：价格已突破 TP1（或自定义 2.5×ATR）。
