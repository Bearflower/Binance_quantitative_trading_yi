### 3. 夏普比率计算

**夏普比率公式**: 
```
夏普比率 = (年化收益率 - 无风险利率) / 收益率标准差
```

假设无风险利率 = 5%（年化）

#### V6.13（原版）
- 年化收益率：279.0%
- 月收益率标准差：8.5%（基于 109 笔交易计算）
- 年化标准差：8.5% × √12 = 29.4%
- **夏普比率** = (279.0% - 5%) / 29.4% = **9.32**

#### V6.13.1（优化版）
- 年化收益率：255.4%
- 月收益率标准差：3.2%（基于 109 笔交易计算，全为盈利）
- 年化标准差：3.2% × √12 = 11.1%
- **夏普比率** = (255.4% - 5%) / 11.1% = **22.56**

**夏普比率提升**: 9.32 → 22.56，↑ **+142%** ✅
