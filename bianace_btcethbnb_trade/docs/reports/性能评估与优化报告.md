## 一、Redis vs cachetools 评估报告

### 1.1 详细对比分析

| 对比维度 | cachetools (当前方案) | Redis (替代方案) | 评估结论 |
|---------|---------------------|-----------------|---------|
| **性能** | 内存直接访问，纳秒级延迟 | 网络IO开销，毫秒级延迟 | cachetools 更优 |
| **吞吐量** | 单进程内极高 | 受网络带宽限制 | cachetools 更优 |
| **TTL支持** | 原生支持TTLCache | 原生支持EXPIRE | 相当 |
| **LRU淘汰** | 原生支持LRUCache | 需配置maxmemory-policy | 相当 |
| **持久化** | 进程重启数据丢失 | 支持RDB/AOF持久化 | Redis 更优 |
| **分布式** | 单进程，无法共享 | 多进程/多服务共享 | Redis 更优 |
| **高可用** | 进程崩溃数据丢失 | 支持主从复制、哨兵、集群 | Redis 更优 |
| **运维成本** | 无需额外服务 | 需要部署和维护Redis服务 | cachetools 更优 |
| **内存占用** | 共享进程内存 | 独立进程内存 | cachetools 更优 |
| **部署复杂度** | 零依赖 | 需要Redis服务 | cachetools 更优 |
| **数据结构** | 基础KV | 丰富数据结构（List/Hash/Set/ZSet） | Redis 更优 |
| **监控能力** | 需自行实现 | 内置INFO命令监控 | Redis 更优 |

### 1.3 推荐方案

**结论：继续使用 cachetools（方案A）**

#### 1.3.1 推荐理由

1. **架构匹配度高**
   - 当前系统为单进程应用，无多进程共享缓存需求
   - cachetools 的单进程内存缓存完全满足需求

2. **性能优势明显**
   - 内存直接访问，延迟在纳秒级别
   - Redis 网络IO延迟在毫秒级别（即使本地回环）
   - 对于高频缓存访问场景，cachetools 性能更优

3. **运维成本最低**
   - 无需部署和维护额外的 Redis 服务
   - 减少系统复杂度和故障点
   - 降低资源消耗（内存、CPU）

4. **当前实现完善**
   - 已实现 TTL 过期策略
   - 已实现 LRU 淘汰策略
   - 已实现缓存统计和监控
   - 已实现线程安全

5. **业务场景适配**
   - 交易对数量少（3个），缓存数据量小
   - 定时任务每小时执行，缓存命中率要求不高
   - 进程重启后重新获取数据成本可接受

#### 1.3.2 Redis 适用场景（不适用于当前项目）

Redis 更适合以下场景：
- 多进程/多服务共享缓存
- 需要缓存持久化
- 分布式部署
- 高可用性要求
- 大规模数据处理
- 复杂数据结构需求

```python
import os
from concurrent.futures import ThreadPoolExecutor
from typing import Optional
import logging

logger = logging.getLogger(__name__)


class DynamicThreadPool:
    """动态线程池管理器"""
    
    def __init__(
        self,
        min_workers: int = 2,
        max_workers: Optional[int] = None,
        queue_size: int = 100
    ):
        """
        初始化动态线程池
        
        Args:
            min_workers: 最小线程数
            max_workers: 最大线程数（None表示自动根据CPU核心数计算）
            queue_size: 任务队列大小
        """
        self.min_workers = min_workers
        self.max_workers = max_workers or self._calculate_max_workers()
        self.queue_size = queue_size
        
        # 创建线程池
        self.executor = ThreadPoolExecutor(
            max_workers=self.max_workers,
            thread_name_prefix="fetcher"
        )
        
        logger.info(
            f"动态线程池初始化：min={min_workers}, "
            f"max={self.max_workers}, queue={queue_size}"
        )
    
    def _calculate_max_workers(self) -> int:
        """根据CPU核心数计算最大线程数"""
        cpu_count = os.cpu_count() or 4
        # IO密集型任务，线程数可以是CPU核心数的2-4倍
        return min(cpu_count * 4, 20)  # 最大不超过20
    
    def submit(self, fn, *args, **kwargs):
        """提交任务"""
        return self.executor.submit(fn, *args, **kwargs)
    
    def shutdown(self, wait: bool = True):
        """关闭线程池"""
        self.executor.shutdown(wait=wait)
```

#### 2.2.2 请求限流机制

```python
import time
from threading import Lock
from collections import deque
from typing import Optional
import logging

logger = logging.getLogger(__name__)


class RateLimiter:
    """滑动窗口限流器"""
    
    def __init__(
        self,
        max_requests: int = 100,
        window_seconds: float = 1.0
    ):
        """
        初始化限流器
        
        Args:
            max_requests: 时间窗口内最大请求数
            window_seconds: 时间窗口大小（秒）
        """
        self.max_requests = max_requests
        self.window_seconds = window_seconds
        self.requests = deque()
        self.lock = Lock()
        
        logger.info(
            f"限流器初始化：{max_requests}请求/{window_seconds}秒"
        )
    
    def acquire(self) -> bool:
        """
        尝试获取请求许可
        
        Returns:
            是否允许请求
        """
        with self.lock:
            now = time.time()
            
            # 移除过期的请求记录
            while self.requests and self.requests[0] <= now - self.window_seconds:
                self.requests.popleft()
            
            # 检查是否超过限制
            if len(self.requests) >= self.max_requests:
                return False
            
            # 记录本次请求
            self.requests.append(now)
            return True
    
    def wait_and_acquire(self, timeout: Optional[float] = None) -> bool:
        """
        等待并获取请求许可
        
        Args:
            timeout: 最大等待时间（秒）
        
        Returns:
            是否成功获取许可
        """
        start_time = time.time()
        
        while True:
            if self.acquire():
                return True
            
            # 检查是否超时
            if timeout and (time.time() - start_time) > timeout:
                return False
            
            # 等待一段时间后重试
            time.sleep(0.01)


class TokenBucketLimiter:
    """令牌桶限流器（更适合突发流量）"""
    
    def __init__(
        self,
        rate: float = 10.0,  # 令牌生成速率（个/秒）
        capacity: int = 20   # 桶容量
    ):
        """
        初始化令牌桶
        
        Args:
            rate: 令牌生成速率
            capacity: 桶容量
        """
        self.rate = rate
        self.capacity = capacity
        self.tokens = capacity
        self.last_time = time.time()
        self.lock = Lock()
        
        logger.info(f"令牌桶初始化：rate={rate}/秒, capacity={capacity}")
    
    def acquire(self, tokens: int = 1) -> bool:
        """
        尝试获取令牌
        
        Args:
            tokens: 需要的令牌数
        
        Returns:
            是否成功获取
        """
        with self.lock:
            now = time.time()
            
            # 补充令牌
            elapsed = now - self.last_time
            self.tokens = min(
                self.capacity,
                self.tokens + elapsed * self.rate
            )
            self.last_time = now
            
            # 检查令牌是否足够
            if self.tokens >= tokens:
                self.tokens -= tokens
                return True
            
            return False
    
    def wait_and_acquire(self, tokens: int = 1, timeout: Optional[float] = None) -> bool:
        """等待并获取令牌"""
        start_time = time.time()
        
        while True:
            if self.acquire(tokens):
                return True
            
            if timeout and (time.time() - start_time) > timeout:
                return False
            
            time.sleep(0.01)
```

#### 2.2.3 错误重试策略

```python
import time
import random
from typing import Callable, Optional, Type, Tuple
from functools import wraps
import logging

logger = logging.getLogger(__name__)


def retry_with_backoff(
    max_retries: int = 3,
    base_delay: float = 1.0,
    max_delay: float = 30.0,
    exponential_base: float = 2.0,
    jitter: bool = True,
    exceptions: Tuple[Type[Exception], ...] = (Exception,)
):
    """
    指数退避重试装饰器
    
    Args:
        max_retries: 最大重试次数
        base_delay: 基础延迟时间（秒）
        max_delay: 最大延迟时间（秒）
        exponential_base: 指数基数
        jitter: 是否添加随机抖动
        exceptions: 需要重试的异常类型
    """
    def decorator(func: Callable):
        @wraps(func)
        def wrapper(*args, **kwargs):
            last_exception = None
            
            for attempt in range(max_retries + 1):
                try:
                    return func(*args, **kwargs)
                except exceptions as e:
                    last_exception = e
                    
                    if attempt == max_retries:
                        logger.error(
                            f"函数 {func.__name__} 重试{max_retries}次后仍然失败: {e}"
                        )
                        raise
                    
                    # 计算延迟时间
                    delay = min(
                        base_delay * (exponential_base ** attempt),
                        max_delay
                    )
                    
                    # 添加随机抖动
                    if jitter:
                        delay = delay * (0.5 + random.random())
                    
                    logger.warning(
                        f"函数 {func.__name__} 第{attempt + 1}次失败，"
                        f"{delay:.2f}秒后重试: {e}"
                    )
                    
                    time.sleep(delay)
            
            raise last_exception
        
        return wrapper
    
    return decorator


# 使用示例
@retry_with_backoff(max_retries=3, base_delay=1.0, exceptions=(ConnectionError, TimeoutError))
def fetch_kline_data(symbol: str, interval: str):
    """获取K线数据（带重试）"""
    # API调用逻辑
    pass
```

#### 2.2.4 超时控制

```python
import signal
from contextlib import contextmanager
from typing import Optional
import logging

logger = logging.getLogger(__name__)


class TimeoutError(Exception):
    """超时异常"""
    pass


@contextmanager
def timeout_context(seconds: Optional[float] = None):
    """
    超时上下文管理器
    
    Args:
        seconds: 超时时间（秒），None表示不超时
    
    Example:
        with timeout_context(10):
            # 10秒内必须完成
            long_running_operation()
    """
    if seconds is None:
        yield
        return
    
    def timeout_handler(signum, frame):
        raise TimeoutError(f"操作超时（{seconds}秒）")
    
    # 设置信号处理器
    original_handler = signal.signal(signal.SIGALRM, timeout_handler)
    signal.setitimer(signal.ITIMER_REAL, seconds)
    
    try:
        yield
    finally:
        # 恢复原始信号处理器
        signal.setitimer(signal.ITIMER_REAL, 0)
        signal.signal(signal.SIGALRM, original_handler)


# 使用concurrent.futures的超时控制
from concurrent.futures import ThreadPoolExecutor, TimeoutError as FuturesTimeoutError


def run_with_timeout(func, args=(), kwargs=None, timeout: Optional[float] = None):
    """
    带超时控制的函数执行
    
    Args:
        func: 要执行的函数
        args: 位置参数
        kwargs: 关键字参数
        timeout: 超时时间（秒）
    
    Returns:
        函数返回值
    
    Raises:
        TimeoutError: 执行超时
    """
    if kwargs is None:
        kwargs = {}
    
    if timeout is None:
        return func(*args, **kwargs)
    
    with ThreadPoolExecutor(max_workers=1) as executor:
        future = executor.submit(func, *args, **kwargs)
        try:
            return future.result(timeout=timeout)
        except FuturesTimeoutError:
            future.cancel()
            raise TimeoutError(f"函数 {func.__name__} 执行超时（{timeout}秒）")
```

### 2.3 asyncio vs ThreadPoolExecutor 评估

#### 2.3.1 对比分析

| 维度 | ThreadPoolExecutor | asyncio |
|-----|-------------------|---------|
| **实现复杂度** | 简单，同步代码风格 | 需要异步改造 |
| **性能** | 线程切换开销 | 协程切换开销极低 |
| **并发数** | 受线程数限制 | 可支持数千协程 |
| **调试难度** | 较低 | 较高 |
| **库兼容性** | 所有库兼容 | 需要异步库支持 |
| **内存占用** | 每线程约8MB | 每协程约KB级 |
| **适用场景** | IO密集型+CPU密集型 | 纯IO密集型 |

#### 2.3.2 性能提升预估

| 场景 | ThreadPoolExecutor | asyncio | 提升 |
|-----|-------------------|---------|-----|
| 3个交易对并发获取 | ~1.5秒 | ~0.8秒 | ~47% |
| 10个交易对并发获取 | ~4秒 | ~1.5秒 | ~62% |
| 50个交易对并发获取 | ~15秒 | ~3秒 | ~80% |

#### 2.3.3 实施建议

**当前建议：继续使用 ThreadPoolExecutor**

理由：
1. 当前交易对数量少（3个），性能差异不明显
2. 现有代码库为同步风格，改造成本较高
3. ThreadPoolExecutor 已满足当前需求

**未来扩展建议：迁移到 asyncio**

条件：
- 交易对数量增加（>10个）
- 需要更高并发性能
- 有充足的重构时间

```python

优化后的数据获取模块

功能：

from decimal import Decimal
from typing import Dict, Any, List, Optional
from concurrent.futures import ThreadPoolExecutor, as_completed
from dataclasses import dataclass
from threading import Lock

from core.data.cache import DataCache
from core.data.indicators import IndicatorCalculator

logger = logging.getLogger(__name__)


@dataclass
class FetchResult:
    """数据获取结果"""
    symbol: str
    success: bool
    data: Optional[Dict[str, Any]] = None
    error: Optional[str] = None
    duration: float = 0.0


class OptimizedMarketDataFetcher:
    """优化的行情数据获取器"""
    
    def __init__(
        self,
        cache_duration_hours: int = 1,
        min_workers: int = 2,
        max_workers: Optional[int] = None,
        rate_limit: int = 50,  # 每秒最大请求数

    ):
        """

            min_workers: 最小线程数
            max_workers: 最大线程数
            rate_limit: 请求限流
            request_timeout: 请求超时

        """

        self.executor = ThreadPoolExecutor(

            rate=rate_limit,
            capacity=rate_limit * 2
        )
        
        # 配置
        self.request_timeout = request_timeout
        self.max_retries = max_retries

        self._stats_lock = Lock()
        self._fetch_count = 0
        self._total_fetch_time = 0.0
        self._success_count = 0
        self._error_count = 0
        
        logger.info(
            f"优化数据获取器初始化：workers={self.max_workers}, "
            f"rate_limit={rate_limit}/s, timeout={request_timeout}s"
        )
    
    def _calculate_max_workers(self) -> int:
        """计算最大线程数"""
        import os
        cpu_count = os.cpu_count() or 4
        return min(cpu_count * 4, 20)
    
    def fetch_market_data(
        self,
        symbols: List[str] = None,
        timeout: Optional[float] = None
    ) -> Dict[str, Dict[str, Any]]:
        """
        获取市场数据（优化版）
        
        Args:
            symbols: 交易对列表
            timeout: 总超时时间
        
        Returns:
            行情数据字典
        """
        if symbols is None:

                    self._fetch_symbol_with_retry,

            for future in as_completed(
                future_to_symbol,
                timeout=timeout or self.request_timeout * len(symbols)
            ):
                symbol = future_to_symbol[future]
                try:
                    result = future.result(timeout=self.request_timeout)
                    results[symbol] = result
                except Exception as e:
                    logger.error(f"获取 {symbol} 数据失败: {e}")
                    results[symbol] = FetchResult(
                        symbol=symbol,
                        success=False,
                        error=str(e)
                    )
            
            # 处理成功的数据
            success_data = {}
            for symbol, result in results.items():
                if result.success and result.data:
                    success_data[symbol] = result.data
            
            # 更新缓存
            if success_data:
                self.cache.set_all(success_data)
            
            # 更新统计
            fetch_time = time.time() - start_time
            with self._stats_lock:
                self._fetch_count += 1
                self._total_fetch_time += fetch_time
                self._success_count += len(success_data)
                self._error_count += len(symbols) - len(success_data)
            
            logger.info(
                f"获取数据完成：成功{len(success_data)}/{len(symbols)}，"
                f"耗时{fetch_time:.2f}秒"
            )
            
            return success_data
            
        except Exception as e:
            logger.error(f"获取市场数据失败: {e}")
            # 返回旧缓存
            if self.cache.get_all():
                logger.warning("使用旧的缓存数据")
                return self.cache.get_all()
            raise
    
    def _fetch_symbol_with_retry(self, symbol: str) -> FetchResult:
        """带重试的单个交易对数据获取"""
        start_time = time.time()
        last_error = None
        
        for attempt in range(self.max_retries):
            try:
                data = self._fetch_symbol_data(symbol)
                return FetchResult(
                    symbol=symbol,
                    success=True,
                    data=data,
                    duration=time.time() - start_time
                )
            except Exception as e:
                last_error = e
                if attempt < self.max_retries - 1:
                    # 指数退避
                    delay = min(2 ** attempt, 10)
                    logger.warning(
                        f"获取 {symbol} 数据失败，{delay}秒后重试: {e}"
                    )
                    time.sleep(delay)
        
        return FetchResult(
            symbol=symbol,
            success=False,
            error=str(last_error),
            duration=time.time() - start_time
        )
    
    def _fetch_symbol_data(self, symbol: str) -> Dict[str, Any]:
        """获取单个交易对数据"""
        # 实现具体的数据获取逻辑
        pass
    
    def get_stats(self) -> Dict[str, Any]:
        """获取性能统计"""
        with self._stats_lock:
            avg_time = (
                self._total_fetch_time / self._fetch_count
                if self._fetch_count > 0 else 0
            )
            return {
                'fetch_count': self._fetch_count,
                'success_count': self._success_count,
                'error_count': self._error_count,
                'total_time': round(self._total_fetch_time, 2),
                'avg_time': round(avg_time, 2),
                'cache_stats': self.cache.get_stats()
            }
    
    def shutdown(self):
        """关闭资源"""
        self.executor.shutdown(wait=True)
```

```python
#!/usr/bin/env python3
"""
性能基准测试脚本

测试各项性能指标并生成报告。

import time
import statistics
from typing import List, Dict, Any
import logging

logger = logging.getLogger(__name__)


class PerformanceBenchmark:
    """性能基准测试"""
    
    def __init__(self):
        self.results = {}
    
    def benchmark_cache(self, iterations: int = 1000) -> Dict[str, Any]:
        """缓存性能测试"""
        from core.data.cache import DataCache
        from decimal import Decimal
        
        cache = DataCache(maxsize=100, ttl_seconds=300)
        
        # 写入测试
        write_times = []
        for i in range(iterations):
            start = time.perf_counter()
            cache.set(f'KEY_{i}', {'value': Decimal(str(i))})
            write_times.append(time.perf_counter() - start)
        
        # 读取测试
        read_times = []
        for i in range(iterations):
            start = time.perf_counter()
            cache.get(f'KEY_{i}')
            read_times.append(time.perf_counter() - start)
        
        return {
            'write_avg_ms': statistics.mean(write_times) * 1000,
            'write_max_ms': max(write_times) * 1000,
            'read_avg_ms': statistics.mean(read_times) * 1000,
            'read_max_ms': max(read_times) * 1000,
            'iterations': iterations
        }
    
    def benchmark_concurrent_fetch(
        self,
        symbols: List[str],
        iterations: int = 10
    ) -> Dict[str, Any]:
        """并发获取性能测试"""
        from core.data.fetcher import MarketDataFetcher
        
        fetch_times = []
        success_count = 0
        
        for i in range(iterations):
            fetcher = MarketDataFetcher(
                cache_duration_hours=0,  # 禁用缓存
                enable_concurrent=True
            )
            
            start = time.perf_counter()
            try:
                data = fetcher.fetch_market_data(symbols)
                if data:
                    success_count += 1
            except Exception as e:
                logger.error(f"第{i}次获取失败: {e}")
            fetch_times.append(time.perf_counter() - start)
        
        return {
            'avg_time_s': statistics.mean(fetch_times),
            'max_time_s': max(fetch_times),
            'min_time_s': min(fetch_times),
            'success_rate': success_count / iterations,
            'iterations': iterations
        }
    
    def generate_report(self) -> str:
        """生成性能报告"""
        report = []
        report.append("=" * 60)
        report.append("性能基准测试报告")
        report.append("=" * 60)
        
        for test_name, result in self.results.items():
            report.append(f"\n{test_name}:")
            for key, value in result.items():
                report.append(f"  - {key}: {value}")
        
        return "\n".join(report)
```

#### 3.2.1 内置监控模块

```python
#!/usr/bin/env python3
"""
性能监控模块

提供实时性能监控和告警功能。
"""

import time
import psutil
import threading
from typing import Dict, Any, Optional, Callable
from dataclasses import dataclass, field
from datetime import datetime
import logging

logger = logging.getLogger(__name__)


@dataclass
class PerformanceMetrics:
    """性能指标数据类"""
    timestamp: datetime
    cpu_percent: float
    memory_mb: float
    thread_count: int
    cache_hit_rate: float
    api_success_rate: float
    avg_response_time: float


class PerformanceMonitor:
    """性能监控器"""
    
    def __init__(
        self,
        check_interval: float = 60.0,
        alert_thresholds: Optional[Dict[str, float]] = None
    ):
        """
        初始化性能监控器
        
        Args:
            check_interval: 检查间隔（秒）
            alert_thresholds: 告警阈值
        """
        self.check_interval = check_interval
        self.alert_thresholds = alert_thresholds or {
            'cpu_percent': 80.0,
            'memory_mb': 500.0,
            'cache_hit_rate': 0.5,
            'api_success_rate': 0.95,
            'avg_response_time': 5.0
        }
        
        self._running = False
        self._monitor_thread: Optional[threading.Thread] = None
        self._metrics_history: list = []
        self._alert_callbacks: list = []
        
        # 统计数据
        self._request_count = 0
        self._error_count = 0
        self._total_response_time = 0.0
    
    def start(self):
        """启动监控"""
        if self._running:
            return
        
        self._running = True
        self._monitor_thread = threading.Thread(
            target=self._monitor_loop,
            daemon=True
        )
        self._monitor_thread.start()
        logger.info("性能监控器已启动")
    
    def stop(self):
        """停止监控"""
        self._running = False
        if self._monitor_thread:
            self._monitor_thread.join(timeout=5)
        logger.info("性能监控器已停止")
    
    def _monitor_loop(self):
        """监控循环"""
        while self._running:
            try:
                metrics = self._collect_metrics()
                self._metrics_history.append(metrics)
                
                # 保留最近100条记录
                if len(self._metrics_history) > 100:
                    self._metrics_history.pop(0)
                
                # 检查告警
                self._check_alerts(metrics)
                
            except Exception as e:
                logger.error(f"监控异常: {e}")
            
            time.sleep(self.check_interval)
    
    def _collect_metrics(self) -> PerformanceMetrics:
        """收集性能指标"""
        process = psutil.Process()
        
        return PerformanceMetrics(
            timestamp=datetime.now(),
            cpu_percent=process.cpu_percent(),
            memory_mb=process.memory_info().rss / 1024 / 1024,
            thread_count=process.num_threads(),
            cache_hit_rate=self._get_cache_hit_rate(),
            api_success_rate=self._get_api_success_rate(),
            avg_response_time=self._get_avg_response_time()
        )
    
    def _get_cache_hit_rate(self) -> float:
        """获取缓存命中率"""
        # 从缓存模块获取
        return 0.0  # 需要实际实现
    
    def _get_api_success_rate(self) -> float:
        """获取API成功率"""
        if self._request_count == 0:
            return 1.0
        return 1.0 - (self._error_count / self._request_count)
    
    def _get_avg_response_time(self) -> float:
        """获取平均响应时间"""
        if self._request_count == 0:
            return 0.0
        return self._total_response_time / self._request_count
    
    def _check_alerts(self, metrics: PerformanceMetrics):
        """检查告警"""
        alerts = []
        
        if metrics.cpu_percent > self.alert_thresholds['cpu_percent']:
            alerts.append(f"CPU使用率过高: {metrics.cpu_percent:.1f}%")
        
        if metrics.memory_mb > self.alert_thresholds['memory_mb']:
            alerts.append(f"内存使用过高: {metrics.memory_mb:.1f}MB")
        
        if metrics.cache_hit_rate < self.alert_thresholds['cache_hit_rate']:
            alerts.append(f"缓存命中率过低: {metrics.cache_hit_rate:.1%}")
        
        if metrics.api_success_rate < self.alert_thresholds['api_success_rate']:
            alerts.append(f"API成功率过低: {metrics.api_success_rate:.1%}")
        
        if metrics.avg_response_time > self.alert_thresholds['avg_response_time']:
            alerts.append(f"响应时间过长: {metrics.avg_response_time:.2f}s")
        
        # 触发告警回调
        if alerts:
            for callback in self._alert_callbacks:
                try:
                    callback(alerts)
                except Exception as e:
                    logger.error(f"告警回调失败: {e}")
    
    def record_request(self, response_time: float, success: bool):
        """记录请求"""
        self._request_count += 1
        self._total_response_time += response_time
        if not success:
            self._error_count += 1
    
    def add_alert_callback(self, callback: Callable[[list], None]):
        """添加告警回调"""
        self._alert_callbacks.append(callback)
    
    def get_current_metrics(self) -> Optional[PerformanceMetrics]:
        """获取当前指标"""
        if self._metrics_history:
            return self._metrics_history[-1]
        return None
    
    def get_metrics_history(self, limit: int = 10) -> list:
        """获取历史指标"""
        return self._metrics_history[-limit:]
```

```python
#!/usr/bin/env python3
"""
性能瓶颈识别工具

自动识别系统性能瓶颈并提供优化建议。

import cProfile
import pstats
import io
from typing import Dict, Any, List
import logging

    """性能瓶颈分析器"""
    
    def __init__(self):
        self.profile_results = {}
    
    def profile_function(self, func, *args, **kwargs) -> Dict[str, Any]:
        """
        分析函数性能
        
        Args:
            func: 要分析的函数
            args, kwargs: 函数参数
        
        Returns:
            性能分析结果
        """

        # 开始分析
        profiler.enable()
        result = func(*args, **kwargs)
        profiler.disable()
        
        # 生成统计
        s = io.StringIO()
        stats = pstats.Stats(profiler, stream=s)
        stats.sort_stats('cumulative')
        stats.print_stats(20)
        
        return {
            'result': result,
            'profile_text': s.getvalue(),
            'total_calls': stats.total_calls,
            'total_time': stats.total_tt
```
