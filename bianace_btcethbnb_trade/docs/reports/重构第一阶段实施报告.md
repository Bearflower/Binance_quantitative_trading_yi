### 2.2 异常处理系统

#### 2.2.1 自定义异常类

**创建文件**: [utils/exceptions.py](file:///Users/yl/vscode/bianace_btcethbnb_trade/utils/exceptions.py)

**异常层次结构**:
```
TradingSystemError (基础异常)
├── ConfigurationError (配置错误)
│   ├── ConfigFileNotFoundError
│   └── ConfigValidationError
├── DataError (数据错误)
│   ├── DataFetchError
│   ├── DataValidationError
│   └── InsufficientDataError
├── TradingError (交易错误)
│   ├── OrderExecutionError
│   ├── InsufficientBalanceError
│   ├── RiskLimitExceededError
│   └── SignalNotFoundError
├── APIError (API 错误)
│   ├── APIConnectionError
│   ├── APIResponseError
│   ├── APIRateLimitError
│   └── APIAuthenticationError
├── NotificationError (通知错误)
│   └── LarkNotificationError
└── DatabaseError (数据库错误)
    ├── DatabaseConnectionError
    └── DatabaseQueryError
```

**使用示例**:
```python
from utils.exceptions import InsufficientBalanceError

# 抛出异常
raise InsufficientBalanceError(
    required=100.0,
    available=50.0,
    currency="USDT"
)

# 异常信息
# [TRADING_ERROR_USDT] 余额不足：需要 100.0 USDT，可用 50.0 USDT
```

#### 2.2.2 统一错误处理器

**使用示例**:
```python

    # 可能抛出异常的代码
    pass
except Exception as e:
    error_info = handle_error(e, context={'module': 'test'}, notify=True)

# 方式 2: 装饰器
@error_handler(notify_on_error=True, reraise=False, default_return=None)
def some_function():
    # 可能抛出异常的代码
    pass
```
