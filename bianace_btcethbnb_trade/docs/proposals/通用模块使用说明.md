# BTC/ETH 交易系统 - 通用模块使用说明

## 📦 已提取的通用模块

### 1. 通知服务模块

**原位置**: `utils/lark_notifier.py`  
**通用服务**: `common_service/notification_service`  
**改造后**: `utils/lark_notifier_v2.py` (已替换为 v2 版本)

**调用方式**:
```python
from utils.lark_notifier_v2 import LarkNotifier

notifier = LarkNotifier()

# 发送通知
notifier.send_notification(
    message="分析任务完成",
    level="info"  # info, warning, error
)

# 或使用便捷函数
from utils.lark_notifier_v2 import notify_completion
notify_completion("BTCUSDT", "/path/to/report.md", "/path/to/screenshot.png")
```

**API 端点**: `http://43.156.242.184:8766/api/v1/send`  
**项目标识**: `btc_eth`

**优势**:
- ✅ 统一管理飞书 webhook
- ✅ 支持异步发送（消息队列）
- ✅ 频率限制防止轰炸
- ✅ 统一日志记录
- ✅ 向后兼容，接口不变

### 2. K 线数据服务（待提取）

**当前**: 直接调用币安 API  
**目标**: 使用通用 K 线服务

**调用方式（改造后）**:
```python
import requests

KLINE_SERVICE_URL = "http://43.156.242.184:8765/api/v1"

def get_klines(symbol, interval, limit=100):
    response = requests.get(
        f"{KLINE_SERVICE_URL}/klines",
        params={"symbol": symbol, "interval": interval, "limit": limit}
    )
    result = response.json()
    return result['data']['klines'] if result.get('code') == 0 else []
```
