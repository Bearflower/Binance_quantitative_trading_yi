## 🆕 阶段 3.3：应急处理模块（新增完成）

### 文件：`services/emergency_handler.py`

#### 实现 traderule.txt 第七章规则

**1. 极端行情处理**
- ✅ 检查价格瞬间反向波动达 5%
- ✅ 立即市价平仓 50% 的仓位（优先平仓亏损最大的品种）
- ✅ 剩余仓位止损收紧至 1.5%
- ✅ 取消所有未成交挂单
- ✅ 禁止逆势开仓、锁仓

**2. 连续亏损处理**
- ✅ 检查连续 2 笔交易亏损
- ✅ 停止交易 3 天
- ✅ 发送飞书通知
- ✅ 记录恢复交易时间

**3. 单周亏损限制**
- ✅ 检查单周亏损是否超过 15%（75U）
- ✅ 停止交易 3 天
- ✅ 恢复后首周杠杆 ≤ 3 倍
- ✅ 发送飞书通知

**4. 应急通知机制**
- ✅ 飞书推送（极端行情、连续亏损、单周亏损）
- ✅ 详细的应急状态报告
- ✅ 交易暂停状态管理

#### 使用示例

```python
from services.emergency_handler import (
    get_emergency_handler,
    check_extreme_price_drop,
    can_trade,
    get_emergency_status
)
from decimal import Decimal

handler = get_emergency_handler()

# 1. 检查极端行情
current_price = Decimal('90000')
entry_price = Decimal('95000')
direction = 1  # 多

if check_extreme_price_drop(current_price, entry_price, direction):
    print("🚨 极端行情触发！")
    
    # 处理极端行情
    positions = [...]  # 当前持仓
    result = handler.handle_extreme_market(positions)
    print(f"已平仓 {result['closed_positions']} 个")

# 2. 检查连续亏损
recent_trades = [
    {'net_pnl': -10},
    {'net_pnl': -12},
    {'net_pnl': 8},
]

triggered, count = handler.check_consecutive_losses(recent_trades)
if triggered:
    handler.handle_consecutive_losses(count)
    print(f"⚠️ 连续亏损 {count} 笔，暂停交易 3 天")

# 3. 检查是否允许交易
allowed, reason = can_trade()
if not allowed:
    print(f"交易暂停：{reason}")

# 4. 获取应急状态
status = get_emergency_status()
print(f"交易暂停：{status['trading_paused']}")
print(f"暂停原因：{status['pause_reason']}")
```
