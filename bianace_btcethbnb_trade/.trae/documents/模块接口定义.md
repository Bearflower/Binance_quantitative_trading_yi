### 1.3 策略参数管理 (StrategyParams)

**文件**: `config/strategy_params.py`

**职责**: 管理可调参数，支持热加载

**公开方法**:
```python
class StrategyParams:
    def get(key_path: str, default: Any = None) -> Any
    """获取参数值（支持点分隔路径）"""
    
    def set(key_path: str, value: Any)
    """设置参数值"""
    
    def validate() -> List[str]
    """验证参数有效性"""
    
    def reload()
    """重新加载参数（热加载）"""
    
    def save_to_file(config_file: str = None)
    """保存参数到文件"""
    
    def load_from_file(config_file: str = None)
    """从配置文件加载"""
```

**使用示例**:
```python
params = get_params()

# 获取参数
total_capital = params.get('account.total_capital')  # Decimal('500')
max_leverage = params.get('signal_grades.S.max_leverage')  # 5

# 设置参数（热加载）
params.set('account.single_position_margin', Decimal('50'))

# 验证参数
errors = params.validate()
if errors:
    for error in errors:
        print(f"参数错误：{error}")
```

## 5. 模块间依赖关系

```
scheduler.py (主调度器)
    ↓
data_fetcher.py → signal_detector.py → position_calculator.py → risk_manager.py
                                              ↓
                                    order_generator.py → trade_executor.py
                                              ↓
                                    trade_recorder.py → database.py
                                              ↓
                                    performance_reporter.py → lark_notifier.py
```

## 6. 数据流示例

### 6.1 正常交易流程
```
1. scheduler.py 每小时触发
2. data_fetcher.fetch_market_data() 获取行情
3. signal_detector.detect_signals() 检测信号
4. position_calculator.calculate_position_size() 计算仓位
5. risk_manager.validate_risk() 风险验证
6. order_generator.generate_orders() 生成订单
7. trade_executor.execute() 执行交易
8. trade_recorder.record() 记录交易
```

### 6.2 报告生成流程
```
1. scheduler.py 每周日触发
2. performance_reporter.generate_weekly_report() 生成报告
3. 从 database 获取交易数据
4. 计算绩效指标（胜率、盈亏比等）
5. lark_notifier.send() 发送飞书通知
```
