## 组件重用评估

### ✅ 完全保留的组件（无需修改）
1. **utils/binance_trade_api.py** - 币安 API 封装完善，支持 PM 账户
2. **models/database.py** - PostgreSQL 数据库管理完善
3. **utils/rate_limiter.py** - 限流器
4. **utils/lark_notifier.py** - 飞书通知（可能需要小优化）
5. **config/settings.py** - 配置管理（需要添加新参数）

### ⚠️ 需要小修改的组件
1. **utils/deepseek_client.py** - 改为可选第二意见，移除强制调用
2. **services/close_detector.py** - 平仓检测逻辑完善，无需大改
3. **utils/json_extractor.py** - 可能需要支持新格式

### 🔄 需要中等修改的组件
1. **services/trade_statistics.py** - 需要整合新报告格式（9.2 + 10.2）
2. **services/weekly_report.py** - 需要整合 9.2 和 10.2，优化格式
3. **utils/binance_api.py** - 可能需要优化数据获取频率（改为每小时）

### ❌ 需要重构的组件
1. **services/auto_executor.py** - 需要集成新规则引擎，不再依赖 AI 报告
2. **scheduler.py** - 需要改为每小时调度，移除 DeepSeek 强制依赖
3. **services/trade_executor.py** - 可能需要适配新的信号格式
