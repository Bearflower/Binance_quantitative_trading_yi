### 2. 错误代码"4"的含义 🔍

**分析结果**：这个"4"不是错误代码，而是**异常消息的内容**（`str(e)` 的结果）

**可能的异常类型**：
1. **IndexError** - 访问不存在的列表索引（如 `list[4]` 但列表长度不足）
2. **KeyError** - 访问不存在的字典键
3. **ValueError** - 值错误
4. **除零错误** - Decimal 除法可能出现

**最可能的原因**：
```python
# 第 230 行的除法运算
'price_change_24h': Decimal(str(data.get('priceChangePercent', '0'))) / Decimal('100'),
```

如果 `data.get('priceChangePercent', '0')` 返回的是 `None` 而不是字符串'0'，那么：
```python
Decimal(str(None)) / Decimal('100')  # Decimal('None') / Decimal('100')
```

这会抛出 ValueError 异常，但消息不会是"4"。

**另一种可能**：
```python
# 第 178 行 - 访问列表最后一个元素
'close': Decimal(str(tf_data.get('prices', [])[-1])) if tf_data.get('prices') else None,
```

如果 `tf_data.get('prices')` 返回一个长度不足的空列表，访问 `[-1]` 会抛出 IndexError。

但这个消息应该是"list index out of range"，而不是"4"。

### 3. 日志截断问题 🔍

**奇怪的现象**：按照代码第 237-242 行，应该会输出详细的 traceback 和 data 信息，但日志中没有。

**可能的原因**：
1. **Docker 日志截断** - Docker 默认会截断长日志行
2. **日志级别问题** - 某些日志可能被过滤
3. **异常类型特殊** - 某些异常可能阻止了后续日志的输出
