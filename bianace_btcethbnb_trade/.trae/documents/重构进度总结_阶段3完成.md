## 使用示例

### 1. 启动调度器（每小时自动执行）
```bash
python scheduler_new.py
```

### 2. 立即执行一次分析（不带交易）
```bash
python scheduler_new.py --dry-run
```

### 3. 立即执行一次分析（带交易）
```bash
python scheduler_new.py --auto-trade
```

### 4. 编程方式使用
```python
from scheduler_new import RuleEngineScheduler

# 创建调度器实例（不带自动交易）
scheduler = RuleEngineScheduler(enable_auto_trade=False)

# 执行一次分析
result = scheduler.run_analysis()

print(f"检测到 {len(result['signals'])} 个信号")
for signal in result['signals']:
    print(f"  {signal['币种']} {signal['开仓方向']} "
          f"等级:{signal['信号等级']}")
```
