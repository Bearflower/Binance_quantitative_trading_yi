#### 2.2 仓位计算模块（100% 完成）
- ✅ 解析 traderule.txt 第四章公式
- ✅ 实现名义价值计算：`名义价值 = 风险金额 / 止损百分比`
- ✅ 实现合约数量计算：`合约数量 = 名义价值 / 开仓价格`
- ✅ 实现保证金计算：`保证金 = 名义价值 / 杠杆`
- ✅ 实现仓位限制检查（单品种/总名义价值）

**核心方法**:
```python
PositionCalculator.calculate_position()
├── _calculate_stop_loss_percentage()  # 计算止损百分比
├── _validate_stop_loss_range()        # 验证止损范围
├── check_total_margin_usage()         # 检查总保证金使用
├── check_total_notional_value()       # 检查总名义价值
└── get_position_summary()             # 生成仓位摘要
```

**计算示例**:
```
输入:
  开仓价：95000U
  止损价：93000U
  方向：多
  信号等级：A

计算过程:
  止损百分比 = (95000 - 93000) / 95000 = 2.11%
  名义价值 = 10U / 2.11% = 474.41U
  杠杆 = 4 倍（A 级信号上限）
  保证金 = 474.41U / 4 = 118.60U
  → 调整为 30U（单仓上限）
  最终名义价值 = 30U × 4 = 120U
  合约数量 = 120U / 95000 = 0.00126 BTC

输出:
  名义价值：120U
  合约数量：0.00126 BTC
  保证金：30U
  杠杆：4x
  风险占比：2%
```

## 技术亮点

### 1. 参数热加载
无需重启系统即可调整策略参数：
```python
from config.strategy_params import get_params, reload_params

params = get_params()

# 调整单仓保证金
params.set('account.single_position_margin', Decimal('50'))

# 验证参数有效性
errors = params.validate()
if not errors:
    print("参数调整成功")
```

### 2. 信号检测自动化

for signal in signals:
