### 3. 精确仓位计算 ✅
**文件**: `core/position_calculator.py`

**实现 traderule.txt 第四章公式**:
- ✅ 名义价值计算：`名义价值 = 风险金额 / 止损百分比`
- ✅ 合约数量计算：`合约数量 = 名义价值 / 开仓价格`
- ✅ 保证金计算：`保证金 = 名义价值 / 杠杆`
- ✅ 仓位限制检查（单品种/总名义价值）

**使用示例**:
```python
from core import calculate_position
from decimal import Decimal

position = calculate_position(
    symbol='BTCUSDT',
    entry_price=Decimal('95000'),
    stop_loss_price=Decimal('93000'),
    direction=1,  # 多
    signal_grade='A'
)

print(f"名义价值：{position['notional_value']:.2f}U")
print(f"保证金：{position['margin']:.2f}U")
print(f"风险占比：{position['risk_ratio']:.1%}")
```

    entry_price=Decimal('95000'),

    stop_loss_pct=Decimal('0.04')

    entry_price=Decimal('95000'),
