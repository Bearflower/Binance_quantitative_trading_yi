## 🎯 核心组件说明

### 1. 指标收集器（MetricsCollector）

**功能特性**：
- ✅ 系统指标：CPU、内存、磁盘、网络连接数
- ✅ 应用指标：API调用成功率、响应时间、错误率、P95响应时间
- ✅ 业务指标：交易成功率、胜率、盈亏、资金使用率、持仓时间
- ✅ 指标历史记录：支持最多1000条历史记录
- ✅ 实时统计：API请求和交易的实时统计

**关键方法**：
```python
# 收集系统指标
collect_system_metrics() -> Dict[str, Any]

# 记录API请求
record_api_request(endpoint, success, response_time, error)

# 记录交易
record_trade(symbol, success, pnl)

# 收集所有指标
collect_all_metrics(account_info, positions) -> Dict[str, Any]

# 获取指标摘要
get_metrics_summary() -> Dict[str, Any]
```

### 2. 告警管理器（AlertManager）

**功能特性**：
- ✅ 灵活的告警规则：支持自定义规则和阈值
- ✅ 多级告警：INFO、WARNING、CRITICAL、EMERGENCY
- ✅ 飞书通知：集成飞书通知服务
- ✅ 告警抑制：避免重复告警
- ✅ 告警历史：记录所有告警事件
- ✅ 告警统计：统计告警频率和分布

**预置告警规则**：
1. **系统告警**（3条）
   - CPU使用率 > 80%
   - 内存使用率 > 80%
   - 磁盘使用率 > 90%

2. **应用告警**（3条）
   - API成功率 < 95%
   - 响应时间 > 5秒
   - 错误率 > 5%

3. **业务告警**（3条）
   - 交易成功率 < 90%
   - 连续亏损 > 5笔
   - 资金使用率 > 80%

**关键方法**：
```python
# 检查指标并触发告警
check_and_alert(metrics) -> List[Dict]

# 发送自定义告警
send_custom_alert(title, message, level)

# 获取告警历史
get_alert_history(limit, level, rule_name) -> List[Dict]

# 抑制告警
suppress_alert(rule_name, duration_minutes)
```

### 3. 健康检查器（HealthChecker）

**功能特性**：
- ✅ 系统健康检查：CPU、内存、磁盘
- ✅ 数据库连接检查：PostgreSQL连接状态
- ✅ 服务依赖检查：通知服务、K线服务、币安API
- ✅ 健康报告：生成详细的健康报告
- ✅ 快速检查：仅检查关键服务

**健康状态**：
- `healthy`：健康
- `degraded`：降级
- `unhealthy`：不健康
- `unknown`：未知

**关键方法**：
```python

check_health() -> Dict[str, Any]

# 快速健康检查
quick_health_check() -> Dict[str, Any]

# 获取健康报告
get_health_report() -> str

# 检查是否健康
is_healthy() -> bool
```

## 🔗 集成示例

### 与调度器集成

```python
from monitoring import MetricsCollector, AlertManager, HealthChecker

class TradingScheduler:
    def __init__(self):
        self.metrics_collector = MetricsCollector()
        self.alert_manager = AlertManager()
        self.health_checker = HealthChecker()
    
    def execute_with_monitoring(self, task_func):
        """带监控的任务执行"""
        start_time = time.time()
        
        try:
            result = task_func()
            
            self.metrics_collector.record_api_request(
                endpoint=task_func.__name__,
                success=True,
                response_time=time.time() - start_time
            )
            
            return result
            
        except Exception as e:
            self.metrics_collector.record_api_request(
                endpoint=task_func.__name__,
                success=False,
                response_time=time.time() - start_time,
                error=str(e)
            )
            
            self.alert_manager.send_custom_alert(
                title=f"任务失败: {task_func.__name__}",
                message=str(e),
                level=AlertLevel.ERROR
            )
            
            raise
    
    def run_monitoring(self):
        """定期运行监控"""
        # 收集指标
        metrics = self.metrics_collector.collect_all_metrics()
        
        # 检查告警
        alerts = self.alert_manager.check_and_alert(metrics)
        
        # 健康检查
        if not self.health_checker.is_healthy():
            self.alert_manager.send_custom_alert(
                title="系统不健康",
                message="请立即检查系统状态",
                level=AlertLevel.CRITICAL
            )
        
        return metrics, alerts
```
