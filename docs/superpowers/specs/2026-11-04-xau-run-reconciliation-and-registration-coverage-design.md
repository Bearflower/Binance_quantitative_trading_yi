# XAU 跨 Run 评估与注册覆盖设计

## 目标

仅在本地、只读地汇总 XAU 影子决策事件；保留物理 run 边界，对等价配置链按 `profile_id + symbol + scheduled_at` 去重，显式列出缺口与冲突。修正 XAUUSDT 注册续期覆盖计划，确保校准版观察期至 2026-12-23 09:00 UTC。

## 边界

- 不修改在线采集、已有事件或生产交易表；不回填未生成的决策。
- 不在服务器回放；不自动续期、部署或下单。
- 单 run 导出接口保持兼容。新增本地多 run 汇总入口和审计清单。
- 本地回放器须识别 `xau_calibrated`，同时保持原版/激进版既有 CLI 与报告行为兼容。

## 汇总规则

输入为显式指定的多个单 run 导出文件及 manifest，并提供冻结的校准 YAML、校准 manifest 与原始 1h 快照。先验证每个 run 的实例、标的、profile、配置哈希和 300 USDT 虚拟权益；用 YAML 中的哈希校验校准 manifest，并重算原始快照 SHA-256。不同配置链不得混合。

对相同小时的事件，以 `profile_id + symbol + scheduled_at` 为键；比较时仅忽略物理 `run_id`、实际 `evaluated_at` 和构建版本 `git_commit`，其他决策字段必须规范化后一致，才可保留最早评估的一条并记录全部来源 run；内容不一致、manifest 不匹配或输入缺失时失败关闭。按观察窗口生成逐小时覆盖清单；缺口标记为 missing，不能解释为 no_signal。结果记录输入文件 SHA-256、去重数、缺口数和物理 run 边界；用于后续本地回放的事件顺序确定。

## 校准版回放

本地回放器增加校准版 profile 配置输入，并按 run manifest 中声明的 profile 构造独立虚拟状态；不得将校准版伪装成原版以复用旧入口。报告增加校准版指标和准入检查，保留原版/激进版既有字段。候选事件不等于已结交易；只有 1m 快照、资金费、交易规则、决策覆盖和输入哈希均可验证时才允许作出准入判断。历史四小时缺口在报告中保持 `insufficient_data`，不能因回放有盈利而自动判通过。

## 注册覆盖

续期使用现有 `/register` 接口且必须人工授权。每次续期后重新读取 `expires_at`；只要不足以覆盖 2026-12-23 09:00 UTC，巡检继续提示后续续期。当前 2026-11-19 到期，单次 30 天续期无法覆盖校准版终点。提醒不得假定一次续期足够。

## 验收

测试覆盖多 run 无重复、相同重复、冲突重复、配置不等价、run 缺失、历史四小时缺口及零候选；校准版回放能独立产出交易与准入指标，原版/激进版回归不变；有决策缺口时准入强制 `insufficient_data`。本地历史样本复核 2026-11-02 04:00–07:00 UTC 为缺口，六个重复小时只计一次。线上三 profile 继续只读运行且不触碰交易表。
