# 缩量试跑剩余证据工程设计

日期：2026-11-18。适用策略：`hrs`、`btc_eth_aggressive`。本设计继承 11 月 10 日只读评估契约；所有缺证结果继续为 `BLOCKED_DATA`，不触发续期、提额、分配或下单。

## 1. 信号到保护的成交漏斗

每个实盘信号以 `(account_id,strategy_id,signal_id,policy_revision,decision_at)` 为稳定键。入口必须在下单前写不可变的风险意图，含 clientOrderId、交易方向、预定数量和配置摘要。交易所签名订单观察给出实际 orderId、状态和成交量；逐笔 userTrades 按账户、币种、orderId、tradeId 归并，要求成交数量与订单返回一致，覆盖游标跨整个决策窗口。保护单须有独立的 algoId、方向、reduceOnly/closePosition、数量和有效时段，能覆盖实际剩余仓位；其状态应以签名查询和成交核对，而非策略日志推断。

漏斗每层分别输出 `observed / verified / unknown / rejected / partial` 数量。取消信号保留拒绝原因；无订单证明必须有交易所终态或经审计的全入口协议窗口，不能用数据库没有记录作为无单证明。HRS 影子来源和激进版普通信号独立统计。某层缺身份、重复、冲突或游标缺页时，只返回可证实的正样本数量及缺口，完整率为未知。

现有代码审计：HRS 预留 `geometry.signal_id` 已写入信号主键；激进版 `prepare_aggressive_entry` 以 `signal_id` 或时间戳构造预留 clientOrderId，但 `entry_geometry` 仅持久化方向、止损、目标、杠杆和等级，未存稳定信号主键。激进版必须先补这条身份链并验证重试保持相同身份，才能将其漏斗标为完整。

验收：固定样本覆盖无单、拒单、部分成交、重复/乱序、重启、跨策略同币种、旧单无法查询、保护单被撤及账号身份冲突；真实窗口中所有策略入口均受捕获触发器覆盖，并有管理员审定的 `protocol_window`、完整 symbol 域及签名游标。现有生产尚无该窗口，因此当前不能声明全漏斗通过。

## 2. 保证金与政策预算

PM 账户的账户级 `accountInitialMargin` 仅用于整账户交叉校验，不按比例分给策略。策略预算采用单独的可重放账本：每个已归属持仓批次链接风险预留、入场和退出逐笔成交、政策 revision、合约规则版本及同一时点标记价；仍在途的预留与该批次持仓互斥计数。期货仓位名义价值按交易所合约规格计算，政策占用以签名快照和事前冻结的风险函数重放。无法拿到规格、批次、方向、数量或采样时点时返回未知。

报告须区分 `policy_budget_margin`（策略内重放结果）、`exchange_account_initial_margin`（账户签名值）和 `estimated_notional_over_leverage`（仅诊断）；只有前两者各自证据完整才允许审计，不把估算值称作交易所逐策略保证金。验收用同币种两策略冲突、部分止盈、预留转持仓、反手、价格变动和重启样本证明不重不漏。

## 3. 策略权益与压力损失

建立策略资本归属事件，要求每笔资金划转有账户方向、资产、USD 时点估值、前后账户权益和策略分配身份。策略净值时间序列由已核净收入、未实现盈亏、策略归属资本和现金流桥接得出；账户权益与各策略及未分配现金之间逐时点守恒。缺历史基线、事件估值或归属时不补零、不外推、不报告策略回撤。

压力损失使用版本化的情景集、冻结的仓位/保护快照、滑点、费用和资金费假设重放，输出损失区间及缺口。情景参数、覆盖率和验收阈值须在首次正式比较之前固定。账户现有 5% 回撤门禁独立保留，不能代替策略曲线或策略压力损失。

## 4. 放宽判定

版本化冻结最小实盘信号、已闭合批次、收入/成交/价格覆盖率、净收益、策略最大回撤、压力损失上限和两个互不重叠的月度留出窗口。阈值未知时不默认通过。窗口从当前试跑政策生效之后起算，成本必须含手续费及资金费，配置身份必须能重放。全部通过仅产生 `REVIEW_CANDIDATE` 供人工审议；风险政策修改继续走独立发布。

## 实施顺序

1. 先审核所有开仓入口和现有捕获触发器，补齐稳定信号身份及保护单观察，建立完整窗口证明。
2. 接入逐笔成交与保护覆盖纯校验器，日报/周报显示每层计数和缺口，生产影子对账。
3. 建立批次级预算占用快照和账户交叉校验；通过数量守恒后再解除保证金未知。
4. 建立资本归属、权益桥接与情景重放；冻结阈值后运行至少两个未来留出月。

每一步先给出会失败的反例测试，再落实现有组件可复用的最小代码；生产发布限定 AI Tuner 和必要的追加式证据表，发布前后核对交易所仓位、保护单、政策及资金分配摘要。
