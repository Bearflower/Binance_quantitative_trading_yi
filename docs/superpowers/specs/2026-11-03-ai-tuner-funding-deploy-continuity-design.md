# AI Tuner 资金费日程采集器部署连续性设计

日期：2026-11-03。范围仅限资金费日程采集器的部署生命周期与验收；不修改策略、调优参数、门禁阈值或历史证据。

## 事实与目标

生产只读核查确认，2026-11-02 14:05 UTC 与 2026-11-03 01:50 UTC 两个五分钟槽位没有成功或失败批次。第二次前一槽 01:45 成功、后一槽 01:55 成功；采集器在 01:50:52 UTC 重建，09:51 北京时间的部署日志记录提交 `b92e3113`。现行 `remote_deploy_runtime.sh` 在所有普通完整部署时无条件执行 `stop_funding_collector_if_running`，然后经过拉镜像、全局 Compose、迁移、ACL 门禁才重启。部署跨过槽位即留下不可恢复的证据缺口。

目标是普通部署不停止或重建既有健康采集器；采集器代码、镜像输入、配置、数据库权限/结构或部署控制发生变化时仍先停机，全部门禁通过后才重建。任何已发生缺槽原样保留，不能回填、推断为成功或降低 90 天连续覆盖要求。

## 两类部署动作

CI 对**整段推送范围** `before..HEAD` 做可测试的变更分类，得到仅有的 `keep` 或 `rotate`。不能读取推送范围、不是受支持的事件或输入值异常时默认 `rotate`，不得默认 `keep`。`keep` 只适用于完全无关的变更；以下路径触发 `rotate`：`ai_tuner/funding_schedule/**`、`ai_tuner/Dockerfile`、`ai_tuner/requirements.txt`、`shared/**`、`docker-compose.yml`、`docker-compose.logging.yml`、`database/postgres/init-scripts/**`、`database/postgres/migrations/**`、`.github/workflows/deploy.yml`、部署动作选择/渲染/运行脚本。数据库迁移一律按敏感变更保守处理，避免漏判角色或依赖变化；分类器测试需覆盖这些边界。一次性 `calibrated-first-create`、`execution-facts-first-create`、`allocation-reconcile` 维持现有定向流程，不顺带操作采集器。

`keep`：部署前记录精确容器 ID、启动时间、镜像 ID、Compose 项目/服务标签，要求容器运行且健康；不调用 `docker stop`，全局 `up` 不使用可能清理 profile 服务的 `--remove-orphans`，且不启用 `funding-schedule` profile。既有 init-scripts、数据库角色和 ACL 门禁仍执行；ACL 失败立即停止精确采集器并令部署失败。门禁成功后**不调用**会因共用镜像新 digest 而重建采集器的普通 `up`；核验同一容器 ID/启动时间仍在运行、健康，随后只读核对下一个已截止五分钟槽位。若部署前容器不存在/不健康或部署后身份改变，失败并要求走 `rotate`，不能把失败当作连续覆盖。

`rotate`：保留现有的先停机、迁移、密码与 ACL 门禁、再显式 profile 启动的顺序。失败时不得启动采集器。部署结果需记录重建前后身份和停机窗口；可能跨过的槽位按数据库事实报告缺口，不能伪造补采。首次部署也走此路径。

CI 将动作作为经过白名单验证的模板参数传给远端脚本，不通过服务器运行时猜测 Git 历史。`keep` 期间采集器可继续使用旧镜像；只有 `rotate` 才要求容器内 `VERSION` 与本次部署一致，避免对未重建容器作错误版本判定。

## 验收与回退

测试先行，覆盖：普通策略/文档变更为 `keep`，上述敏感路径及无法判定的推送范围为 `rotate`；远端脚本 `keep` 路径没有停机、profile 启动或重建命令，身份不变且 ACL 失败精确停止；`rotate` 路径保持先停、后门禁、再启动；渲染器拒绝非法动作。用实际 Docker Compose 版本在隔离环境做 `--dry-run` 或等价演练，验证 profile 容器不会被全局 `up` 波及；不能仅凭静态字符串测试宣布成功。

上线先只进行代码和测试复审，再核对本次生产推送范围与其他未合并改动，避免连带部署。部署前记录最近三个成功槽位、容器身份和 ACL；部署后核对容器身份/健康、权限、日志、至少三个**连续已截止槽位**。若出现新缺槽，保留证据、报警、停止宣称连续性；若 ACL 失败，停止采集器。安全回退优先恢复旧部署脚本并执行 `rotate` 门禁，不能回填停机期间槽位。
