# HRS 自身额度与账户保证金独立核算

2026-11-20：用户明确选择 HRS 额度只核算自身持仓和未释放预留，同时保留全账户真实可用保证金检查。生产政策r8采用 hrs_owned_quota_account_free_v1 与 hrs_minimum_executable_v1，原到期时点不变。其他策略仓位不能消耗HRS专属26.18 USDT额度，但其实际账户保证金与预留影响账户整体可用额度。

归属必须由两路实际库存、完整成交和唯一经济所有者证明；未知归属保持拒绝。预留仅在已证明未发送或终态订单且两路库存为零、普通和条件订单均为空时释放，不使用TTL猜测。最低可执行订单风险例外不代表1%是绝对损失保证，其他门禁仍独立有效。

历史权益缺口用真实标记价与完整经济事件追加重建，保留原始检查点、份额、起点及亏损锁存，明确数据实际获取时间；不将不足30天的起始段写成完整月度验收。
