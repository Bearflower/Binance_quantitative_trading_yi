# 原始 ATR 丢失的未接管旧仓保留交易所保护并按真实成交时间退出

## 背景

ETH、SOL、XRP 旧仓的信号等级和 ATR 不在现有数据库中，按当前 ATR 和默认等级恢复普通软件止盈会改变原交易规则。交易所真实 reduce-only 止盈止损单仍在，且能从逐笔成交核实旧 lot 首笔入场时间。用户已批准保留保护单并使用最长 120 小时的保守时间退出。

## 备选方案

- 猜测等级/ATR 并软件接管：可能提前误触发止盈或时间退出，未采用。
- 立即平掉全部旧仓：改变原持仓计划，未采用。
- 保留交易所原保护单，以完整成交 lot 和归属核验作为到期退出前提：已采用。

## 决策

旧仓不重建普通软件 TP；持续核对交易所止损触发价、reduce-only、方向及覆盖数量。以已核实首笔成交时间加 120 小时为上限，在到期时重新读取归属、交易所净仓及从锚点至今的完整成交，只有 lot 身份一致才提交 reduce-only 市价平仓。提交前不撤交易所保护单；若交易所拒单，保留保护并报警、后续重试，人工复核。确认真实仓位归零后才清理剩余条件单及归属记录。

## 理由

该方案避免用不存在的历史参数编造退出规则，同时保持已有交易所保护。lot 核验防止净额账户内同币重开或归属变化时误平其他仓位。

## 后果

SOL、XRP 的截止时间分别是北京时间 2026-11-04 16:11:16、2026-11-05 13:13:48。到期前无法证明真实退出已执行；若交易所因条件单占仓拒绝市价 reduce-only 单，仓位可能超过 120 小时，必须报告并处置，不能把保护保留误述为已按时退出。ETH 原 lot 已在旧版运行期间归零，不再等待截止时间。

## 适用范围与修订

适用于本批已审计旧仓与相同证据条件下的未接管仓位；实现见 `dbfcc652`。若后来恢复出可信原始等级/ATR 或交易所接口语义改变，需重新审查，不直接套用猜测参数。无替代决策。
