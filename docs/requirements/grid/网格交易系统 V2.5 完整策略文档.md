## 3. 多因子保证金智能引导系统（核心新增）

### 3.1 设计思想

保证金是网格的「燃料」。不同市场状态下，燃料使用效率完全不同。本系统通过**多因子综合评分**，动态计算建议保证金，实现「震荡加码、趋势减码、极端清仓」。

### 3.2 核心公式


建议保证金 = 基础保证金 
           × 状态系数
           × 趋势强度系数
           × 波动率系数
           × BTC一致性系数
           × 资金费率系数
           × 成交量系数（可选）


> 当前 V2.5 实现为**五因子**（状态/趋势强度/波动率/BTC一致性/资金费率）；成交量系数为可选增强因子，本版本未启用（见 3.8）。


### 3.3 因子一：状态系数（核心）

状态系数**按 MarketState 枚举逐项映射**，与市场状态判定口径一致。危险态（价格紧急/早期预警/趋势确认/趋势加速/极端强趋势/波动率异常）系数为 0，普通强趋势 0.3，弱趋势 0.6，震荡 1.0；震荡且 1h ADX<18 时按强震荡系数 1.2 加码。

| MarketState 枚举 | 状态系数 | 建议保证金（200U） | 说明 |
|------------------|----------|--------------------|------|
| OSCILLATION + ADX<18 | 1.2 | 240 USDT | 强震荡，加码20% |
| OSCILLATION（震荡） | 1.0 | 200 USDT | 基准值 |
| WEAK_TREND（弱趋势） | 0.6 | 120 USDT | 减码40% |
| NORMAL_STRONG_TREND（普通强趋势） | 0.3 | 60 USDT | 大幅减码 |
| PRICE_EMERGENCY（价格紧急） | 0 | 0 USDT | 立即清仓 |
| EARLY_WARNING_15M（早期预警） | 0 | 0 USDT | 危险态，保守 |
| TREND_CONFIRMED_1H（趋势确认） | 0 | 0 USDT | 危险态，保守 |
| TREND_ACCELERATING（趋势加速） | 0 | 0 USDT | 危险态，保守 |
| EXTREME_STRONG_TREND（极端强趋势） | 0 | 0 USDT | 清仓 |
| VOLATILITY_ABNORMAL（波动率异常） | 0 | 0 USDT | 危险态，保守 |

> 未在配置中列出的枚举一律返回 0（保守处理）。`state_coeff` 映射配置见 `config.yaml` 的 `margin_guide.state_coeff`（V2.5 起实施）。

### 3.4 因子二：趋势强度系数（ADX细调）

python
if ADX < 20:
    趋势强度系数 = 1.0 + (20 - ADX) / 100    # 越平静越加码，最多+20%
elif ADX < 30:
    趋势强度系数 = 1.0 - (ADX - 20) / 50     # 逐步减码
else:
    趋势强度系数 = 0.5 - (ADX - 30) / 40     # 快速减码，最低0


### 3.5 因子三：波动率系数（ATR）

python
波动率系数 = 基准ATR / 当前ATR
波动率系数 = max(0.5, min(1.5, 波动率系数))


- 波动率升高（ATR变大）→ 系数 <1 → 减少保证金
- 波动率降低（ATR变小）→ 系数 >1 → 增加保证金

### 3.6 因子四：BTC 一致性系数（跨市场确认）

**为什么重要**：BTC 是市场龙头，ETH 与 BTC 的 30 日相关性通常在 0.7-0.9。大行情往往由 BTC 先启动。

| ETH 状态 | BTC 状态 | 系数 | 说明 |
|----------|----------|------|------|
| 同向趋势 | 同向趋势 | 1.0 | 高置信度，正常执行 |
| 趋势 | 震荡 | 0.7 | 中置信度，减码 |
| 趋势 | 反向趋势 | 0.4 | 低置信度（背离），大幅减码 |
| 震荡 | 任意 | 1.0 | 震荡市不受BTC影响 |

**BTC 独立检测器**：为保证 ETH 与 BTC 的市场状态互不影响，系统为 BTCUSDT 单独运行一个完整的 MarketStateDetector 实例（与 ETH 主检测器参数相同、实例状态独立不污染）。

**背离检测（预警信号，V2.5 实施）**：

- 背离检测仅对**趋势态**（非震荡/弱趋势）且 BTC 检测成功的场景执行；ETH 处于震荡或弱趋势时不检测。
- **不单独推送背离警告**（V2.5 已按用户最终决策调整）：背离结果仅作为**现有推送模板末尾追加的一行提示**，由 `signal_bot._append_divergence()` 追加到趋势态警报末尾，格式为 `⚠️ 背离: <提示文本>`。
- 检测用近 24 根 1h K 线（ETH/BTC 各一次）：

python
if ETH价格创新高 and BTC未创新高:
    提示一行"BTC未创新高，ETH上涨可能为假突破"
if ETH价格创新低 and BTC未创新低:
    提示一行"BTC未创新低，ETH下跌可能为假跌破"


### 3.7 因子五：资金费率系数（市场情绪）

**数据来源**：币安 `GET /fapi/v1/fundingRate` 接口

| 资金费率 | 系数 | 含义 |
|----------|------|------|
| > 0.05% | 0.7 | 多头拥挤，市场过热，减码 |
| 0 ~ 0.05% | 1.0 | 多空平衡 |
| -0.05% ~ 0 | 1.0 | 多空平衡 |
| < -0.05% | 1.2 | 空头拥挤，市场恐慌，可加码 |

**注意**：资金费率每 8 小时更新一次，不需要每次巡检都获取。

### 3.8 因子六：成交量系数（可选，真假突破）

> **V2.5 未启用**：本版本保持五因子实现，成交量因子暂不参与计算，仅保留设计以备后续版本启用。

python
if 价格突破 and 成交量 > 近20根均量 × 1.5:
    确认为真突破 → 系数 = 0（立即终止）
else:
    可能是假突破 → 系数 = 1.0（保持观察）


### 3.9 综合计算示例

**场景**：基础保证金 200 USDT，当前 ADX=22，ATR=30（基准ATR=40），BTC同向，资金费率 0.02%

- 状态系数 = 1.0（震荡）
- 趋势强度系数 = 1.0 - (22-20)/50 = 0.96
- 波动率系数 = 40/30 = 1.33
- BTC一致性系数 = 1.0
- 资金费率系数 = 1.0
- **建议保证金 = 200 × 1.0 × 0.96 × 1.33 × 1.0 × 1.0 ≈ 255 USDT**

**解读**：当前震荡且波动率偏低，可以适当加码至 255 USDT。

## 4. 保证金调整触发规则

### 4.1 调整触发条件

| 条件 | 动作 |
|------|------|
| 建议保证金 / 当前保证金 > 1.2 | 建议增加保证金 |
| 建议保证金 / 当前保证金 < 0.8 | 建议减少保证金 |
| 建议保证金 = 0 | 建议清仓 |
| 比例在 0.8-1.2 之间 | 不调整（避免频繁操作） |

### 4.2 单次调整幅度限制


单次最大调整 = 基础保证金 × 0.3

以 200U 为例，单次最大调整 60 USDT。

### 4.3 调整冷却时间

- 同方向调整（加码/减码/清仓）间隔至少 **4 小时**
- 反向调整（如从加码转为减码）可立即执行；清仓与减码视为不同方向，互不拦截

**冷却期间的文案（V2.5 实施）**：冷却期内**保留建议但抑制动作**，板块标题显示「冷却中，暂不操作」，并附说明行（如「说明: 距上次加码未满4h冷却期，本次仅提示不操作」），同时尾部展示冷却剩余时间（如「冷却: 剩余 2.5h（上次加码 10:05）」）。

## 7. 网格参数计算（沿用 V2.4）

### 7.1 基础参数（ETHUSDT）

| 市场状态 | 区间宽度 | 基准网格数 | 网格范围 | 止损缓冲 |
|----------|----------|------------|----------|----------|
| 震荡 | 10 × ATR_smooth | 8 | [5, 12] | 2 × ATR |
| 弱趋势 | 12 × ATR_smooth | 6 | [4, 10] | 2.4 × ATR |

### 7.2 计算公式

**震荡市场**：

下边界 = 当前价格 - 5 × ATR_smooth
上边界 = 当前价格 + 5 × ATR_smooth
N = round(8 × (基准ATR / 当前ATR))
N = max(5, min(12, N))
终止最低价 = 下边界 - 2 × ATR_smooth
终止最高价 = 上边界 + 2 × ATR_smooth
每格利润率 = ((上边界 - 下边界) / N) / 当前价格 × 100%

若利润率 < 1%，则 N = 5 强制重算；若仍不足，将区间宽度扩大至 12×ATR。

**弱趋势市场**：

下边界 = 当前价格 - 6 × ATR_smooth
上边界 = 当前价格 + 6 × ATR_smooth
N = round(6 × (基准ATR / 当前ATR) × 0.8)
N = max(4, min(10, N))
终止最低价 = 下边界 - 2.4 × ATR_smooth
终止最高价 = 上边界 + 2.4 × ATR_smooth


**最低间距硬性校验**：

min_grid_spacing = 当前价格 × 0.006  # 0.6%
if 每格间距 < min_grid_spacing:
    推送："⚠️ 当前波动率极低，网格间距过窄（<0.6%），建议暂停开仓"

## 8. 波动率异常检测（沿用 V2.4）

- 巡检频率：每 1 小时
- 检测窗口：4 小时
- 触发：连续两次巡检 `当前ATR_smooth / 4小时前ATR_smooth > 1.3`
- 存储：首次异常时记录 `atr_peak`
- 恢复：`当前ATR_smooth / atr_peak < 1.2`
