- 频率控制：每日最大4笔交易

**核心文档**:

- [新币做空策略 V4.0 （情绪面优化版）.md](./new_coin/新币做空策略%20V4.0%20（情绪面优化版）.md) - V4.0 情绪面优化版
- [V4.0 最终版问题解释.md](./new_coin/V4.0%20最终版问题解释.md) - V4.0 最终版问题解释
- [完全平仓后取消孤儿条件单.md](./new_coin/完全平仓后取消孤儿条件单.md) - 完全平仓后取消孤儿条件单
- [2026-04-02做空策略调整1.md](./new_coin/2026-04-02做空策略调整1.md) - 一币一单策略

**主要内容**:
- 策略目标：每个新币只做一次空单，捕捉上线后第一波衰竭下跌
- 三维筛选：合约数据（OI/交易量比）+ 技术形态 + 资金费率
- 评分系统：满分10分，开仓需≥6.5分（V4.0完整版为≥5.0分）
- 止损止盈：ATR动态止损 + 分批止盈 + 移动止盈
- **入场后自动停止监控**：入场成功后立即停止对该币种的监控（加入 known_symbols、从K线服务注销），不再等待48小时过期

**关键特性**:
- 时间窗口：上线<48小时
- 合约筛选：OI/上线以来总交易量 < 0.4
- 技术形态：三次冲顶 + 长上影线 + 放量滞涨
- 风控机制：每笔最大亏损2%，杠杆≤2倍
- **入场即停止监控**：入场成功后立即加入 known_symbols、从K线服务注销，后续不再评分

### 3. 网格交易策略

**核心文档**: 
- [网格交易v2.0.md](./grid/网格交易v2.0.md) - V2.0完整需求
- [网格交易v2.0补充.md](./grid/网格交易v2.0补充.md) - 移动止盈详解
- [Grid_Trading_V2.1.md](./grid/Grid_Trading_V2.1.md) - V2.1 双重时间框架 + 波动率异常检测
- [Grid_Trading_V2.2.md](./grid/Grid_Trading_V2.2.md) - V2.2 参数优化升级（最新版）

**主要内容**:
- 策略思想：趋势过滤 + 动态参数 + 半自动信号灯
- **市场状态识别（V2.1 升级）**：震荡 / 弱趋势 / 普通强趋势 / 极端强趋势 / 波动率异常（5种状态）
- 双重时间框架确认：1h（主判断） + 4h（趋势过滤）
- 波动率异常检测：连续两次巡检 ATR 飙升 > 30% 触发暂停（V2.2 灵敏度提升）
- 网格参数自动计算：价格区间、网格数量、止盈止损

**关键特性**:
- 趋势强度系数：k = min(0.5, max(0, (ADX-25)/30))
- 移动止盈：盈利≥15%启动，回撤5%止盈
- 强趋势主动暂停：普通强趋势（1h ADX≥30 且 4h ADX≥25 方向一致）建议终止；极端强趋势（1h ADX≥40 且 4h ADX≥30）必须终止（V2.2 双重确认）
- 弱趋势谨慎运行：减少网格数量（基准6格，范围[4,10]）、放宽价格区间（6.0×ATR）、止损缓冲2.4×ATR（V2.2 优化）
- 震荡市运行：基准8格（范围[5,12]），价格区间5.0×ATR（V2.2 优化）
- 推送冷却：6小时（V2.2 延长）
- 上移/下移功能：趋势跟踪
- 仓位可行性验证：确保每格≥1张

- 每日交易统计与飞书推送（北京时间 12:10）

- 检测次数、有效信号、成功执行、胜率、亏损统计

- APScheduler 定时调度，容器启动补发

### 5. 月度资金分配系统

**核心文档**: [月度资金分配需求文档.md](./capital_allocation/月度资金分配需求文档.md)

**主要内容**:
- 每月最后一天按收益率排名动态分配各策略资金占比
- 参与策略：MTPCS、新币做空、HRS（网格策略不参与）
- 风险备用金固定 10%，其余 90% 按排名分配（第1名40%、第2名30%、第3名20%）
- 收益率 = 本月已实现 PnL / 月初分配资金
- 分配结果存储于数据库新表 `capital_allocation`，同时写入 `ai_tuner/config.yaml`
- 飞书卡片推送通知

**关键特性**:
- 首月使用默认基准：MTPCS 30%、新币做空 40%、HRS 20%
- 新增策略需预设 `fallback_ratio` 才纳入分配池
- 不设最低保障，严格按排名淘汰
- 限制各策略最大名义开仓金额（Max Notional）作为生效方式

### 6. 交易周报

**核心文档**: [需求说明.md](./weekly_report/需求说明.md)

**主要内容**:
- 每周交易统计与飞书推送（北京时间 每周一 09:20）
- **v2.0 统一数据源架构**：三指标（委托/成交/平仓）统一从 Binance API 采集
- 币种级明细表格 + 全策略汇总
- 勾稽校验规则（成交 >= 平仓 硬约束）
- 跨周持仓自动标注（条件单跨周触发说明）

**关键特性**:
- allOrders API 分批查询（7天一批，4周回溯窗口）
- 客户端双路过滤：`time` → order_count, `updateTime` + `FILLED` → fill_count
- 三级降级策略：API → trade_records → N/A
- 数据质量告警 + 勾稽校验不通过告警
