# 交易日报 — 需求说明

**文档版本**: v1.0
**最后更新**: 2026-05-15
**维护者**: 项目团队

---

## 一、功能概述

交易日报是跨策略的每日交易统计与推送模块。每天北京时间 **12:10** 自动统计前一日的交易数据，通过飞书 Webhook 推送到指定群聊。

覆盖策略：MTPCS 策略、新币做空策略、网格交易策略。

---

## 二、推送内容

### 2.1 标题

```
📊 交易日报 — YYYY年MM月DD日
```

### 2.2 策略概况（每个策略一个摘要）

```
📈 MTPCS策略
   检测次数：X次
   ├─ 有效信号：X个
   ├─ 成功执行：X 笔
   ├─ 胜率：X.X%
   └─ 亏损：X 笔
```

### 2.3 全策略汇总

```
📊 全策略汇总
   总检测：X 次 | 总执行：X 笔 | 整体胜率：X.X%
```

## 三、数据采集逻辑

### 3.1 检测次数

从策略专属数据库表查询前一日 `detection_time` 范围内的信号记录数：

| 策略 | 数据源表 |
|------|---------|
| MTPCS 策略 | `btc_eth.trade_signals` |
| 新币做空策略 | `new_coin.short_signals` |
| 网格交易策略 | `grid.grid_signals` |

### 3.2 有效信号

`btc_eth` 和 `grid` 策略查询 `status = 'valid'` 的信号；`new_coin` 查询 `is_active = true`。

### 3.3 下单笔数

从统一交易记录表 `trading.trade_records` 查询前一日 `executed_at` 范围内的记录数，按策略过滤。

**数据来源**: `shared/trade_logger.py` → `trading.trade_records` 统一交易记录表。
所有策略通过 `BinanceClient` API 层的 Hook 机制自动写入，无需策略单独处理。

### 3.4 盈亏与胜率

从 **Binance income API**（`/papi/v1/um/income`，`incomeType=REALIZED_PNL`）获取前一日已实现盈亏：

- `win_count` = income > 0 的笔数
- `loss_count` = income < 0 的笔数
- `win_rate` = win_count / (win_count + loss_count) × 100%

**胜率仅针对已平仓的头寸**，未平仓头寸不纳入统计。

---

## 四、数据一致性约束

| 约束 | 说明 |
|------|------|
| 订单数 ≥ 平仓数 | 一笔平仓对应至少一笔订单 |
| 平仓数 = 盈 + 亏 | 每笔平仓必然有盈亏结果 |
| 全策略汇总 = 各策略之和 | 汇总数据与分策略数据一致 |

## 五、配置说明

配置文件: `strategies/daily_report/config.yaml`

```yaml
daily_report:
  schedule:
    hour: 12       # 北京时间 12:00
    minute: 10     # 12:10 推送
  feishu_webhook: ""  # 空值时从环境变量 FEISHU_DAILY_REPORT_WEBHOOK 读取
  strategies:
    btc_eth:
      name: "MTPCS策略"
      schema: "btc_eth"
      emoji: "📈"
    new_coin:
      name: "新币做空策略"
      schema: "new_coin"
      emoji: "📉"
    grid:
      name: "网格交易策略"
      schema: "grid"
      emoji: "🔲"
```

**环境变量**:
- `FEISHU_DAILY_REPORT_WEBHOOK`: 飞书机器人 Webhook 地址（优先级高于 config.yaml）

---

## 六、调度机制

使用 APScheduler，在容器启动时注册定时任务：
- 每天北京时间 12:10 执行 `send_daily_report()` 
- 容器启动后立即执行一次（补发可能的遗漏）
