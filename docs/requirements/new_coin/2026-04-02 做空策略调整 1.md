# 2026-04-02 做空策略调整

## 策略优化说明

本文档记录了 2026 年 4 月 2 日对做空策略进行的调整和优化。

## 主要调整内容

### 1. 精度处理优化

- 改进了价格和数量的精度计算逻辑
- 确保符合币安 API 的精度要求
- 避免因精度问题导致的订单失败

### 2. PM 账户支持

- 完善了 PM 账户（投资组合保证金账户）的集成
- 优化了余额检查和风险控制
- 支持多仓位管理

### 3. 错误处理增强

- 增加了更详细的错误日志
- 改进了异常捕获机制
- 提供了更清晰的错误提示
