# 新币做空策略 V4.0 完整版（情绪面优化）

## 1. 策略概述

- **目标**：针对币安新上线的永续合约币种，**每个币种只做一次空单**，捕捉上线后第一波明确的衰竭下跌行情。
- **核心理念**：通过**合约数据（OI/上线以来总交易量比率）+ 价格行为形态（三次冲顶、长上影线、放量滞涨）+ 多因子情绪指标（资金费率 + OI变化率）** 三维筛选，找到高概率下跌机会。
- **策略优势**：低交易频率（年约150-200笔）、严格风控、完全基于可获取的实时数据。

---

## 2. 币种预筛选（必须全部满足）

| 筛选维度 | 条件 | 数据源 | 一票否决 |
|---------|------|--------|----------|
| 时间窗口 | 上线时间 < 48小时 | 币安公告 | ✅ 是 |
| 合约数据 | OI / 上线以来总交易量 ≤ 0.5 | 币安API | ✅ 是（>0.5直接放弃） |

**说明**：  
- 使用 **OI / 上线以来总交易量** 替代 OI/市值比。  
- 上线以来总交易量 = 从第一根K线到当前K线的成交量之和（USD）。  
- 阈值 >0.5 为一票否决，0.4~0.5 得分0分（但不否决，可人工复核）。

---

## 3. 信号评分系统（满分10分，开仓需总分 ≥ 6.5）

### 3.1 合约数据（权重45%）

| OI / 上线以来总交易量 | 得分 | 说明 |
|----------------------|------|------|
| < 0.2 | 10 | 优秀 |
| 0.2 ~ 0.3 | 7 | 良好 |
| 0.3 ~ 0.4 | 3 | 偏高，谨慎 |
| 0.4 ~ 0.5 | 0 | 极危险，手动复核（默认不开） |
| > 0.5 | 一票否决 | 直接放弃 |

### 3.2 技术面（权重35%）

基于 **1小时K线**，每根K线收盘后判断。**纯形态评分**。

| 条件 | 分值 | 量化标准 |
|------|------|----------|
| 三次冲顶 | 0~4 | 最近3-5根K线，高点逐次降低（差≥0.2%）或同一水平受阻≥3次 |
| 长上影线 | 0~3 | 上影线长度 ≥ 实体长度 × 2，且实体为阴线或十字星 |
| 放量滞涨 | 0~3 | 成交量 ≥ 前5根平均 × 1.5，且收盘价低于前一根K线高点 |
| **技术总分** | **0~10** | 三项得分相加 |

**硬性入场要求**：  
- 技术总分 ≥ **6**  
- 三次冲顶分 ≥ **2**

### 3.3 情绪面（权重20%）

情绪面采用 **双因子打分**，满分10分，权重20%。两个子因子各0~5分，相加得到情绪总分。

| 子因子 | 满分 | 数据源 | 评分规则 |
|--------|------|--------|----------|
| **资金费率（年化）** | 5分 | 币安API（最近一次结算前实时费率） | > 100% → 5分<br>50%~100% → 3分<br>30%~50% → 1分<br>< 30% → 0分 |
| **OI变化率（3小时）** | 5分 | 币安API（3小时前OI → 当前OI） | OI增长率 ≥ 50% → 5分<br>30%~50% → 3分<br>10%~30% → 1分<br>< 10% 或负增长 → 0分 |

**计算示例**：  
- 资金费率年化 120% → 5分  
- OI 3小时增长 40% → 3分  
- 情绪总分 = 5 + 3 = **8分**

**说明**：  
- OI变化率 = `(当前OI - 3小时前OI) / 3小时前OI`，若3小时前数据不足（上线不足3小时），则用上线以来的最短时间窗口计算。  
- 两个因子独立评分，鼓励捕捉“多头拥挤 + 新增杠杆入场”的双重情绪信号。

### 3.4 总分计算与开仓条件

```
总分 = (合约得分 × 0.45) + (技术得分 × 0.35) + (情绪得分 × 0.20)
```

**开仓必须同时满足**：  
- 总分 ≥ **6.5**  
- 技术面硬性要求（技术总分 ≥6 且 三次冲顶 ≥2）  
- 无任何一票否决项  
- 该币种尚未开仓过

## 4. 进场时机详细规则

- **时间框架**：1小时K线  
- **评分时机**：**每个1小时K线收盘后**立即评分一次  
- **启动条件**：至少有 **14根** 已收盘的1小时K线（保证ATR计算）  
- **开仓执行**：满足条件后，在当前K线收盘时**市价开空**，立即挂好止损止盈单  
- **入场后处理**：入场成功后**立即停止对该币种的监控**，包括：
  - 将该币种加入 `known_symbols`（不再被检测为新币）
  - 从K线服务注销（停止采集该币种的K线数据）
  - 后续周期不再对该币种评分、不再推送通知
  - 飞书通知中标注为"已入场(已停止监控)"
- **放弃条件**：
  - 形态出现后价格反弹超过最近高点
  - 上线48小时内无合格信号（且尚未入场）
  - 评分不足但继续等待时超48小时（且尚未入场）

## 5. 止损与止盈参数

### 5.1 止损设置（取三者最大值）

| 止损类型 | 计算公式 | 说明 |
|----------|----------|------|
| ATR硬止损 | 开仓价 + 2.5 × ATR(14) | 主要动态止损 |
| 紧急止损 | 开仓价 × 1.015 | 开仓后15分钟内有效 |
| 最小绝对止损 | 开仓价 × 1.05 | 5%硬性下限 |
| **最终止损价** | **取上述最大值** | — |

### 5.2 止盈设置（分批+移动）

| 目标 | 触发条件 | 平仓比例 |
|------|----------|----------|
| 第一目标 | 价格 ≤ 开仓价 - 1.5 × ATR | 30% |
| 第二目标 | 价格 ≤ 开仓价 - 3.5 × ATR | 40% |
| 移动止盈 | 从最低点反弹 1.5 × ATR | 剩余30% |
| 时间止损 | 持仓超过 **72小时** 且未达第一目标 | 100% |

## 6. 仓位管理与风控

| 规则 | 设定 |
|------|------|
| 每笔最大亏损 | 账户总资金 **2%** |
| 杠杆 | ≤ **2倍**（固定） |
| 单日最多开仓 | **2个币种** |
| 连续亏损暂停 | 连续3笔亏损后，暂停交易 **2天** |
| 最大回撤熔断 | 累计亏损 ≥ **15%** 时暂停交易 **一周** |
| 黑名单机制 | 触发止损后24小时内反向暴涨超过止损价5%的币种，**永久禁止** |

## 7. 执行流程清单

1. **早间准备**：获取币安新币公告，列出上线时间 < 48小时的币种。  
2. **筛选**：计算 `OI / 上线以来总交易量`，排除 >0.5 的币种。  
3. **等待信号**：每小时整点后，对已收盘的1小时K线进行技术面、情绪面评分（需 ≥14根K线）。  
4. **开仓**：若总分 ≥6.5 且技术面满足硬性要求，市价开空，立即挂止损止盈单。**入场成功后立即停止对该币种的监控**（加入 known_symbols、从K线服务注销、后续周期不再评分和推送）。  
5. **持仓管理**：每日检查时间止损与移动止盈。  
6. **复盘**：每周统计胜率、盈亏比、最大回撤。

## 9. 重要说明

- **无基本面评分**：解锁数据难以实时获取，完全移除。  
- **OI替代指标**：采用 `OI / 上线以来总交易量`，解决市值缺失问题。  
- **情绪面多因子**：资金费率 + OI变化率，提升极端情绪捕捉能力。  
- **参数持续优化**：建议每月根据实盘表现微调阈值。
- **入场后自动停止监控**：每个币种入场成功后立即停止监控（加入 known_symbols、从K线服务注销、后续周期不再评分），不再等待48小时过期。
