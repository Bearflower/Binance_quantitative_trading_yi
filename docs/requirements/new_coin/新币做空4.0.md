# 新币做空策略 V4.0 最终确认版

## 1. 策略概述

- **目标**：针对币安新上线的永续合约币种，**每个币种只做一次空单**，捕捉上线后第一波明确的衰竭下跌行情。
- **核心理念**：通过**合约数据（OI/上线以来总交易量比率）+ 价格行为形态（三次冲顶、长上影线、放量滞涨）+ 资金费率**三维筛选，找到高概率下跌机会，实现“一击必中”。
- **策略优势**：低交易频率（年约150-200笔）、严格风控、完全基于可获取的实时数据。

---

## 2. 币种预筛选（必须全部满足）

| 筛选维度 | 条件 | 数据源 | 一票否决 |
|---------|------|--------|----------|
| 时间窗口 | 上线时间 < 48小时 | 币安公告 | ✅ 是 |
| 合约数据 | OI / 上线以来总交易量 < 0.4（暂定） | 币安API | ✅ 是（>0.4放弃） |

**说明**：  
- 因市值数据难以获取，使用 **OI / 上线以来总交易量** 替代 OI/市值比。  
- 上线以来总交易量 = 从第一根K线到当前K线的成交量之和（USD）。  
- 阈值 0.4 为初步建议，需回测微调。

---

## 3. 信号评分系统（满分10分，开仓需总分 ≥ 6.5）

### 3.1 合约数据（权重45%）

| OI / 上线以来总交易量 | 得分 | 说明 |
|----------------------|------|------|
| < 0.2 | 10 | 优秀 |
| 0.2 ~ 0.3 | 7 | 良好 |
| 0.3 ~ 0.4 | 3 | 偏高，谨慎 |
| 0.4 ~ 0.5 | 0 | 极危险，放弃 |
| > 0.5 | 一票否决 | 直接放弃 |

### 3.2 技术面（权重35%）

基于 **1小时K线**，每根K线收盘后判断。**纯形态评分，不使用 RSI、MACD 等传统指标**。

| 条件 | 分值 | 量化标准 |
|------|------|----------|
| 三次冲顶 | 0~4 | 最近3-5根K线，高点逐次降低（差≥0.2%）或同一水平受阻≥3次 |
| 长上影线 | 0~3 | 上影线长度 ≥ 实体长度 × 2，且实体为阴线或十字星 |
| 放量滞涨 | 0~3 | 成交量 ≥ 前5根平均 × 1.5，且收盘价低于前一根K线高点 |
| **技术总分** | **0~10** | 三项得分相加 |

**最低要求**：技术总分 ≥ 6 且 “三次冲顶” ≥ 2。

### 3.3 情绪面（权重20%）

使用当前资金费率（年化）。

| 资金费率（年化） | 得分 |
|----------------|------|
| > 150% | 10 |
| 100% ~ 150% | 7 |
| 50% ~ 100% | 3 |
| < 50% 或 负费率 | 0 |

### 3.4 总分计算与开仓条件

```
总分 = (合约得分 × 0.45) + (技术得分 × 0.35) + (情绪得分 × 0.20)
```

**开仓必须同时满足**：  
- 总分 ≥ **6.5**  
- 技术面满足最低要求（技术总分 ≥6 且 三次冲顶 ≥2）  
- 无任何一票否决项  
- 该币种尚未开仓过

## 4. 进场时机详细规则

- **时间框架**：1小时K线  
- **评分时机**：**每个1小时K线收盘后**立即评分一次  
- **启动条件**：至少有 **14根** 已收盘的1小时K线（以保证ATR计算），若不足14根，使用固定5%止损（止盈对应为3%/6%）。  
- **形态检测自适应机制**：形态检测采用自适应算法，根据可用K线数量动态调整检测参数（无需等待30根K线，最早14根即可参与评分）。具体参数从 `config.yaml` 的 `pattern.adaptive` 段读取。
- **开仓执行**：满足条件后，在当前K线收盘时**市价开空**，立即挂好止损止盈单。  
- **入场后处理**：入场成功后**立即停止对该币种的监控**，包括：
  - 将该币种加入 `known_symbols`（不再被检测为新币）
  - 从K线服务注销（停止采集该币种的K线数据）
  - 后续周期不再对该币种评分、不再推送通知
  - 飞书通知中标注为"已入场(已停止监控)"
- **放弃条件**：
  - 形态出现后价格反弹超过最近高点
  - 上线48小时内无合格信号（且尚未入场）
  - 评分不足但继续等待时超48小时（且尚未入场）

## 5. 止损与止盈（核心参数最终确认）

### 5.1 止损设置（取最大值）

| 止损类型 | 计算公式 | 说明 |
|----------|----------|------|
| ATR硬止损 | 开仓价 + 2.5 × ATR(14) | 主要止损 |
| 紧急止损 | 开仓价 × 1.015 | 开仓后15分钟内有效 |
| 最小绝对止损 | 开仓价 × 1.05 | 5%硬性下限 |
| **最终止损** | **取三者最大值** | — |

### 5.2 止盈设置（分批+移动）

| 目标 | 触发条件 | 平仓比例 |
|------|----------|----------|
| 第一目标 | 价格 ≤ 开仓价 - 1.5 × ATR | 30% |
| 第二目标 | 价格 ≤ 开仓价 - 3.5 × ATR | 40% |
| 移动止盈 | 从最低点反弹 1.5 × ATR | 剩余30% |
| 时间止损 | 持仓超过 **72小时** 且未达第一目标 | 100% |

**说明**：  
- 若K线不足14根（无ATR），则固定使用：止损5%，止盈3%/6%，移动止盈回撤3%。  
- 该参数组合预期盈亏比 > 1.2，胜率 > 50%。

## 6. 仓位管理与风控

| 规则 | 设定 |
|------|------|
| 每笔最大亏损 | 账户总资金 2% |
| 杠杆 | ≤ 2倍（固定） |
| 单日最多开仓 | 2个币种 |
| 连续亏损暂停 | 连续3笔亏损后，暂停2天 |
| 最大回撤熔断 | 累计亏损 ≥15% 时暂停一周 |
| 黑名单机制 | 触发止损后24小时内反向暴涨超过止损价5%的币种，永久禁止 |

**仓位计算示例**（账户500U，止损幅度5%）：  
- 最大亏损 = 10U  
- 开仓价值 = 10 / 5% = 200U  
- 2倍杠杆 → 保证金 = 100U（佔20%）

## 7. 执行流程清单

1. **早间**：获取币安新币公告，列出上线<48小时的币种。  
2. **筛选**：计算每个币种的 `OI / 上线以来总交易量`，排除 >0.4 的币种。  
3. **等待信号**：对通过筛选的币种，每小时整点后对已收盘的1小时K线进行技术形态+情绪评分。  
4. **开仓**：满足总分≥6.5且技术最低要求后，在K线收盘时市价开空，立即挂好止损止盈单。**入场成功后立即停止对该币种的监控**（加入 known_symbols、从K线服务注销、后续周期不再评分和推送）。  
5. **持仓**：每日检查时间止损与移动止盈。  
6. **复盘**：每周统计胜率、盈亏比、最大回撤。

## 9. 重要说明

- **无基本面评分**：因新币解锁数据难以实时获取且不完整，完全移除。  
- **OI/市值比替代**：采用 `OI / 上线以来总交易量` 比率，解决了市值数据缺失问题。  
- **纯形态技术面**：经回测验证有效，不依赖传统指标。  
- **参数需持续优化**：止损止盈、比率阈值等可根据实盘表现微调。
- **入场后自动停止监控**：每个币种入场成功后立即停止监控（加入 known_symbols、从K线服务注销、后续周期不再评分），不再等待48小时过期。
