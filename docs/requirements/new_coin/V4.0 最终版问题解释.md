根据最新确认的 **V4.0 最终版策略**，针对你提出的9个问题，现逐一明确如下：

---

### 1. OI/总交易量比率评分逻辑
- **指标**：`OI / 上线以来总交易量`（上线以来总交易量 = 从第一根K线到当前K线的成交量之和，USD）
- **评分标准**（权重45%）：

| 比率区间 | 得分 |
|----------|------|
| < 0.2    | 10   |
| 0.2 ~ 0.3| 7    |
| 0.3 ~ 0.4| 3    |
| 0.4 ~ 0.5| 0    |
| > 0.5    | 一票否决 |

**逻辑**：比率越低，代表存量杠杆相对于增量热钱越小，市场越安全，得分越高。

---

### 2. 一票否决机制
**存在**，包括以下情况：
- **OI/总交易量比率 > 0.5** → 直接放弃该币种
- **上线时间 > 48小时** → 不再监控
- **技术面硬性要求不满足**（技术总分<6 或 三次冲顶分<2） → 不开仓（但币种仍可继续等待下一根K线，不算一票否决）
- **该币种已入场** → 入场成功后立即停止监控（加入 known_symbols、从K线服务注销、后续周期不再评分），不再等待48小时过期

---

### 3. 资金费率评分标准逻辑
- **年化资金费率**（取最近一次结算前实时费率）
- **评分标准**（权重20%）：

| 年化费率 | 得分 |
|----------|------|
| > 150%   | 10   |
| 100%~150%| 7    |
| 50%~100% | 3    |
| <50% 或 负| 0    |

**逻辑**：费率越高，多头拥挤程度越高，潜在踩踏下跌概率越大，得分越高。

---

### 4. 技术面入场条件逻辑
- **纯形态评分**（不使用 RSI/MACD），基于1小时K线收盘后判断。
- **三项指标**：
  - 三次冲顶（0~4分）：最近3-5根K线高点逐次降低（差≥0.2%）或同一水平受阻≥3次。
  - 长上影线（0~3分）：上影线长度 ≥ 实体×2，且实体为阴线或十字星。
  - 放量滞涨（0~3分）：成交量 ≥ 前5根平均×1.5，且收盘低于前高。
- **硬性入场要求**：
  - 技术总分 ≥ **6**
  - 三次冲顶分 ≥ **2**
- 满足硬性要求后，再结合合约分和情绪分计算总分（≥5.0）才开仓。

---

### 5. ATR动态止损
- **周期**：14根1小时K线
- **计算公式**：`止损价 = 开仓价 + 2.5 × ATR(14)`
- **说明**：止损幅度为 2.5 倍ATR，相比早期版本（2.0）放宽，以提高容错。

---

### 6. 紧急止损机制
- **触发条件**：开仓后 **15分钟内**，价格反向（上涨）超过 **1.5%**
- **执行**：立即平仓离场
- **计算**：`紧急止损价 = 开仓价 × 1.015`

---

### 7. 最终止损价取最大值逻辑
最终止损价 = **MAX( ATR止损价, 紧急止损价, 最小绝对止损价 )**
- **ATR止损价** = 开仓价 + 2.5×ATR
- **紧急止损价** = 开仓价 × 1.015
- **最小绝对止损价** = 开仓价 × 1.05（即5%硬性下限）

**作用**：防止因ATR过小或紧急止损过窄导致被正常波动扫损，确保止损宽度至少5%。

---

### 8. 最大回撤熔断
- **触发条件**：账户累计亏损（从初始本金或最近高点回撤）达到 **15%**
- **措施**：**暂停交易一周**，进行复盘分析，找出问题并调整策略后，方可恢复交易。

---

### 9. 单日开仓限制
- **每日最多开仓**：**2个币种**
- **目的**：控制单日总风险暴露（每笔风险2%，合计≤4%），避免因连续亏损导致单日回撤过大。
