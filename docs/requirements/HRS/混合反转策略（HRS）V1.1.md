
# 混合反转策略 HRS V1.1 完整文档
## Hybrid Reversal Strategy (HRS)

## 1. 策略概述

- **目标**：针对币安永续合约中**流动性充足的存量币种**（不限市值），捕捉**暴涨后的做空机会**与**暴跌后的做多机会**。
- **核心理念**：利用“极端情绪 + 衰竭形态 + 拥挤仓位”引发反向波动，通过**多维度量化评分**实现高概率反转交易。
- **交易方向**：双向（做空 / 做多），每币种同时最多持有一个方向，同一币种不可同时持有多空。
- **优势**：高胜率（回测预期 ≥70%），严格风控，低杠杆，完全基于实时公开数据。

---

## 2. 币种池与预筛选

### 2.1 币种池范围
- **初始池**：币安永续合约中**所有币种**（排除以下类型）。
- **排除币种**：
  - 稳定币（USDT、USDC、BUSD、DAI 等）
  - 杠杆代币（如 ETHBULL、BTCDOWN 等）
  - 币安官方标记“观察”或“风险”的币种
- **流动性门槛（必须同时满足）**：
  - 24h 成交额 ≥ **5000 万 USDT**
  - 当前持仓量 OI ≥ **1000 万 USDT**


### 2.2 每日动态筛选（自动执行）
每天早上8:00 (UTC+8) 扫描一次，更新候选池。

| 条件                     | 做空候选                     | 做多候选                     |
|------------------------|------------------------------|------------------------------|
| 24h 涨跌幅              | ≥ 12%                        | ≤ -10%                       |
| 资金费率（年化）        | ≥ 80%                        | ≤ -20%                       |
| 价格偏离 EMA20（4h）    | ≥ 8%（向上偏离）             | ≤ -6%（向下偏离）             |
| OI / 市值比             | ≥ 0.10（拥挤）               | ≤ 0.05（冷清，或不做要求）    |

### 2.3 新币策略冲突屏蔽（重要）
- **规则**：若某个交易对在过去 **3天内**（72小时）曾由【新币做空策略 V4.0】开仓（包括已平仓或仍在持仓），则该交易对**自动排除**在本策略的候选池之外，期间不做任何反转信号监控与开仓。
- **目的**：避免两个策略在同一币种上产生冲突，尊重新币策略的“一币一单”原则。
- **实现方式**：维护一个全局黑名单表，记录每个币种被新币策略开仓的时间戳（精确到小时），每次动态筛选及评分前检查该表。

## 3. 信号评分系统（满分10分，开仓需总分 ≥ 6.5）

### 3.1 合约数据（权重 25%）—— OI / 市值比

| OI / 市值比 | 做空得分 | 做多得分 | 说明                     |
|-------------|----------|----------|--------------------------|
| > 0.25      | 10       | 0        | 极度拥挤，做空极佳       |
| 0.20 – 0.25 | 8        | 1        | 拥挤，有利空头           |
| 0.15 – 0.20 | 6        | 3        | 中等偏拥挤               |
| 0.10 – 0.15 | 4        | 5        | 中性                     |
| 0.05 – 0.10 | 2        | 7        | 冷清，有利多头           |
| < 0.05      | 0        | 10       | 极冷清，做多极佳         |

**数据源**：币安API（OI）+ CoinGecko（市值）  
*若某币种无法获取市值（如极新币），则 OI/市值比 得分按 0 处理（做空得分0，做多得分5），避免错误信号。*

---

### 3.2 技术面（权重 45%）—— 1小时K线形态

#### 做空形态评分（满分10分）

| 条件         | 分值 | 量化标准 |
|--------------|------|----------|
| 三次冲顶     | 0–4  | 最近3-5根K线高点依次降低（差≥0.2%）或同一水平受阻≥3次 |
| 长上影线     | 0–3  | 上影线长度 ≥ 实体长度 × 2，实体为阴线或十字星 |
| 放量滞涨     | 0–3  | 成交量 ≥ 前5根均量×1.5，且收盘价低于前一根高点 |
| **做空技术总分** | **0–10** | 三项相加 |

#### 做多形态评分（满分10分）

| 条件         | 分值 | 量化标准 |
|--------------|------|----------|
| 三次探底     | 0–4  | 最近3-5根K线低点依次抬高（差≥0.2%）或同一支撑≥3次 |
| 长下影线     | 0–3  | 下影线长度 ≥ 实体长度 × 2，实体为阳线或十字星 |
| 放量止跌     | 0–3  | 成交量 ≥ 前5根均量×1.5，收盘价高于前一根低点 |
| **做多技术总分** | **0–10** | 三项相加 |

#### 硬性入场要求（不满足则不开仓）
- 技术总分 ≥ **6.0**
- 做空：三次冲顶分 ≥ 2；做多：三次探底分 ≥ 2

---

### 3.3 情绪面（权重 30%）—— 资金费率（年化）

| 资金费率（年化） | 做空得分 | 做多得分 |
|----------------|----------|----------|
| > 150%         | 10       | 0        |
| 100% – 150%    | 8        | 2        |
| 50% – 100%     | 6        | 4        |
| 0% – 50%       | 3        | 6        |
| -20% – 0%      | 1        | 8        |
| < -20%         | 0        | 10       |

---

### 3.4 总分计算与开仓条件

```
总分 = (合约得分 × 0.25) + (技术得分 × 0.45) + (情绪得分 × 0.30)
```

**开仓必须同时满足**：
- 总分 ≥ **6.5**
- 技术面硬性要求（技术总分 ≥ 6.0，且相应方向的基础形态分 ≥ 2）
- 该币种当前无同向持仓（可反向开仓，但不可同向加仓）

## 4. 进场时机与执行

- **K线周期**：1小时
- **评分触发**：每个1小时K线**收盘后**立即对候选池内所有币种评分
- **最小K线要求**：至少需要 **24根** 已收盘的1小时K线（保证EMA20及形态检测有效）
- **开仓执行**：满足条件后，在当前K线收盘价**市价开仓**，立即挂好止损止盈单
- **方向限制**：同一币种若已持有多单，不可再开空单；反之亦然。可同时持有不同币种的多单和空单。
- **放弃条件**：
  - 形态出现后价格反向突破最近极值（冲顶后新高 / 探底后新低）
  - 开仓信号出现后15分钟内未入场（滑点过大）
  - 币种从候选池中移出（如成交额或OI低于门槛）

## 5. 止损与止盈

### 5.1 止损设置（取三者最大值）

| 止损类型         | 计算公式                     | 说明                     |
|----------------|------------------------------|--------------------------|
| ATR硬止损       | 开仓价 ± 2.5 × ATR(14)       | 多空方向相反             |
| 紧急止损         | 开仓价 × 1.015（空）/ 0.985（多） | 开仓后15分钟内有效       |
| 最小绝对止损     | 开仓价 × 1.05（空）/ 0.95（多）  | 5%硬性下限               |
| **最终止损价**   | **取上述最大值**             | —                        |

### 5.2 止盈设置（分批+移动）

| 目标         | 触发条件                                   | 平仓比例 |
|--------------|--------------------------------------------|----------|
| 第一目标     | 盈利 ≥ 1.5 × ATR                           | 30%      |
| 第二目标     | 盈利 ≥ 3.5 × ATR                           | 40%      |
| 移动止盈     | 从最佳价格回撤 1.5 × ATR                   | 剩余30%  |
| 时间止损     | 持仓超过 **72小时** 且未达第一目标         | 100%     |

## 6. 订单管理（重要）

### 6.1 平仓后自动取消未触发订单
- **规则**：当合约**完全平仓**（无论是止损触发、止盈触发、移动止盈、时间止损还是手动干预）后，系统必须**立即自动撤销**该合约下所有与该平仓方向相关的**未触发订单**，包括：
  - 未触发的止盈限价单（第一目标、第二目标）
  - 未触发的移动止盈条件单
  - 未触发的止损单（若止损单已触发则不存在）
- **目的**：防止已平仓后残留订单在后续价格波动中意外成交，导致无持仓下的净敞口或重复开仓。
- **实现方式**：在平仓回调函数中，调用交易所 `cancel_all_orders(symbol)` 接口，或记录每个订单ID逐一撤销。

## 7. 仓位管理与风控

| 规则                   | 设定                                     |
|------------------------|------------------------------------------|
| 每笔最大亏损           | 账户总资金 **2%**                        |
| 杠杆                   | ≤ **2倍**（固定）                        |
| 单日最多开仓（总）     | **3个币种**（含多空）                    |
| 同一方向单日最多开仓   | **2个**                                  |
| 连续亏损暂停           | 连续3笔亏损后，暂停交易 **2天**          |
| 最大回撤熔断           | 累计亏损 ≥ **15%** 时暂停交易 **一周**   |
| 黑名单机制             | 触发止损后24小时内反向波动超过止损价5%，该币种**永久禁止** |

**仓位计算示例**（账户1000U，做空止损幅度5%）：
- 最大亏损 = 1000 × 2% = 20U
- 开仓价值 = 20 / 5% = 400U
- 2倍杠杆 → 保证金 = 400 / 2 = 200U（佔20%）

## 8. 回测建议与方法

### 8.1 回测数据要求
- 时间范围：至少 **6个月**（推荐1年）
- 币种：币安永续合约中满足流动性门槛的币种（动态筛选）
- K线数据：1小时K线（OHLCV），OI历史数据，资金费率历史

### 8.2 回测步骤
1. **复现候选池筛选**：每日动态筛选，需模拟每日8:00的币种状态及流动性门槛。
2. **形态检测算法**：编写自动化脚本，严格按照文档中的量化标准判定三次冲顶/探底、影线、放量。
3. **计算总分**：每个1小时K线收盘后对候选池内币种评分，记录符合条件的开仓信号。
4. **模拟交易**：按文档的止盈止损、仓位管理进行逐笔交易，记录盈亏、胜率、最大回撤。
5. **参数优化**：调整评分阈值（如总分从6.5调整到6.0或7.0）、ATR倍数等，观察稳定性。

### 8.3 预期回测指标（参考逻辑）
- **胜率**：70% – 85%（反转行情确定性较强）
- **盈亏比**：1.5 : 1 至 2.5 : 1
- **年化收益率**：50% – 150%（取决于行情波动与仓位）
- **最大回撤**：≤ 15%

> 建议使用 **前向测试**（Walk‑Forward）验证参数稳健性。

## 9. 实盘注意事项

1. **滑点与流动性**：避免在极端波动或低流动性币种开仓，优先选择24h成交额 > 5000万 USDT 且 OI > 2000万 USDT 的币种。
2. **资金费率结算影响**：每日00:00、08:00、16:00 (UTC) 结算，结算前后情绪分可能剧烈变化，建议避开结算前5分钟入场。
3. **多空同时持仓**：若遇到大盘极端行情，多空仓位可能同时亏损（双杀），建议设置**总风险敞口**（净 Delta 不超过账户资金的30%）。
4. **黑名单管理**：建议使用数据库记录永久禁用的币种，避免再次入场。
5. **订单取消机制**：务必在代码中实现平仓后自动取消未触发订单，并定期（如每小时）检查残留订单做二次清理。
6. **定期复盘**：每周统计胜率、盈亏比、实际滑点，动态调整 OI/市值比分档。
