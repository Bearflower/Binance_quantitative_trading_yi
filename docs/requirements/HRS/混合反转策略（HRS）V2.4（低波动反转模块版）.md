## 第二部分：HRS V2.4 完整文档

## 1. 策略概述

- **目标**：针对币安永续合约中**流动性充足的存量币种**，捕捉**暴涨后的做空机会**与**暴跌后的做多机会**，同时覆盖低波动震荡市中的均值回归机会。
- **核心理念**：采用 **"三轨并行"** 机制，覆盖不同市场状态：
  - **轨道 A（标准反转）**：利用"极端情绪 + 衰竭形态（三次探底/冲顶）"入场，适用于中高波动趋势市。
  - **轨道 B（极端市场模块 EMM）**：利用"价格极端偏离 + 费率极端 + 仓位拥挤"三重共振入场，绕过形态检测，适用于高波动单边市。
  - **轨道 C（低波动反转模块 LV-RM）**：利用"布林带触轨 + RSI超买超卖 + 4h趋势过滤"入场，专门捕捉低波动震荡市中的均值回归机会。**← V2.4 新增**

### 1.1 三轨覆盖的市场状态

| 市场状态 | 特征 | 触发模块 |
|----------|------|----------|
| 高波动单边市 | 24h 涨跌幅 > 15%，趋势强劲 | **EMM** |
| 中波动趋势市 | 24h 涨跌幅 5-15%，有明显形态 | **标准模式** |
| 低波动震荡市 | 24h 涨跌幅 < 5%，价格在区间内反复 | **LV-RM** ← 新增 |
| 极低波动横盘 | ATR 持续收缩，无明确方向 | 无（等待） |

### 1.2 三轨领地划分原则

```
趋势确立时（|涨跌幅| ≥ 5%） → 交给标准模式（如有形态）或 EMM（如极端）
趋势缺失时（|涨跌幅| < 5%） → 交给 LV-RM（布林带触轨）
```

每个模块只在自己最擅长的市场状态下工作，避免重复计算。

## 2. 币种池与预筛选

### 2.1 币种池范围
- **初始池**：币安永续合约中**所有币种**（排除稳定币、杠杆代币、观察标签币）。
- **流动性门槛（必须同时满足）**：
  - 24h 成交额 ≥ **5000 万 USDT**
  - 当前持仓量 OI ≥ **1000 万 USDT**

### 2.2 每日动态筛选（自动执行）
每天早上 **8:05 (UTC+8)** 执行全市场扫描，动态计算当日阈值。

#### 步骤 1：采集全市场数据
获取所有 USDT 永续合约的以下数据：24h 涨跌幅、资金费率（年化）、OI / 市值比、价格偏离 EMA20（4h）。

#### 步骤 2：计算动态阈值（基于全市场分位数） [⚠ V2.5 已变更]

| 筛选维度 | 做空候选条件 | 做多候选条件 |
|----------|-------------|-------------|
| **24h 涨跌幅** | ≥ 12% | ≤ -10% |
| **资金费率（年化）** | ≥ 市场 **80分位数** | ≤ 市场 **20分位数** |
| **OI / 市值比** | ≥ 市场 **80分位数** | ≤ 市场 **20分位数** |
| **EMA20(4h)偏离** | ≥ 市场 **70分位数** | ≤ 市场 **30分位数** |

**配置常量（可调）**：
```python
CONFIG = {
    "rate_percentile_short": 0.80,
    "rate_percentile_long": 0.20,
    "oi_percentile_short": 0.80,
    "oi_percentile_long": 0.20,
    "ema_percentile_short": 0.70,
    "ema_percentile_long": 0.30,
}
```

#### 步骤 3：筛选候选池 [⚠ V2.5 已变更]
- 满足做空方向所有条件的币种 → 做空候选池
- 满足做多方向所有条件的币种 → 做多候选池

#### 步骤 4：LV-RM 扫描范围（V2.4 新增） [⚠ V2.5 已变更]

LV-RM 模块**不直接扫描所有流动性币种**，而是遵循以下流程：

1. 标准模式/EMM 扫描完成后，收集**所有落选币种**（即通过流动性门槛但未满足标准模式/EMM 条件的币种）
2. 从落选币种中筛选出 **24h 涨跌幅 < 5%** 的低波动币种
3. 对这些低波动币种执行 LV-RM 检查

> **逻辑依据**：趋势确立的币种（|涨跌幅|≥5%）交给标准模式或 EMM 处理，LV-RM 只处理趋势缺失的币种，三者形成清晰的"领地划分"。

## 3. 信号评分系统（三轨并行）

### 3.1 合约数据（权重 25%）—— OI / 市值比（通用）

| OI / 市值比 | 做空得分 | 做多得分 | 说明 |
|-------------|----------|----------|------|
| > 0.25 | 10 | 0 | 极度拥挤 |
| 0.20 – 0.25 | 8 | 1 | 拥挤 |
| 0.15 – 0.20 | 6 | 3 | 中等偏拥挤 |
| 0.10 – 0.15 | 4 | 5 | 中性 |
| 0.05 – 0.10 | 2 | 7 | 冷清 |
| < 0.05 | 0 | 10 | 极冷清 |

### 3.2 情绪面（权重 30%）—— 资金费率（通用）

| 年化费率 | 做空得分 | 做多得分 |
|----------|----------|----------|
| > 150% | 10 | 0 |
| 100% – 150% | 8 | 2 |
| 50% – 100% | 6 | 4 |
| 0% – 50% | 3 | 6 |
| -20% – 0% | 1 | 8 |
| < -20% | 0 | 10 |

### 3.3 轨道 A：标准模式（权重 45%）

适用于中高波动趋势市，基于K线形态检测。

| 条件 | 分值 | 量化标准 |
|------|------|----------|
| **三次冲顶/探底** | 0–4 | 最近 **5根** K线高点/低点依次降低/抬高（差≥0.2%），或同一水平受阻/支撑≥3次 |
| **长影线** | 0–3 | 上/下影线 ≥ 实体 × 2 |
| **放量滞涨/止跌** | 0–3 | 成交量 ≥ 前5根均量 × 1.5 |
| **极端行情加分** | +1.5 | 做多：跌幅≥15%；做空：涨幅≥15% |
| **标准技术总分** | 0–10 | 三项相加 + 加分，封顶10分 |

**入场条件**：标准总分 ≥ 6.0，且技术分 ≥ 4.0，三次形态基础分 ≥ 1.0。

### 3.4 轨道 B：极端市场模块 EMM（权重 45%）

适用于高波动单边市，绕过形态检测。

#### EMM 做多触发条件（三条件 AND）

| 条件 | 阈值 |
|------|------|
| **24h 涨跌幅** | ≤ -15% |
| **资金费率** | ≤ 市场 **10分位数** |
| **OI / 市值比** | ≥ 市场 **90分位数** |

#### EMM 做空触发条件（三条件 AND）

| 条件 | 阈值 |
|------|------|
| **24h 涨跌幅** | ≥ +15% |
| **资金费率** | ≥ 市场 **90分位数** |
| **OI / 市值比** | ≥ 市场 **90分位数** |

#### EMM 技术得分 = 5.0（固定值）

**入场条件**：EMM 总分 ≥ 6.0。

### 3.5 轨道 C：低波动反转模块 LV-RM（权重 45%）—— V2.4 新增

适用于低波动震荡市，基于布林带 + RSI + 4h趋势过滤。

#### LV-RM 做多触发条件（必须全部满足）

| 维度 | 时间框架 | 阈值 | 作用 |
|------|----------|------|------|
| **价格位置** | **1h** | 价格 ≤ 布林带下轨（20,2） | 核心执行信号：价格处于历史区间低位 |
| **RSI(14)** | **1h** | ≤ 30 | 核心执行信号：超卖区域 |
| **资金费率** | 实时 | ≤ -10% 年化 | 情绪验证：空头拥挤 |
| **K线确认** | **1h** | 收盘价 > 前一根K线最低价 | 止跌确认，防止继续暴跌 |
| **🆕 趋势过滤（一票否决）** | **4h** | 价格 > EMA20 且 价格 ≥ EMA20 × 0.97 | 防止在4h暴跌趋势中逆势抄底 |

> **做多趋势过滤逻辑**：必须满足 **4h级别价格在EMA20上方（多头排列）**，且偏离不超过-3%。如果4h价格远低于EMA20，说明大趋势仍在暴跌，此时1h的触轨信号是"接飞刀"，直接拒绝。

#### LV-RM 做空触发条件（必须全部满足）

| 维度 | 时间框架 | 阈值 | 作用 |
|------|----------|------|------|
| **价格位置** | **1h** | 价格 ≥ 布林带上轨（20,2） | 核心执行信号：价格处于历史区间高位 |
| **RSI(14)** | **1h** | ≥ 70 | 核心执行信号：超买区域 |
| **资金费率** | 实时 | ≥ 30% 年化 | 情绪验证：多头拥挤 |
| **K线确认** | **1h** | 收盘价 < 前一根K线最高价 | 滞涨确认，防止继续暴涨 |
| **🆕 趋势过滤（一票否决）** | **4h** | 价格 < EMA20 且 价格 ≤ EMA20 × 1.03 | 防止在4h暴涨趋势中逆势做空 |

> **做空趋势过滤逻辑**：必须满足 **4h级别价格在EMA20下方（空头排列）**，且偏离不超过+3%。如果4h价格远高于EMA20，说明大趋势仍在暴涨，此时1h的触轨信号是"接升空火箭"，直接拒绝。

#### 量化示例：趋势过滤

- **做多**：若4h EMA20 = 1.00，则允许价格范围为 **1.00 ~ 1.03**（必须 > 1.00 且 ≤ 1.03）
- **做空**：若4h EMA20 = 1.00，则允许价格范围为 **0.97 ~ 1.00**（必须 < 1.00 且 ≥ 0.97）

> 注意：做多和做空的价格区间是**互斥**的，两者不会同时发生。

#### LV 技术评分（V2.4 修订版）

**取消费率双重权重**，费率仅在情绪分中体现（30%权重）。LV技术分仅包含布林带触轨和RSI两项。

| 条件 | 分值 | 量化方式 |
|------|------|----------|
| **布林带触轨** | 0–4 | 基础分2 + min(突破幅度 × 2, 2)，突破幅度 = |收盘价 - 轨道边界| / 布林带宽度 |
| **RSI 达标** | 0–3 | RSI≤30（多）/≥70（空）即得3分 |
| **LV 技术总分** | **0–7** | 两项相加，封顶7分 |

**布林带触轨评分公式说明**：
```
布林带宽度 = 上轨 - 下轨
突破幅度 = |收盘价 - 轨道边界| / 布林带宽度
布林带触轨得分 = 2 + min(突破幅度 × 2, 2)   # 范围 2-4 分
```
- 刚触轨：得2分基础分
- 突破幅度越大，得分越高，封顶4分

#### LV-RM 总分计算

```
LV总分 = (合约分 × 0.25) + (LV技术分 × 0.45) + (情绪分 × 0.30)
```

**入场条件**：LV总分 ≥ 6.0，且 LV技术分 ≥ 4.0。

> **LV技术分 ≥ 4.0 的意义**：仅靠布林带触轨（最高4分）无法单独入场，必须配合 RSI 达标，确保信号是"多重验证的反转"而非"单纯的极端价格"。

## 4. 进场逻辑与执行（三轨决策流） [⚠ V2.5 已变更]

在每个 1 小时 K 线收盘后，按以下**固定顺序**判断：

```
1. 检查完整 EMM（3/3 条件）
   └── 触发 → 入场（轨道 B）✅

2. 检查半 EMM（2/3 条件）
   └── 触发 → 合约分=Max(原始,3.0)，技术分=5.0，总分≥5.0 → 入场 ✅

3. 检查标准模式（轨道 A）
   └── 技术分=形态分+加分，技术≥4.0，形态≥1.0，总分≥6.0 → 入场 ✅

4. 收集落选币种 → 筛选 |涨跌幅|<5% 的低波动币种 → 执行 LV-RM 检查（轨道 C）
   └── 检查布林带、RSI、费率、K线确认、4h趋势过滤 → 全部满足 → LV总分≥6.0，LV技术≥4.0 → 入场 ✅

5. 均不满足 → 放弃 ❌
```

### 4.1 资金费率获取规则
- 所有模块的评分均使用 K 线收盘时间点的**历史费率快照**，禁止使用实时费率。

## 5. 止损与止盈

### 5.1 止损设置（三轨各自配置）

| 模式 | ATR止损 | 紧急止损 | 最小绝对止损 | 最终取法 |
|------|---------|---------|-------------|----------|
| **标准模式 / EMM（做空）** | 开仓价 + 2.5×ATR | 开仓价 × 1.015 | 开仓价 × 1.05 | 取三者**最大值** |
| **标准模式 / EMM（做多）** | 开仓价 - 2.5×ATR | 开仓价 × 0.985 | 开仓价 × 0.95 | 取三者**最小值** |
| **LV-RM（做空）** | 开仓价 + **1.5×ATR** | 开仓价 × **1.01** | 开仓价 × **1.03** | 取三者**最大值** |
| **LV-RM（做多）** | 开仓价 - **1.5×ATR** | 开仓价 × **0.99** | 开仓价 × **0.97** | 取三者**最小值** |

### 5.2 止盈设置（三轨各自配置）

| 目标 | 标准模式 / EMM | LV-RM |
|------|---------------|-------|
| 第一目标 | 盈利 ≥ 1.5×ATR → 平30% | 盈利 ≥ **1.0×ATR** → 平30% |
| 第二目标 | 盈利 ≥ 3.5×ATR → 平40% | 盈利 ≥ **2.0×ATR** → 平40% |
| 移动止盈 | 从最佳价格回撤 1.5×ATR → 平30% | 从最佳价格回撤 **1.0×ATR** → 平30% |
| 时间止损 | 持仓超过 **72小时** → 100% 平仓 | 持仓超过 **48小时** → 100% 平仓 |

> **LV-RM 止盈逻辑**：LV-RM 属于均值回归交易，通常目标利润为回归布林带中轨（约 1.0–1.5 倍 ATR）。因此降低止盈目标，更紧的止损止盈也更适合快进快出的低波动交易风格。
