### 3.5 🚀 极端市场模块 EMM（轨道 B）—— V2.0-C 新增

当市场满足以下**极端条件**时，策略将**自动绕过**标准技术面（三次探底/冲顶等）的苛刻要求，直接触发开仓信号。

#### 3.5.1 EMM 做多触发条件（超跌反弹）
必须 **同时满足** 以下 3 项硬性指标：

| 条件 | 阈值 | 逻辑解释 |
| :--- | :--- | :--- |
| **24h 涨跌幅** | ≤ **-20%** | 市场出现极端恐慌性抛售 |
| **资金费率（年化）** | ≤ **-50%** | 空头拥挤至极点，做空成本极高 |
| **OI / 市值比** | ≥ **0.15** | 合约持仓量巨大，一旦反弹容易引发逼空 |

#### 3.5.2 EMM 做空触发条件（超涨暴跌）
必须 **同时满足** 以下 3 项硬性指标：

| 条件 | 阈值 | 逻辑解释 |
| :--- | :--- | :--- |
| **24h 涨跌幅** | ≥ **20%** | 市场出现极端FOMO式拉升 |
| **资金费率（年化）** | ≥ **150%** | 多头拥挤至极点，做多成本极高 |
| **OI / 市值比** | ≥ **0.25** | 合约持仓量巨大，一旦下跌容易引发多头踩踏 |

#### 3.5.3 EMM 技术得分赋值规则
当 EMM 条件触发时，**不再计算标准技术形态得分**，直接赋值：

- **EMM 技术得分 = 5.0**（固定值）

> **为什么是 5.0？**  
> 5.0 分既满足了“技术硬门槛 ≥ 4.0”的要求，又在加权计算中给予了适中的权重。即使合约得分仅为 0（极端情况），5.0×0.45=2.25 分，加上情绪满分 3.0 分，总分也有 5.25 分，此时若合约得分有 3 分（0.75），即可达到 6.0 门槛，确保了只在“极端情绪+拥挤仓位”真正共振时入场。

#### 3.5.4 EMM 总分计算（轨道 B）
```
EMM 总分 = (合约得分 × 0.25) + (5.0 × 0.45) + (情绪得分 × 0.30)
```
- **入场条件**：EMM 总分 ≥ **6.0**，且无任何一票否决项（如新币策略冲突、流动性降级等）。

## 4. 进场逻辑与执行（双轨决策流）

### 4.1 决策优先级
在每个 1 小时 K 线收盘后，按以下顺序判断：

1. **第一步：检查 EMM 条件**
   - 如果满足第 3.5 节的 EMM 触发条件 → 计算 EMM 总分。
   - 若 EMM 总分 ≥ 6.0 → **立即入场（轨道 B）**，跳过标准评分。
2. **第二步：检查标准模式（轨道 A）**
   - 如果未触发 EMM，则计算标准总分。
   - 若标准总分 ≥ 6.0，且满足技术硬门槛（技术分≥4.0，形态基础分≥1.0）→ **入场（轨道 A）**。
3. **第三步：均不满足** → 放弃本次信号，等待下一根 K 线。

### 4.2 资金费率获取规则（硬编码）
- 评分时使用的资金费率必须是该 K 线**收盘时间点**对应的**历史费率快照**，禁止使用实时费率。

### 4.3 放弃条件
- 标准模式：形态失效（反向突破极值）、开仓延迟（15 分钟未完全成交）、流动性降级、新币策略冲突。
- EMM 模式：若发出市价单后 15 分钟内未完全成交，同样视为放弃（但 EMM 条件触发后，不检查“反向突破极值”，因为极值本身已被极端行情打破）。

### 4.4 双向信号冲突处理
若同一币种同时满足 EMM 做多和 EMM 做空（理论上不可能，因涨跌幅无法同时满足），优先选择 EMM 总分高的一方。

## 8. 实盘注意事项（V2.0-C 新增）

1. **EMM 的“双刃剑”效应**：EMM 旨在捕捉尖底/尖顶，但若极端行情后继续沿原方向大幅运行（如黑天鹅连续暴跌），EMM 入场可能导致止损。务必严格执行 5% 绝对止损。
2. **EMM 触发后的监控**：EMM 入场通常发生在波动剧烈时，滑点可能较大。建议设置限价保护（如接受 0.5% 滑点），超出则拒绝成交。
3. **数据依赖**：OI / 市值比在 EMM 中至关重要。若某币种市值数据缺失，EMM 将无法触发（因无法计算 OI/市值），此时请参考标准模式。
