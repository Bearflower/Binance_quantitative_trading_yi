## 第一部分：V2.4 → V2.5 修改点清单

| 修改项 | V2.4（旧值） | V2.5（新值） | 修改理由 |
|--------|-------------|-------------|----------|
| **候选池逻辑** | 多重 AND（所有条件必须同时满足） | **宽松 OR（满足任意 2 个条件即可入池，4 个维度任意组合）** | AND 条件过多导致候选池长期为空 |
| **涨跌幅角色** | 硬性条件（必须满足） | **作为“任意2条件”之一，非硬性** | 低波动市场下涨跌幅不达标但有价值的币种也能入池 |
| **分位数阈值** | 做空：费率≥80分位，OI≥80分位，EMA≥70分位；做多：费率≤20分位，OI≤20分位，EMA≤30分位 | **全部改为 50 分位（中位数）** | 降低门槛，与“宽松 OR”协同 |
| **涨跌幅阈值** | 做空≥12%，做多≤-10% | **做空≥8%，做多≤-8%** | 与代码保持一致，同步放宽 |
| **LV-RM 扫描范围** | 候选池落选 + \|涨跌幅\| < 5% | **全市场流动性币种直接筛选 \|涨跌幅\| < 8%（完全独立于候选池）** | 候选池为空时 LV-RM 仍可正常工作 |
| **版本号** | V2.4 | **V2.5** | 核心逻辑升级 |


## 第二部分：V2.5 候选池新逻辑详解

### 新逻辑示例（做多方向）

```
候选条件（做多方向，4 个维度）：
  A. 24h 涨跌幅 ≤ -8%
  B. 资金费率 ≤ 市场 50 分位数（中位数）
  C. OI / 市值比 ≤ 市场 50 分位数（中位数）
  D. EMA20(4h) 偏离 ≤ 市场 50 分位数（中位数）

入池规则：满足 A、B、C、D 中任意 2 个条件 → 进入候选池
（4 个维度任意组合，共 6 种组合方式：AB、AC、AD、BC、BD、CD）
```

### 为什么“任意 2 条件”不限制组合？

限制组合等价于人为预设市场特征（例如只允许“涨跌幅+费率”组合，意味着认为只有“下跌且费率低”的币种才有价值）。V2.5 的设计哲学是：**候选池只管“粗筛”，不预设市场特征**。哪怕是一个不跌反涨但费率和 OI 都极端的币种，也可以进入候选池——最终由评分系统决定值不值得入场。

### 预期效果对比

| 场景 | V2.4（AND） | V2.5（OR，任意2个） |
|------|-------------|-------------------|
| 当前市场做多候选 | 0 个 | **预计 8-12 个** |
| 当前市场做空候选 | 0 个 | **预计 5-8 个** |
| 策略可用性 | 几乎停摆 | **正常运转** |


## 第三部分：HRS V2.5 完整文档


## 1. 策略概述

- **目标**：针对币安永续合约中**流动性充足的存量币种**，捕捉**暴涨后的做空机会**与**暴跌后的做多机会**，覆盖全市场状态。
- **核心理念**：采用 **“三轨并行 + 多时间框架”** 机制：

  - **轨道 A（标准反转）**：利用“衰竭形态（三次探底/冲顶）”入场，适用于中高波动趋势市。
  - **轨道 B（极端市场模块 EMM）**：利用“价格极端偏离 + 费率极端 + 仓位拥挤”三重共振入场，适用于高波动单边市。
  - **轨道 C（低波动反转模块 LV-RM）**：利用 **1小时** 布林带触轨 + RSI 超买超卖作为**执行信号**，专门捕捉低波动震荡市中的均值回归机会（V2.5：**完全独立于候选池**）。

### 1.1 V2.5 核心变化：候选池扩容 + LV-RM 独立

V2.5 的核心是**重构候选池筛选逻辑**，从“多重 AND（所有条件必须同时满足）”改为 **“宽松 OR（满足任意 2 个条件即可入池，不限组合）”**，同时将分位数阈值从极值（20/80 分位）降至中位数（50 分位），并将涨跌幅阈值与代码统一为 8%。此外，**LV-RM 模块完全独立于候选池**，从全市场流动性币种中直接筛选涨跌幅<8%的币种，确保候选池为空时 LV-RM 仍可正常运行。


## 2. 币种池与预筛选

### 2.1 币种池范围

#### 通用流动性门槛（所有模块共用）
- 24h 成交额 ≥ **5000 万 USDT**
- 当前持仓量 OI ≥ **1000 万 USDT**

#### LV-RM 扫描范围（V2.5：完全独立）
LV-RM **不再依赖候选池落选币种**，改为直接从全市场流动性币种中筛选：
1. 所有满足流动性门槛的币种（24h 成交额 ≥5000万U，OI ≥1000万U）
2. 且 **|24h 涨跌幅| < 8%**（低波动震荡环境）

> **独立理由**：候选池长期为空时，依赖候选池落选币种的 LV-RM 将同样失效。独立后，LV-RM 在候选池为空时仍可正常工作，确保策略在低波动市场中持续运转。

### 2.2 每日动态筛选（V2.5 候选池新逻辑）

每天早上 **8:05 (UTC+8)** 执行全市场扫描，动态计算当日阈值。

#### 步骤 1：采集全市场数据
获取所有 USDT 永续合约的以下数据：24h 涨跌幅、资金费率（年化）、OI / 市值比、价格偏离 EMA20（4h）。

#### 步骤 2：计算动态阈值（V2.5：中位数）

| 筛选维度 | 做空候选条件 | 做多候选条件 | V2.4 旧值 |
|----------|-------------|-------------|-----------|
| **24h 涨跌幅** | ≥ **8%**（作为4个维度之一） | ≤ **-8%**（作为4个维度之一） | ≥12% / ≤-10% |
| **资金费率（年化）** | ≥ 市场 **50分位数** | ≤ 市场 **50分位数** | 80分位 / 20分位 |
| **OI / 市值比** | ≥ 市场 **50分位数** | ≤ 市场 **50分位数** | 80分位 / 20分位 |
| **EMA20(4h)偏离** | ≥ 市场 **50分位数** | ≤ 市场 **50分位数** | 70分位 / 30分位 |

#### 步骤 3：候选池入池规则（V2.5 核心变更）

**入池规则**：满足以下 4 个条件中 **任意 2 个** 即可进入候选池（不限组合）。

**做多候选池条件**：
| 编号 | 条件 | 阈值 |
|------|------|------|
| A | 24h 涨跌幅 | ≤ -8% |
| B | 资金费率（年化） | ≤ 市场 50 分位数 |
| C | OI / 市值比 | ≤ 市场 50 分位数 |
| D | EMA20(4h) 偏离 | ≤ 市场 50 分位数 |

**做空候选池条件**：
| 编号 | 条件 | 阈值 |
|------|------|------|
| A | 24h 涨跌幅 | ≥ 8% |
| B | 资金费率（年化） | ≥ 市场 50 分位数 |
| C | OI / 市值比 | ≥ 市场 50 分位数 |
| D | EMA20(4h) 偏离 | ≥ 市场 50 分位数 |

> **示例**：某币种做多方向：涨跌幅 -9%（满足 A），费率 ≤ 中位数（满足 B），但 OI/市值比 > 中位数（不满足 C），EMA 偏离 > 中位数（不满足 D）→ 满足 A+B 共 2 个条件 → **进入候选池**。

> **组合全放开说明**：允许任意 2 个条件组合（AB、AC、AD、BC、BD、CD），不限制组合类型。候选池只管粗筛，最终入场由评分系统把关。

**配置常量**：
```python
CONFIG = {
    # V2.5 候选池新配置
    "candidate_pool": {
        "logic": "or_any_2",          # 满足任意2个条件
        "change_threshold": 0.08,     # 涨跌幅阈值（做空≥8%，做多≤-8%）
        "rate_percentile": 0.50,      # 中位数
        "oi_percentile": 0.50,        # 中位数
        "ema_percentile": 0.50,       # 中位数
    },
    # EMM 仍然使用极端分位数（不变）
    "emm": {
        "rate_percentile": 0.10,      # 做多 ≤10分位 / 做空 ≥90分位
        "oi_percentile": 0.90,        # ≥90分位
    },
    # LV-RM 独立配置
    "lv_rm": {
        "scan_mode": "full_market",   # 全市场流动性币种，不依赖候选池
        "max_abs_change_pct": 0.08,   # |涨跌幅| < 8%
    }
}
```


## 3. 信号评分系统（三轨并行）

### 3.1 合约数据（权重 25%）—— OI / 市值比

| OI / 市值比 | 做空得分 | 做多得分 |
|-------------|----------|----------|
| > 0.25 | 10 | 0 |
| 0.20 – 0.25 | 8 | 1 |
| 0.15 – 0.20 | 6 | 3 |
| 0.10 – 0.15 | 4 | 5 |
| 0.05 – 0.10 | 2 | 7 |
| < 0.05 | 0 | 10 |

### 3.2 情绪面（权重 30%）—— 资金费率

| 年化费率 | 做空得分 | 做多得分 |
|----------|----------|----------|
| > 150% | 10 | 0 |
| 100% – 150% | 8 | 2 |
| 50% – 100% | 6 | 4 |
| 0% – 50% | 3 | 6 |
| -20% – 0% | 1 | 8 |
| < -20% | 0 | 10 |


### 3.3 轨道 A：标准模式（权重 45%）

| 条件 | 分值 | 量化标准 |
|------|------|----------|
| **三次冲顶/探底** | 0–4 | 最近 **5根 1h** K线高点/低点依次降低/抬高（差≥0.2%），或同一水平受阻/支撑≥3次 |
| **长影线** | 0–3 | 上/下影线 ≥ 实体 × 2 |
| **放量滞涨/止跌** | 0–3 | 成交量 ≥ 前5根均量 × 1.5 |
| **极端行情加分** | +1.5 | 做多：跌幅≥15%；做空：涨幅≥15% |
| **标准技术总分** | 0–10 | 三项相加 + 加分，封顶10分 |

**入场条件**：标准总分 ≥ 6.0，且技术分 ≥ 4.0，三次形态基础分 ≥ 1.0。


### 3.4 轨道 B：极端市场模块 EMM（权重 45%）

**EMM 阈值保持不变**（仍使用极端分位数）：
- 做多：跌幅≤-15% + 费率≤10分位 + OI/市值≥90分位
- 做空：涨幅≥+15% + 费率≥90分位 + OI/市值≥90分位

**EMM 技术得分 = 5.0（固定值）**，入场条件：EMM 总分 ≥ 6.0。


### 3.5 轨道 C：低波动反转模块 LV-RM（权重 45%）

#### 3.5.1 扫描范围（V2.5：完全独立）
LV-RM **不再依赖候选池落选币种**，直接从全市场流动性币种中筛选：
1. 所有满足流动性门槛的币种（24h 成交额 ≥5000万U，OI ≥1000万U）
2. 且 **|24h 涨跌幅| < 8%**

> 不满足上述条件的币种，LV-RM 直接跳过，不进行后续检查。

#### 3.5.2 LV-RM 触发条件（不变）

| 序号 | 条件 | 时间框架 | 做多阈值 | 做空阈值 |
|------|------|----------|----------|----------|
| ① | **布林带位置** | 1h | 价格 ≤ 下轨 | 价格 ≥ 上轨 |
| ② | **RSI(14)** | 1h | ≤ 30 | ≥ 70 |
| ③ | **资金费率** | 实时 | ≤ -10% | ≥ 30% |
| ④ | **K线确认** | 1h | 收盘价 > 前低 | 收盘价 < 前高 |
| ⑤ | **趋势过滤** | 4h | 价格>EMA20且≥EMA20×0.97 | 价格<EMA20且≤EMA20×1.03 |

#### 3.5.3 LV 技术评分（不变）
| 条件 | 分值 | 量化标准 |
|------|------|----------|
| **布林带触轨** | 0–4 | 基础 2 分 + 比例加分，封顶 4 分 |
| **RSI 达标** | 0–3 | 达标得 3 分，否则 0 分 |
| **LV 技术总分** | **0–7** | 两项相加 |

**入场条件**：LV总分 ≥ 6.0，且 LV技术分 ≥ 4.0。


## 4. 进场逻辑与执行（四步决策流）

```
1. 检查完整 EMM（3/3 条件）→ 入场 ✅
2. 检查半 EMM（2/3 条件）→ 入场 ✅
3. 检查标准模式（轨道 A）→ 入场 ✅
4. 检查 LV-RM（轨道 C，全市场独立扫描）→ 入场 ✅
5. 均不满足 → 放弃 ❌
```
