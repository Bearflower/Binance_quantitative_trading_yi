```
## 4. 进场时机与执行

### 4.1 K线预热机制（候选池新币种）

每日早8:00筛选出的新候选币种，若本地存储的1小时K线数量不足 **24根**，执行以下操作：

1. **拉取历史数据**：通过币安API获取该币种 **最近7天的1小时K线**（最多168根）。
2. **补足缓存**：将历史K线与现有数据合并去重，按时间排序存储。
3. **激活条件**：若补足后K线总数 ≥ 24根，该币种即可参与下一个整点收盘后的评分；若仍不足24根（如新币上线不足24小时），则暂不评分，等待自然积累满24根后再自动激活。
4. **增量更新**：激活后，通过WebSocket或定时任务订阅实时1小时K线，每完成一根新K线即触发评分。

> 此机制确保币种一旦满足流动性门槛，无需等待24小时即可开始监控，同时保证技术指标（EMA20、ATR等）计算所需的最小数据量。
```
