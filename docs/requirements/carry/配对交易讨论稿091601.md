# 相对价值策略族 产品文档

**版本**：v0.1（草案）
**日期**：2026-09-16
**状态**：待评审
**范围**：同一/跨市场、多层的相对价值与统计套利策略族

---

## 1. 背景与目标

### 1.1 背景

前期已证伪三个方向：动量、regime、朴素 z-score 配对交易。结论不是"这些方向永远无效"，而是"朴素实现 + 本币池 + 本参数集"无稳定 alpha。

核心教训：

- 没有回归机制的价差，本质是随机游走，不是套利；
- 相关性不等于协整；
- 统计套利在无物理约束时，是概率游戏，不是无风险套利。

### 1.2 目标

构建一套**按回归机制硬度分层**的相对价值策略族：

- 硬层（L0–L2）作为基本盘，追求稳定、低回撤；
- 准硬层（L3）作为补充；
- 软层（L4）作为卫星，小仓位、严格风控；
- 只共用数据、执行、风控基础设施，**每层独立回测、独立风控、独立资金分配**。

### 1.3 非目标

- 不做 L5（泛赛道）、L6（Meme）纯统计配对；
- 不追求单一"全能回测"覆盖所有层；
- 不把统计套利包装成"无风险套利"。

---

## 2. 核心原则

### 2.1 回归硬度决定层级

策略分层不看资产类别，看**价差偏离后是否有物理/结构性力量把它拉回**。

| 硬度 | 回归机制 | 是否保证回归 |
|---|---|---|
| 极硬 | 资金费率、到期收敛、兑换锚 | 结构性保证 |
| 硬 | 跨所搬砖、铸造/赎回 | 套利者会吃回 |
| 准硬 | 近似替代 + 统计 | 大概率回归 |
| 软 | 共同因子 + 统计套利者 | 可能回归，可能永久断裂 |

### 2.2 经济逻辑先于统计

任何配对/价差，先回答三个问题：

1. 偏离怎么产生的？谁在错价？
2. 回归的物理机制是什么？谁有动力拉回？
3. 为什么这个机制现在还有效？为什么别人没吃掉？

答不上来，直接淘汰，不进统计检验。

### 2.3 每层独立

- 独立回测、独立参数、独立风控、独立净值曲线；
- 只共用：数据管道、执行接口、风控框架、监控告警。

### 2.4 诚实标注

文档中所有参数为**建议初值**，需回测验证。已证伪结论单独列出，防止重复踩坑。

## 3. 策略族分层定义

### L0：同一币 · 同一所 · 不同形式

**品种**
- 现货 vs 永续（基差 / 资金费率）
- 交割 vs 永续（到期收敛）
- 稳定币对（USDC/USDT）
- 质押凭证 vs 原生（所内现货，如 WBETH/ETH）

**回归机制**：资金费率、到期收敛、兑换锚。结构性保证。

**业务逻辑**：赚资金费率/基差偏离 + 流动性溢价。

**选品逻辑**
- 只看基差/费率是否超过成本阈值；
- 计算：净基差 = 基差 − 手续费 − 滑点 − 资金费 − 保证金成本；
- 超过阈值才做。

**执行**：单所、双腿、原子性下单。

**风控**：费率反转、流动性、保证金、单所集中度。

**优先级**：★ ★ ★ ★ ★（最优先）

---

### L1：同一币 · 跨所

**品种**
- A 所永续 vs B 所永续
- A 所现货 vs B 所永续

**回归机制**：搬砖 + 费率差。硬。

**业务逻辑**：赚跨所价差 + 资金调拨效率。

**选品逻辑**
- 价差 > 手续费 + 滑点 + 资金调拨成本 + 延迟风险溢价；
- 需考虑提币暂停、网络拥堵、交易所风险。

**执行**：多所账户、资金调拨、延迟管理、部分成交处理。

**风控**：交易所风险、提币暂停、延迟、单所限额。

**优先级**：★ ★ ★ ★（基础设施成本高，次优先）

---

### L2：同一币 · 链上 vs 所

**品种**
- stETH/ETH、WBTC/BTC、所内映射资产

**回归机制**：铸造/赎回。硬。

**业务逻辑**：赚折溢价 + 链上/所内摩擦。

**选品逻辑**
- 折溢价 > Gas + 桥费 + 时间成本 + 合约风险溢价。

**执行**：链上钱包 + 交易所账户。

**风控**：智能合约、桥、Gas 飙升、提币暂停。

**优先级**：★ ★ ★（操作复杂，视意愿）

---

### L3：高度可替代资产

**品种**
- 同一项目不同链映射（所内都上）
- 质押衍生品之间（如 stETH vs rETH）

**回归机制**：近似硬锚 + 统计。

**业务逻辑**：赚替代性价差 + 统计回归。

**选品逻辑**
- 经济逻辑 → 协整检验 → 半衰期 → 断裂次数。

**执行**：同所或跨所，双腿。

**风控**：映射失效、流动性、协整断裂。

**优先级**：★ ★ ★（补充层）

---

### L4：同叙事强替代（统计套利）

**品种**
- L1 龙头之间（ETH/SOL/BNB）
- DeFi 蓝筹之间（UNI/AAVE/CRV）
- 平台币之间（所内可比）

**回归机制**：共同因子 + 统计套利者。软。

**业务逻辑**：赌短期错价是暂时的，不是新均衡。

**选品逻辑（严格顺序）**
1. 经济逻辑：为什么一起动？共享什么因子？谁拉回？
2. 共同因子验证：是否被同一因子驱动？排除共同锚污染。
3. 协整，不是相关：价差平稳，长期绑定。
4. 回归参数：半衰期 10–30 天；滚动 β 稳定；前后子样本一致；断裂次数少。
5. 执行可行性：流动性、做空、借币、资金费、净收益。
6. 风控：协整失效即退、断裂止损、单币出现上限。

**执行**：同所、双腿。

**风控**：协整失效即退、断裂止损、单币出现上限、仓位/相关性上限。

**优先级**：★ ★（卫星层，小仓位）

---

### 不做：L5 / L6

- L5 泛赛道：共同因子弱，分化易永久；
- L6 Meme：无基本面，纯情绪，断裂频繁。

**逻辑上不成立，不立项。**

## 4. 统一技术架构

### 4.1 数据层

**数据源**
- 多所 K 线（现货、永续、交割）
- 资金费率历史
- 基差、标记价格、指数价格
- 链上汇率（L2 用）
- 上市/下架时间、流动性标记

**处理规范（含前期教训）**
1. **收益量纲**：组合净值必须逐日合成，禁止把不同价格量级的 spread 直接累加。
2. **共同锚去重**：统计每个币在选中对中的出现次数，设上限，按质量贪心保留；检查是否所有对都跟同一币协整（共同因子污染）。
3. **新币历史过滤**：每币要求 ≥ 365 天样本才进候选池；上市 < 90 天直接排除。
4. 统一时间轴、复权、缺口处理、停牌/下架标记。

### 4.2 信号层（分层独立）

| 层 | 信号 |
|---|---|
| L0 | 基差/费率阈值 |
| L1 | 跨所价差阈值 |
| L2 | 链上折溢价阈值 |
| L3/L4 | 协整 + rolling z-score（2σ 入场，0.5σ 平仓，断裂止损） |

### 4.3 组合层

- 按**风险预算**分配，不是资金等权；
- 每层独立净值曲线；
- 层内多品种等风险贡献（risk parity）；
- 全局限制：总敞口、相关性、单币暴露、单所暴露。

### 4.4 执行层

| 场景 | 要求 |
|---|---|
| 同所双腿 | 原子性下单，防单腿成交 |
| 跨所 | 资金调拨、延迟管理、对冲 |
| 链上 | 钱包、Gas、桥、时间成本 |

### 4.5 风控层

**硬层（L0–L2）**
- 价差反转、流动性、交易所风险、提币暂停。

**软层（L3–L4）**
- 协整失效即退（不等 z 回到 4σ）；
- 断裂止损；
- 单币出现次数上限；
- 半衰期恶化退出。

**全局**
- 总敞口上限、相关性上限、回撤熔断、单所集中度。

### 5.1 分配公式

w_i \propto \frac{\text{预期夏普}_i \times \text{容量}_i}{\text{回撤}_i}
\]

### 5.2 粗略优先级

| 层 | 仓位定位 | 杠杆 |
|---|---|---|
| L0 | 基本盘，大仓位 | 低 |
| L1 | 中仓位 | 中 |
| L2 | 小仓位 | 低 |

| L4 | 卫星，小仓位 | 低 |

## 6. 回测与验证方法论

### 6.1 必须遵守的规范（前期教训）

1. **净值曲线**：逐日、按同一日历对齐、固定资金等权，禁止"每日等权再平衡到在场对"。
2. **收益量纲**：每对独立账户，日收益 = position × Δspread（对数收益近似），扣成本；组合为固定权重加权。
3. **共同锚去重**：单币出现次数上限；检查共同因子污染。
4. **新币过滤**：每币 ≥ 365 天样本。
5. **样本外**：前后子样本一致、滚动窗口、walk-forward。
6. **成本**：手续费 + 滑点 + 资金费 + 借币 + 冲击成本，全部计入。

### 6.2 已证伪结论（防重复踩坑）

**朴素 z-score 配对（L4 类）在本币池的结果：**

| 指标 | 数值 |
|---|---|
| 盈利对占比 | 41/86 = 47.7% |
| 单对年化中位数 | 0~2% |
| 头部最好 | +25%（STEEM/VTHO） |
| 断裂率 | 158/1289 = 12% |
| 单对最大回撤 | -40%~-90% |

**结论**：朴素 z-score 配对在本币池无稳定 alpha，不立项。
非"配对交易无效"，而是"朴素实现 + 本币池 + 本参数"无效。

### 6.3 每层验收标准

| 层 | 最低夏普 | 最大回撤 | 断裂率 | 备注 |
|---|---|---|---|---|
| L0 | > 2.0 | < 5% | — | 硬层，要求高 |
| L1 | > 1.5 | < 10% | — | 含交易所风险 |
| L2 | > 1.5 | < 10% | — | 含合约风险 |
| L3 | > 1.0 | < 15% | < 5% | 准硬 |
| L4 | > 0.8 | < 20% | < 10% | 软层，门槛低 |

**不达标的层，不进入实盘。**

# 附录 A：L0 详细设计（同一币 · 同一所 · 不同形式）

## A.1 业务逻辑

### A.1.1 钱从哪来

L0 的本质是**同一资产的两个价格**，在同一个交易所内被两种不同机制定价：

| 形式 | 定价机制 | 偏差来源 |
|---|---|---|
| 现货 | 即时交割，实物锚 | 现货买卖压力 |
| 永续 | 资金费率 + 标记价格 | 杠杆多空失衡 |
| 交割 | 到期收敛 | 期限结构 |
| 质押凭证 | 兑换率 + 流动性溢价 | 质押需求、赎回延迟 |
| 稳定币对 | 兑换锚 | 流动性、信用溢价 |

**收益来源**：
- 永续资金费率（多头付空头，或反之）
- 基差收敛（现货-永续价差回归）
- 到期收敛（交割-永续）
- 兑换率套利（质押凭证）
- 稳定币折溢价

**关键**：这些是**结构性收益**，不是赌方向。回归由机制保证，不由统计保证。

### A.1.2 为什么现在还有效

- 资金费率是**每 8 小时结算**的，存在时间成本，不是所有人都愿意持有；
- 基差受**保证金效率**和**资金占用**约束；
- 交割合约有**到期日**，需要展期管理；
- 质押凭证有**赎回延迟**和**智能合约风险**；
- 稳定币对受**信用溢价**和**流动性分层**影响。

这些摩擦就是利润来源。

---

## A.2 品种池

### A.2.1 优先级排序

| 优先级 | 品种 | 回归机制 | 容量 | 竞争 |
|---|---|---|---|---|
| P0 | 现货 vs 永续（主流币） | 资金费率 | 大 | 极激烈 |
| P1 | 交割 vs 永续 | 到期收敛 | 中 | 激烈 |
| P2 | 稳定币对（USDC/USDT） | 兑换锚 | 大 | 激烈 |
| P3 | 质押凭证 vs 原生（WBETH/ETH） | 兑换率 | 小 | 中 |
| P4 | 现货 vs 永续（山寨币） | 资金费率 | 小 | 少 |

**建议从 P0 开始，逐步扩展。**

### A.2.2 品种筛选标准

- 现货 + 永续**同时上线**，且有足够流动性；
- 永续有**资金费率历史** ≥ 90 天；
- 现货/永续**深度足够**，单笔冲击成本可控；
- 无**下架/退市**风险标记；
- 非**新上市**（上市 ≥ 90 天）。

---

## A.3 信号构建

### A.3.1 现货-永续基差

\[
\text{basis}_t = \frac{P_{\text{perp},t} - P_{\text{spot},t}}{P_{\text{spot},t}}
\]

**理论锚**：永续价格 = 现货价格 × (1 + 资金费率预期 × 剩余时间)。长期看 basis 应围绕资金费率累积值波动。

### A.3.2 资金费率累积

\[
\text{funding\_cum}_t = \sum_{i=1}^{t} \text{funding}_i
\]

**信号**：
- 如果 basis 显著高于 funding 累积值 → 永续贵了 → 做空永续、做多现货；
- 如果 basis 显著低于 funding 累积值 → 永续便宜了 → 做多永续、做空现货。

### A.3.3 净收益公式

**做空永续 + 做多现货（正基差策略）**：

\[
\text{PnL} = \underbrace{\text{basis}_{\text{entry}} - \text{basis}_{\text{exit}}}_{\text{基差收敛}} + \underbrace{\sum \text{funding}}_{\text{资金费收入}} - \underbrace{\text{fee} - \text{slippage} - \text{borrow}}_{\text{成本}}
\]

**注意**：
- 做多现货需要**资金占用**，做空永续需要**保证金**；
- 资金费率可能反向（多头付空头时，做空永续反而付钱）；
- 借币成本、手续费、滑点全部计入。

### A.3.4 入场条件

\[
\text{net\_edge} = |\text{basis}| + \text{funding\_expect} - \text{cost} > \text{threshold}
\]

**建议阈值**：
- 主流币：年化净收益 > 8%；
- 山寨币：年化净收益 > 15%（补偿流动性风险）。

### A.3.5 出场条件

- basis 回归到 ±0.1% 以内；
- 资金费率反转且持续 > 3 期；
- 净收益低于成本；
- 流动性恶化。

## A.4 执行

### A.4.1 下单方式

- **原子性**：同时下现货和永续单，防止单腿成交；
- **限价单**：用 maker 单降低手续费，但需管理未成交风险；
- **分批建仓**：大仓位分批，降低冲击成本。

### A.4.2 保证金管理

- 永续空头需要保证金，现货多头占用资金；
- **总资金占用** = 现货名义 + 永续保证金；
- 杠杆建议 ≤ 2x，防止极端行情强平。

### A.4.3 展期（交割合约）

- 交割合约到期前**提前展期**，避免实物交割；
- 展期成本计入净收益。

- 单品种 ≤ 总资金 20%；
- 单交易所 ≤ 总资金 50%；
- 总杠杆 ≤ 2x。

### A.5.3 回撤熔断

- 单日回撤 > 2% → 减仓 50%；
- 累计回撤 > 5% → 暂停新开仓；
- 累计回撤 > 10% → 全部平仓，人工介入。

# 附录 B：L4 详细设计（同叙事强替代 · 统计套利）

## B.1 业务逻辑

### B.1.1 钱从哪来

L4 的本质是**两个不同资产**的价差，在偏离后回归。没有物理约束，只有统计关系。

**收益来源**：
- 短期错价（流动性冲击、情绪轮动、事件驱动）；
- 统计套利者资金推动回归；
- 共同因子（大盘、赛道 β）的对冲后残差。

**关键**：这是**概率游戏**，不是无风险套利。

### B.1.2 回归力量

| 力量 | 强度 | 说明 |
|---|---|---|
| 共同因子 | 中 | 对冲后只剩残差 |
| 赛道 β | 弱-中 | 会漂移 |
| 基本面替代性 | 弱 | 仅少数对存在 |
| 统计套利者资金 | 弱 | 可能反向 |
| 叙事替代性 | 弱 | 情绪驱动 |

**结论**：回归力量弱，断裂风险高。

---

## B.2 品种池

### B.2.1 只做 Tier 2

| Tier | 类型 | 是否做 |
|---|---|---|
| Tier 0 | 同一币不同形式 | 不做（属 L0） |
| Tier 1 | 高度可替代资产 | 不做（属 L3） |
| Tier 2 | 同叙事强替代 | **做** |
| Tier 3 | 同赛道泛配对 | 不做 |
| Tier 4 | Meme 配对 | 不做 |

### B.2.2 Tier 2 具体范围

- **L1 龙头之间**：ETH/SOL/BNB/AVAX 等；
- **DeFi 蓝筹之间**：UNI/AAVE/CRV/COMP 等；
- **平台币之间**：所内可比平台币；
- **同叙事新公链**：如多个 L2、多个模块化项目。

**排除**：
- 跨赛道（L1 vs Meme）；
- 市值差异过大（如 BTC vs 小市值 L1）；
- 流动性差异过大。

### B.2.3 品种筛选标准

- 同赛道、同市值段、同流动性层级；
- 上市 ≥ 365 天；
- 日成交额 ≥ 阈值；
- 无下架风险；
- 历史协整关系稳定。

---

## B.3 信号构建

### B.3.1 协整关系

\[
\log P_A = \alpha + \beta \log P_B + \epsilon
\]

\[
\text{spread} = \log P_A - \beta \log P_B - \alpha
\]

**要求**：spread 平稳（ADF 检验 p < 0.05）。

### B.3.2 滚动 z-score

\[
z_t = \frac{\text{spread}_t - \mu_{\text{rolling}}}{\sigma_{\text{rolling}}}
\]

**建议窗口**：60-120 天。

### B.3.3 入场条件

- |z| > 2.0；
- 协整关系样本外稳定；
- 半衰期 10-30 天；
- 滚动 β 无显著漂移；
- 流动性充足。

### B.3.4 出场条件

- z 回归到 0.5 以内；
- 协整失效（ADF p > 0.1）；
- 断裂止损（spread 扩大 > 3σ）；
- 半衰期恶化 > 60 天；
- 流动性恶化。

## B.4 共同锚去重

### B.4.1 问题

如果所有对都跟某个币（如 BANKUSDT）协整，那不是真实配对，而是**共同因子污染**。

### B.4.2 去重逻辑

1. 统计每个币在选中对中的出现次数；
2. 设上限（如单币 ≤ 3 对）；
3. 按质量（ADF p 值、半衰期、样本外稳定性）排序；
4. 贪心保留高质量对，跳过超限对；
5. 检查是否所有对都跟同一币协整 → 共同因子污染，全部剔除。

### B.4.3 实现要点

```python
# 按质量排序
pairs_sorted = sorted(pairs, key=lambda x: x.quality_score, reverse=True)

selected = []
symbol_count = defaultdict(int)

for pair in pairs_sorted:
    a, b = pair.symbol_a, pair.symbol_b
    if symbol_count[a] >= MAX_USES or symbol_count[b] >= MAX_USES:
        continue
    selected.append(pair)
    symbol_count[a] += 1
    symbol_count[b] += 1
```

## B.6 执行

### B.6.1 下单方式

## B.8 回测方法

### B.8.1 数据要求

- 永续 K 线（1h 或 4h）；

### B.8.2 回测逻辑（净值曲线版）

```
for each pair:
    spread = log(A) - beta * log(B) - alpha
    z = rolling_zscore(spread, window)
    
    for each day:
        if no position and |z| > 2.0:
            open position (long/short spread)
        
        if position exists:
            daily_pnl = position * (spread[t] - spread[t-1])
            accrue daily_pnl
            if exit_condition:
                close position
                deduct cost

# 组合层面
combo_nav = fixed_weight_sum(all_pair_navs)  # 固定权重，不是每日再平衡
combo_rets = combo_nav.pct_change()
```

**关键**：
- 每对独立账户，日收益 = position × Δspread；
- 组合用**固定权重**加权，不是每日再平衡；
- 成本在开平仓日扣除。

## B.9 预期与陷阱

### B.9.1 预期

- 收益中等，波动大；
- 容量中等；
- 少数对贡献主要收益；
- 需要严格风控。

### B.9.2 陷阱

- **伪回归**：数据挖出来的协整，样本外崩溃；
- **共同因子污染**：所有对都跟同一币协整；
- **新币污染**：短历史币过度拟合；
- **断裂**：协整关系永久改变；
- **成本吞噬**：手续费 + 滑点 + 资金费吃掉利润；
- **过拟合**：参数在样本内优化，样本外失效。

### B.9.3 已证伪结论（防重复踩坑）

**朴素 z-score 配对在本币池的结果**：

| 指标 | 数值 |
|---|---|
| 盈利对占比 | 41/86 = 47.7% |
| 单对年化中位数 | 0~2% |
| 头部最好 | +25%（STEEM/VTHO） |
| 断裂率 | 158/1289 = 12% |
| 单对最大回撤 | -40%~-90% |

**结论**：朴素 z-score 配对在本币池无稳定 alpha，不立项。
非"配对交易无效"，而是"朴素实现 + 本币池 + 本参数"无效。

**改进方向**：
- 只做 Tier 2，严格选对；
- 加严协整检验（滚动 ADF、样本外一致）；
- 断裂止损（不等 4σ）；
- 动态 β（Kalman）；
- 共同锚去重；
- 新币过滤。
