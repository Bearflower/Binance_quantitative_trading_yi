
动态 ATR + 动态成交量 + 币种差异化
## 一、核心架构

本方案在 v6.16.7 基础上，实现三大核心升级：

1. **动态 ATR 过滤器**（保留并优化）  
   - 基于历史 35% 分位数 + ADX 调节 + 币种绝对下限
2. **动态成交量过滤器**（新增）  
   - 基于过去 20 小时均量 + ADX 调节 + 币种差异化倍数
3. **币种差异化参数配置**  
   - 为 BTC、ETH、BNB、SOL、XRP、TRX 分别设置独立阈值

所有修改均集中在信号产生的前置过滤器阶段，不影响评分系统、止盈止损、仓位管理等已验证成功的核心逻辑。

## 三、动态 ATR 过滤器（完整代码）

```python
import numpy as np
from typing import List

class DynamicATRFilter:
    def __init__(self, symbol_config: dict):
        self.config = symbol_config
        self.min_abs = self.config.get('atr_abs_min', 0.006)  # 绝对下限，单位：小数（0.006=0.6%）
        self.percentile = self.config.get('atr_percentile', 35)
        self.strong_factor = self.config.get('atr_factor_strong', 0.8)
        self.weak_factor = 1.0  # 弱趋势时不低于分位数
    
    def check(self, current_atr_percent: float, 
              atr_history_1h: List[float], 
              close_history_1h: List[float],
              adx_1d: float) -> tuple[bool, str]:
        """
        :return: (是否通过, 拒绝原因)
        """
        # 绝对下限检查
        if current_atr_percent < self.min_abs:
            return False, f"ATR% {current_atr_percent:.2f}% < 绝对下限 {self.min_abs*100:.1f}%"
        
        # 至少需要30个样本计算分位数
        if len(atr_history_1h) < 30 or len(close_history_1h) < 30:
            # 数据不足时使用固定宽松下限（0.6%）
            temp_min = max(0.006, self.min_abs)
            if current_atr_percent < temp_min:
                return False, f"数据不足，ATR% {current_atr_percent:.2f}% < 临时下限 {temp_min*100:.1f}%"
            return True, ""
        
        # 计算历史 ATR% 序列（最近 720 小时）
        lookback = min(len(atr_history_1h), 720)
        atr_pct_list = []
        for i in range(-lookback, 0):
            atr = atr_history_1h[i]
            close = close_history_1h[i]
            if close > 0:
                atr_pct_list.append(atr / close * 100)
        
        if len(atr_pct_list) < 20:
            return True, ""  # 样本不足，暂时通过
        
        # 动态阈值
        base_threshold = np.percentile(atr_pct_list, self.percentile)
        factor = self.strong_factor if adx_1d > 25 else self.weak_factor
        min_allowed = base_threshold * factor
        min_allowed = max(min_allowed, self.min_abs * 100)  # 转为百分数单位
        
        if current_atr_percent >= min_allowed:
            return True, ""
        else:
            return False, f"ATR% {current_atr_percent:.2f}% < 动态下限 {min_allowed:.2f}% (基准={base_threshold:.2f}%, ADX={adx_1d:.1f})"
```

## 四、动态成交量过滤器（完整代码）

```python
class DynamicVolumeFilter:
    def __init__(self, symbol_config: dict):
        self.config = symbol_config
        self.base_ratio = self.config.get('vol_ratio_base', {'S':1.4, 'A':1.2, 'B':0.0, 'C':0.0})
        self.lookback_hours = 20
    
    def check(self, current_volume: float, volume_history_1h: List[float],
              adx_1d: float, grade: str) -> tuple[bool, str]:
        """
        grade: 'S', 'A', 'B', 'C'
        """
        min_ratio = self.base_ratio.get(grade, 0.0)
        if min_ratio == 0.0:
            return True, ""  # 不检查成交量
        
        # 计算过去20小时平均成交量
        if len(volume_history_1h) < self.lookback_hours:
            return True, ""  # 数据不足，暂不检查
        
        avg_volume = sum(volume_history_1h[-self.lookback_hours:]) / self.lookback_hours
        if avg_volume == 0:
            return True, ""
        
        vol_ratio = current_volume / avg_volume
        
        # ADX 调节：强趋势时允许成交量要求降低20%
        effective_min = min_ratio
        if adx_1d > 25:
            effective_min = min_ratio * 0.8
        
        if vol_ratio >= effective_min:
            return True, ""
        else:
            return False, f"成交量比率 {vol_ratio:.2f} < {effective_min:.2f} (等级{grade}, ADX={adx_1d:.1f})"
```

## 五、信号检查完整流程（集成示例）

```python
def check_signal(symbol, current_data, historical_data, adx_1d, grade, score):
    config = SYMBOL_CONFIG[symbol]
    
    # 1. ADX 过滤
    if adx_1d < config['adx_min']:
        return False, f"ADX {adx_1d:.1f} < {config['adx_min']}"
    
    # 2. 动态 ATR 过滤
    atr_filter = DynamicATRFilter(config)
    atr_ok, atr_reason = atr_filter.check(
        current_atr_percent=current_data['atr_percent'],
        atr_history_1h=historical_data['atr_history'],
        close_history_1h=historical_data['close_history'],
        adx_1d=adx_1d
    )
    if not atr_ok:
        return False, atr_reason
    
    # 3. 动态成交量过滤
    vol_filter = DynamicVolumeFilter(config)
    vol_ok, vol_reason = vol_filter.check(
        current_volume=current_data['volume'],
        volume_history_1h=historical_data['volume_history'],
        adx_1d=adx_1d,
        grade=grade
    )
    if not vol_ok:
        return False, vol_reason
    
    # 4. 评分等级阈值
    min_score = config.get('s_min_score', 85) if grade == 'S' else 75
    if score < min_score:
        return False, f"评分 {score} < {min_score}"
    
    # 5. 频率控制（每日最大交易数、冷却期等，沿用原有逻辑）
    # ... 略
    
    return True, "通过所有检查"
```

## 九、注意事项

- 动态 ATR 和动态成交量过滤器需要历史数据列表（按时间顺序）。请确保您的数据存储能够提供至少 720 小时的 ATR 和 close 序列，以及 20 小时的成交量序列。
- 对于数据不足的初期阶段，过滤器会自动使用临时宽松阈值，避免信号完全缺失。
- 建议在回测中开启详细日志，记录每个信号的过滤原因，便于后续微调。
