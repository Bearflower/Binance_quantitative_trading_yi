- 评分系统可能过于依赖趋势强度，而形态质量权重不足，导致假突破信号多。

## 二、具体调整步骤（从易到难）

### 步骤1：优化止盈止损，减少频繁止损

**当前吊灯止损参数（v6.13）**：启动倍数2.5×ATR，回撤幅度1.5×ATR。建议调整为：

| 参数 | 原值 | 建议新值 | 理由 |
|------|------|----------|------|
| 止损倍数 | 1.5×ATR | **2.0×ATR** | 给予价格更多波动空间，避免被随机震荡扫损 |
| 吊灯启动倍数 | 2.5×ATR | **3.0×ATR** | 延迟移动止损启动，让利润先奔跑 |
| 吊灯回撤倍数 | 1.5×ATR | **2.0×ATR** | 允许更大幅度的回撤，避免过早离场 |
| 增加时间止损 | 无 | **72小时未达TP1则平仓50%** | 防止持仓过久占用资金 |

**预期效果**：胜率可能降至35%左右，但盈亏比提升，整体亏损收窄或转正。

### 步骤2：调整前置过滤器，回归方案2但增加趋势确认

方案2（ADX≥15，量比≥1.2，ATR%1-8%）的56笔交易是较好的样本基础。在其基础上增加**二级趋势确认**：

- 要求 **4小时EMA21方向与日线EMA21方向一致**（避免逆大趋势）。
- 增加 **RSI过滤**：多头开仓时4小时RSI > 40（避免在极度超卖时逆势），空头时RSI < 60。

**预期效果**：交易数从56降至30-40，胜率有望提升至45%以上。

### 步骤3：调整评分权重，提高形态质量占比

当前评分系统（3维度：趋势强度40，形态质量35，动量背离25）可能过于侧重趋势。建议调整为：

| 维度 | 原权重 | 新权重 | 理由 |
|------|--------|--------|------|
| 趋势强度 | 40 | **30** | 降低权重，因为ADX已过滤 |
| 形态质量 | 35 | **45** | 提高形态确认的重要性（如阳包阴、背离） |
| 动量背离 | 25 | **25** | 保持不变 |

同时将A级最低分从75降至**70**，B级从65降至**60**，C级从55降至**50**，以增加信号数量（但保持质量）。

### 步骤4：增加市场状态识别，避免震荡市交易

使用**布林带宽度**或**ATR变化率**识别震荡市：
- 当过去5根4小时K线的ATR波动率低于过去20根ATR均值的80%时，判定为震荡市，此时**禁止开仓**。
- 或者直接使用ADX < 20时不开仓（保持方案1的ADX≥20，但放宽其他条件）。

**预期效果**：交易数减少，但胜率显著提升。

### 步骤5：动态仓位管理（根据信号强度）

当前仓位固定（S级50%，A级30%，B级15%，C级5%）。可改为：
- 根据信号评分在等级内线性调整，例如A级评分75-84分，仓位从20%线性到40%。
- 同时设置**单品种累计风险上限**：同一币种连续开仓（如加仓）后，总风险不超过总资金3%。

## 实现“4小时EMA21方向与日线EMA21方向一致”有多种方式，推荐使用**价格相对于EMA21的位置**来判断方向（简单有效），也可以使用**EMA21斜率**（更精确但计算稍复杂）。以下是两种实现的代码示例（Python），适用于回测或实盘。

## 方案一：基于价格与EMA21的相对位置（推荐，简单）

**逻辑**：若日线收盘价 > 日线EMA21，且4小时收盘价 > 4小时EMA21，则多头方向一致；空头反之。

```python
def is_trend_aligned(df_daily, df_4h, direction='LONG'):
    """
    df_daily: 日线DataFrame，包含 'close' 和 'ema21' 列
    df_4h: 4小时DataFrame，包含 'close' 和 'ema21' 列
    direction: 'LONG' 或 'SHORT'
    """
    # 取最新值
    daily_close = df_daily['close'].iloc[-1]
    daily_ema21 = df_daily['ema21'].iloc[-1]
    h4_close = df_4h['close'].iloc[-1]
    h4_ema21 = df_4h['ema21'].iloc[-1]
    
    if direction == 'LONG':
        return (daily_close > daily_ema21) and (h4_close > h4_ema21)
    else:
        return (daily_close < daily_ema21) and (h4_close < h4_ema21)
```

**优点**：计算简单，实时性强，不会引入未来函数。  
**缺点**：在价格围绕EMA21震荡时，方向可能频繁变化，但结合其他过滤器（如ADX>20）可缓解。

## 方案二：基于EMA21斜率（更平滑，避免震荡干扰）

**逻辑**：分别计算日线和4小时EMA21的斜率（如最近5根K线的线性回归斜率），斜率同为正则为多头方向一致，同为负则为空头方向一致。

```python
import numpy as np

def calculate_slope(ema_series, periods=5):
    """计算最近periods根EMA21的斜率（线性回归）"""
    y = ema_series.iloc[-periods:].values
    x = np.arange(periods)
    slope, _ = np.polyfit(x, y, 1)
    return slope

def is_trend_aligned_slope(df_daily, df_4h, direction='LONG'):
    daily_slope = calculate_slope(df_daily['ema21'])
    h4_slope = calculate_slope(df_4h['ema21'])
    
    if direction == 'LONG':
        return daily_slope > 0 and h4_slope > 0
    else:
        return daily_slope < 0 and h4_slope < 0
```

**优点**：信号更稳定，避免价格小幅穿越EMA21导致的误判。  
**缺点**：需要至少5根K线数据，回测初期可能无法计算（可跳过或使用方案一回退）。

## 整合到现有策略中（以方案一为例）

在您的 `real_data_backtest_v6.py` 或评分引擎中，找到判断趋势或生成信号的部分（例如 `_check_trend_filter_v6` 函数），增加以下条件：

```python
# 假设已有 daily_data 和 h4_data 的 DataFrame
if direction == 'LONG':
    if not (daily_close > daily_ema21 and h4_close > h4_ema21):
        return False  # 趋势方向不一致，拒绝信号
else:
    if not (daily_close < daily_ema21 and h4_close < h4_ema21):
        return False
```

## 注意事项

1. **数据对齐**：确保日线和4小时数据的时间戳对齐（例如使用前一天的日线数据与最新的4小时数据比较）。
2. **杠杆与多空**：该过滤条件对多空方向分别处理，不要错误交叉使用。
3. **与ADX协同**：该条件可替代或补充原有的ADX要求，建议与ADX≥15/20一起使用，效果更佳。

采用方案一即可满足您的需求，且易于集成。如果您希望更平滑，可改用方案二。
