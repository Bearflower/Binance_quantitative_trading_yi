本版本基于 v6.16.7（已验证最优）进行微调，兼顾 **SOLUSDT 信号质量** 与 **其他主流币种交易机会**，在保持高夏普（1.55）和低回撤（3.29%）的同时，适度增加币种多样性。

---

### 一、核心交易原则

- **单笔最大亏损**：≤ 总资金的 2%（500U × 2% = 10U）
- **总保证金占用**：≤ 总资金的 30%（≤150U）
- **杠杆**：S 级 5 倍，A 级 4 倍，B 级 3 倍，C 级 2 倍
- **同时持仓品种**：≤ 2 个
- **亏损时禁止加仓、禁止提高杠杆**
  > ✅ **已实现**：`analyze()` 步骤 1.2，在频率控制检查之后、K 线数据获取之前，检查该币种是否已有活跃持仓。若持仓方向为 LONG 且当前价 < 入场价（浮亏），或 SHORT 且当前价 > 入场价（浮亏），则跳过信号生成，返回 `reason="已有做多/做空持仓浮亏，禁止加仓"`。盈利状态下的持仓不阻止新信号。

---

### 二、500U 微型账户特规（阶段一）

- 总资金：500U，单笔风险固定 10U（波动率目标仓位可调整至 5~15U）
- 最大总保证金占用：150U
- 允许同时持仓 ≤ 2 个品种
- 信号等级：S、A、B、C（B/C 级轻仓参与）
- 强制利润提取：账户创新高时，提取盈利的 50% 至储蓄账户
  > ✅ **已实现**：通过飞书推送提醒。每次 `update_positions()` 巡检时调用 `_check_profit_extraction()`，检测账户权益是否创新高，若创新高则计算 `(当前权益 - 初始资金) × 50%` 的建议提取金额，通过飞书 `notification.send()` 发送推送提示。每周最多推送一次，避免重复骚扰；API 调用频率控制（至少间隔 60 分钟重新查询账户信息）；ATH 余额持久化到 `strategy_global_state` 数据库表，重启后恢复。**不执行实际划转操作**（需手动操作或后续接入 Binance 划转 API）。

### 三、交易标的与禁止情形

- **交易标的**：BTCUSDT、ETHUSDT、BNBUSDT、SOLUSDT、XRPUSDT、TRXUSDT
- **禁止交易**：
  - 24 小时涨跌幅 >25%（多）或 <-20%（空）
  - |资金费率| > 0.05%（代码采用更严格值，原文档 0.08%）
  - 买卖价差 > 0.3%
  - 距离重大消息发布前后 1 小时（如 CPI、非农、FOMC）
  > ✅ **已实现**：通过硬编码配置覆盖 2025-2026 年 CPI/FOMC/NFP 共 47 个事件。在 `config.yaml` 的 `economic_calendar.events` 中配置，`_check_economic_calendar()` 在每次 `analyze()` 时在频率控制检查之后、K 线数据获取之前执行，事件前后各 60 分钟禁止交易。事件时间使用 UTC 时间。

#### 4.2 趋势过滤器（硬性条件）

**多头方向**（必须同时满足）：
- 日线收盘价 > 日线 EMA55
- 日线 EMA21 斜率 > 0.05%（最近 5 根日线线性回归）
- 4 小时价格回调至 4 小时 EMA21 附近（价差 ≤ 1.5×ATR14）
- 1 小时收盘价 > 1 小时 EMA21

**空头方向**：对称（日线收盘价 < EMA55，斜率 < -0.05%，4h 反弹至 EMA21，1h 收盘价 < EMA21）

**禁止入场**：
- 日线 EMA21 斜率绝对值 < 0.03%
- ATR/价格 > 4.5% 或 < 1.0%（静态下限，但会被动态 ATR 覆盖）
- 最近 6 小时内出现单根 1h K 线涨跌幅 > 5%
- 资金费率绝对值 > 0.05%

#### 4.4 动态 ATR 过滤器（替代静态下限）

```python
def check_atr_dynamic(symbol, current_atr_pct, atr_history_1h, close_history_1h, adx_1d, config):
    # 绝对下限
    abs_min = config['atr_abs_min']
    if current_atr_pct < abs_min:
        return False, f"ATR% {current_atr_pct:.2f}% < 绝对下限 {abs_min*100:.1f}%"
    
    # 至少需要30个样本
    if len(atr_history_1h) < 30:
        return current_atr_pct >= 0.006, ""
    
    # 计算历史35%分位数（最近720小时）
    pct = config['atr_percentile'] / 100
    lookback = min(len(atr_history_1h), 720)
    atr_pct_list = []
    for i in range(-lookback, 0):
        if close_history_1h[i] > 0:
            atr_pct_list.append(atr_history_1h[i] / close_history_1h[i] * 100)
    if len(atr_pct_list) < 20:
        return True, ""
    base = np.percentile(atr_pct_list, pct*100)
    factor = config['atr_factor_strong'] if adx_1d > 25 else 1.0
    min_allowed = max(base * factor, abs_min * 100)
    if current_atr_pct >= min_allowed:
        return True, ""
    else:
        return False, f"ATR% {current_atr_pct:.2f}% < 动态下限 {min_allowed:.2f}%"
```

### 五、止盈止损策略（吊灯止损）

- **止损** = 1.5 × ATR（多头：开仓价 - 1.5×ATR）
- **TP1** = 开仓价 + 4.0×ATR，平仓 **25%**
- **TP2** = 开仓价 + 6.0×ATR，平仓 **25%**
- **吊灯止损**：当价格突破 2.5×ATR 后启动，回撤 1.5×ATR 时平仓剩余 50% 仓位
- **时间止损**：72 小时未达 TP1，平仓 50%（若持仓超过 72h）

### 六、仓位管理与风险控制

- **波动率目标仓位**：单笔风险金额 = 10U × (历史中位 ATR% / 当前 ATR%)，限制 [5U, 15U]
- **冷却期**：同币种 12 小时
- **每日最大总交易数**：6 笔
- **连续亏损暂停**：连续 5 笔亏损，暂停 1 天
- **每日最大亏损**：5% 总资金（25U），触及则当日停止

### 八、紧急与特殊处理

- **极端行情**（瞬间反向 5%）：立即平仓 50%，剩余止损收紧至 1.0×ATR
- **连续亏损**：5 笔亏损 → 暂停 1 天；单周亏损 >15% → 暂停 3 天
  > ✅ **已实现**：`FrequencyController._check_weekly_loss()` 在每次 `can_trade()` 时调用，从 `daily_pnl` 按 ISO 周号聚合周盈亏，超过 `initial_capital_usdt × 15%` 阈值时设置 `pause_until` 为 3 天后。暂停期间所有交易被阻止。参数可配置：`weekly_loss_max_ratio: 0.15`、`weekly_loss_pause_days: 3`。
- **强平预警**：保证金率 ≤1.5 减仓 50%，≤1.2 全部平仓
