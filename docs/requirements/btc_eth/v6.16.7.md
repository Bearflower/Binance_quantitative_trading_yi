# v6.16.7 止损止盈单立即触发问题修复

基于 v6.16.6 进行问题修复，解决止损止盈条件单在开仓后立即触发的问题。

---

## 一、问题描述

### 问题现象

在 v6.16.6 版本中，开仓后设置的止损止盈条件单有时会立即触发，导致刚开仓就被平仓。

### 问题原因

止损止盈触发价的计算基于入场价格（限价单价格），但实际成交价格可能与入场价格存在差异：

1. **限价单未成交时**：`avgPrice` 为 "0"，使用入场价计算触发价
2. **价格波动**：开仓期间价格可能已经发生变化
3. **触发价不合理**：
   - 做多止损价 ≥ 当前价格 → 立即触发
   - 做空止损价 ≤ 当前价格 → 立即触发

### 影响范围

- 策略执行模块（`strategies/btc_eth/strategy.py`）
- 配置文件（`strategies/btc_eth/config.yaml`）

---

## 二、解决方案

### 核心改进

1. **获取当前实际价格**：在设置止损止盈单前，调用币安API获取当前实时价格
2. **基于当前价格重新计算触发价**：使用当前价格而非入场价计算止损止盈触发价
3. **触发价合理性验证**：验证触发价是否符合逻辑，异常时自动调整
4. **新增配置项**：`trigger_price_adjustment_ratio` 用于异常情况下的调整比例
5. **告警通知**：价格获取失败时发送告警通知

### 3. 触发价合理性验证

**代码位置**：`strategy.py` 第1731-1751行

if signal['direction'] == 'LONG' and sl_trigger >= current_price:
    logger.warning(
        f"{signal['symbol']} 止损触发价异常（做多止损价应低于当前价），调整触发价",
        sl_trigger=float(sl_trigger),
        current_price=float(current_price),

    logger.warning(
        f"{signal['symbol']} 止损触发价异常（做空止损价应高于当前价），调整触发价",

        current_price=float(current_price),

    if tick_size:
        sl_trigger = (sl_trigger // tick) * tick

## 四、配置参数更新

### 新增配置项

**文件**：`strategies/btc_eth/config.yaml`

```yaml
risk:
  # v6.16.7新增：异常情况下的触发价调整比例
  trigger_price_adjustment_ratio: 0.02  # 2%调整比例（用于止损止盈触发价异常时的自动调整）
```

### 参数说明

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `trigger_price_adjustment_ratio` | float | 0.02 | 触发价异常时的调整比例（2%） |

**使用场景**：
- 当止损触发价 ≥ 当前价格（做多）时，自动调整为当前价格 × (1 - 0.02)
- 当止损触发价 ≤ 当前价格（做空）时，自动调整为当前价格 × (1 + 0.02)
- 当止盈触发价 ≤ 当前价格（做多）时，自动调整为当前价格 × (1 + 0.02)
- 当止盈触发价 ≥ 当前价格（做空）时，自动调整为当前价格 × (1 - 0.02)
