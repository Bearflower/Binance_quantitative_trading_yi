# v6.16.3 信号质量优化版

基于 v6.16.2 进行迭代优化，重点解决胜率过低的问题。

---

## 一、背景分析

### v6.16.2 存在的问题

1. **胜率过低**：31.11%，远低于目标55%
2. **信号质量差**：ATR%下限降低后引入了大量低质量信号
3. **B级和C级信号过多**：45笔交易中，B级和C级占多数
4. **市场状态过滤过于严格**：过滤了144个信号

### 优化目标

1. 提升胜率（目标：≥50%）
2. 减少低质量信号（目标：交易次数减少30%-50%）
3. 提升整体收益率（目标：正收益）

---

## 二、核心优化内容

### 优化一：提高B级评分阈值

**原逻辑**：
- B级：≥ 65分

**新逻辑**：
- B级：≥ 70分（提高5分）

**预期效果**：过滤掉评分较低的B级信号，提高信号质量。

### 优化二：低波动市场额外过滤

**逻辑**：
当 ATR% < 0.5% 时（极低波动市场），要求更高的评分：
- B级信号：评分 ≥ 75分（相当于A级门槛）
- C级信号：直接拒绝

**实现方式**：
```python
def check_low_volatility_filter(atr_percent: float, grade: str, score: float) -> Tuple[bool, str]:
    """
    低波动市场额外过滤
    
    Args:
        atr_percent: ATR百分比
        grade: 信号等级
        score: 信号评分
    
    Returns:
        (是否通过, 原因说明)
    """
    if atr_percent < 0.5:
        if grade == 'C':
            return False, "低波动市场拒绝C级信号"
        elif grade == 'B' and score < 75:
            return False, f"低波动市场B级信号评分不足（{score}分 < 75分）"
    
    return True, "通过"
```

### 优化三：取消市场状态过滤

**原逻辑**：
- 市场状态过滤器会检查市场整体趋势，过滤掉逆势信号
- 过滤了144个信号

**新逻辑**：
- 完全取消市场状态过滤
- 让评分系统自己决定信号质量

**理由**：
1. 市场状态判断可能不准确
2. 评分系统已经包含了趋势强度（ADX）评估
3. 过度过滤可能错过优质信号
