## 1. 问题概述

### 1.1 问题描述

BTC/ETH 策略在评分环节中，BTCUSDT、ETHUSDT、BNBUSDT 三个交易对全部评分为 0（D 级），原因是评分计算时抛出异常：**"执行异常: 'EMA55'"**。

该异常导致所有交易对的评分流程中断，策略无法正常产出交易信号，**生产环境交易完全停滞**。

### 1.2 影响范围

| 影响维度 | 详情 |
|---------|------|
| 交易对 | BTCUSDT、ETHUSDT、BNBUSDT（全部监控交易对） |
| 时间框架 | 日线（1d） |
| 策略功能 | v6.16.10 趋势过滤器（`_check_trend_filter`） |
| 业务影响 | 所有交易对评分归零，无法开仓，策略完全失效 |
| 生产环境 | 是（`strategies/btc_eth/` 目录） |
| 回测环境 | 回测代码独立实现指标计算，**可能不受影响**（需验证） |

## 2. 根因分析

### 2.1 根因链

```
评分计算 → _check_trend_filter() 趋势过滤
    → 引用 indicators['1d']['EMA55']（strategy.py:1274）
        → indicators['1d'] 由 TechnicalIndicators.calculate_all() 生成
            → EMA 计算循环仅含 [12, 26]，缺少 55 周期（indicators.py:318-319）
                → indicators['1d'] 字典中不存在键 'EMA55'
                    → 抛出 KeyError: 'EMA55'
```

### 2.2 代码位置

| 文件 | 行号 | 问题描述 |
|------|------|---------|
| [shared/indicators.py](file:///Users/yl/vscode/Binance_quantitative_trading/shared/indicators.py#L318-L319) | 318-319 | EMA 计算循环 `for period in [12, 26]` 缺少 55 周期 |
| [strategies/btc_eth/strategy.py](file:///Users/yl/vscode/Binance_quantitative_trading/strategies/btc_eth/strategy.py#L1274) | 1274 | `_check_trend_filter` 引用 `indicators['1d']['EMA55']` |
| [strategies/btc_eth/strategy.py](file:///Users/yl/vscode/Binance_quantitative_trading/strategies/btc_eth/strategy.py#L1298-L1304) | 1298-1304 | 做多/做空条件均依赖 EMA55 判断 |

### 2.3 对比分析

MA 计算循环（[indicators.py:315-316](file:///Users/yl/vscode/Binance_quantitative_trading/shared/indicators.py#L315-L316)）**已包含 55 周期**：

```python
# MA 计算（正确）
for period in [7, 21, 55]:
    indicators[f'MA{period}'] = TechnicalIndicators.calculate_ma(data, period)

# EMA 计算（缺失 55）
for period in [12, 26]:
    indicators[f'EMA{period}'] = TechnicalIndicators.calculate_ema(data, period)
```

两者模式一致，EMA 循环遗漏了 55 周期属于**实现遗漏**，而非设计遗漏。

### 2.4 可行性验证

- `calculate_ema()` 方法（[indicators.py:78-96](file:///Users/yl/vscode/Binance_quantitative_trading/shared/indicators.py#L78-L96)）对 period 参数无上限限制
- `_validate_period()` 方法（[indicators.py:40-54](file:///Users/yl/vscode/Binance_quantitative_trading/shared/indicators.py#L40-L54)）仅校验 `period > 0`，55 可通过校验
- EMA 计算使用 `ewm(span=55)`，pandas 原生支持任意正整数 span

## 3. 需求描述

### 3.1 功能需求

**FR-01：在 `calculate_all` 方法中新增 EMA55 计算**

在 [shared/indicators.py](file:///Users/yl/vscode/Binance_quantitative_trading/shared/indicators.py) 的 `TechnicalIndicators.calculate_all()` 方法中，将 EMA 计算循环周期列表从 `[12, 26]` 修改为 `[12, 26, 55]`。

**修改前：**
```python
for period in [12, 26]:
    indicators[f'EMA{period}'] = TechnicalIndicators.calculate_ema(data, period)
```

**修改后：**
```python
for period in [12, 26, 55]:
    indicators[f'EMA{period}'] = TechnicalIndicators.calculate_ema(data, period)
```

### 3.2 需求优先级（MoSCoW）

| 优先级 | 需求项 | 说明 |
|--------|--------|------|
| **M（必须）** | EMA55 指标计算 | 修复策略评分阻塞问题，恢复交易功能 |

### 3.3 不做的事

1. **不新增 EMA 周期**：仅补全 55 周期，不新增其他 EMA 周期（如 EMA7、EMA21 等）
2. **不修改 strategy.py**：策略层 `_check_trend_filter` 方法无需改动，其 EMA55 引用是正确的
3. **不修改配置**：`config.yaml` 无需变更
4. **不修改回测代码**：回测代码 `backtest_v61610_full.py` 独立实现指标计算，需单独验证但不在本次修复范围

## 5. 风险评估

| 风险项 | 风险等级 | 说明 | 缓解措施 |
|--------|---------|------|---------|
| 数据行数不足 | 低 | 日线数据少于 55 根时 EMA55 全为 NaN，趋势过滤器可能抛出异常 | `_check_trend_filter` 中已检查 `'1d' in indicators`，但未检查 `EMA55` 是否存在 NaN。建议后续增加 NaN 检查 |
| 性能影响 | 低 | 新增一个 EMA 计算，`ewm(span=55)` 为 O(n) 操作，影响极小 | 不视为风险 |
| 回测代码不一致 | 中 | 回测代码 `backtest_v61610_full.py` 独立实现指标计算，可能也未包含 EMA55 | 需单独验证回测代码，如需修复则另开任务 |
