# v6.19 极端选择性版 -- 本金保护优先

本版本基于 v6.18 进行激进收紧，核心目标是将本金保护置于首位，通过极致收紧入场条件实现"宁可错过，不可做错"的交易哲学。

## 二、核心目标

### 2.1 问题背景

v6.18 及之前版本在震荡市中频繁产生低质量信号，导致：
- 假突破频繁触发止损
- 震荡市中反复被洗出
- 资金曲线持续回撤

### 2.2 解决思路

**一刀切策略**：不区分震荡市和趋势市的策略，而是直接禁止在非强趋势环境中开仓。如果市场不够强，就完全不交易。

### 2.3 预期效果

- 交易频率大幅降低（预期每月 3-5 笔）
- 每笔交易质量极高
- 本金几乎零回撤
- 宁可空仓等待，也不在不确定的市场中冒险

## 三、市场状态识别系统

### 3.1 设计理念

引入二元市场状态判定：**STRONG_TREND**（强趋势市）或 **RANGING**（震荡市）。只有 STRONG_TREND 状态下才允许开仓。

### 3.2 强趋势市判定条件（5 条件，必须全部满足）

| 序号 | 条件 | 参数 | 说明 |
|------|------|------|------|
| 1 | ADX 强度 | ADX(14) > 35 | 日线级别，确保趋势足够强劲 |
| 2 | 布林带宽度 | BB 宽度 > 7% | 日线 Bollinger Bands (20,2)，宽度 = (上轨-下轨)/中轨 |
| 3 | 价格变化幅度 | 近 5 日价格变化 > 5% | 绝对值，确保价格有足够的位移 |
| 4 | EMA21 斜率 | 日线 EMA21 斜率 > 0.15% | 最近 5 根日线线性回归斜率 |
| 5 | 4h K 线一致性 | 连续 3 根 4h K 线收盘在 EMA21 同侧 | 确保短期趋势方向一致 |

**判定逻辑**：

```python
def is_strong_trend(klines_1d, klines_4h) -> bool:
    """
    5 条件强趋势市判定
    返回 True 表示 STRONG_TREND，False 表示 RANGING
    """
    conditions = [
        check_adx_above_35(klines_1d),           # 条件 1
        check_bb_width_above_7pct(klines_1d),    # 条件 2
        check_price_change_above_5pct(klines_1d), # 条件 3
        check_ema21_slope_above_015(klines_1d),   # 条件 4
        check_4h_kline_consistency(klines_4h),    # 条件 5
    ]
    return all(conditions)
```

### 3.3 市场状态影响

| 市场状态 | 开仓权限 | 说明 |
|----------|----------|------|
| **STRONG_TREND** | 仅 S 级信号可开仓 | A/B/C 级全部拒绝 |
| **RANGING** | 完全禁止开仓 | 不产生任何信号 |

## 四、策略行为

### 4.1 STRONG_TREND 状态下的交易规则

在强趋势市判定通过后，沿用 v6.18 的信号评分体系，但**仅接受 S 级信号**：

| 等级 | 处理方式 | 原因 |
|------|----------|------|
| S 级 | 允许开仓 | 最强信号，置信度最高 |
| A 级 | 拒绝 | 不够极端，放弃 |
| B 级 | 拒绝 | 不够极端，放弃 |
| C 级 | 拒绝 | 不够极端，放弃 |

### 4.2 RANGING 状态下的行为

```
市场状态 = RANGING
  → 跳过所有币种分析
  → 不产生任何交易信号
  → 日志记录："当前市场为震荡市，禁止开仓"
```

### 4.3 交易标的

沿用 v6.18 的交易标的：
- BTCUSDT、ETHUSDT、BNBUSDT、SOLUSDT、XRPUSDT、TRXUSDT

## 五、风控参数

### 5.1 止盈止损

| 参数 | 数值 | 说明 |
|------|------|------|
| 止损 | 1.5 × ATR(14) | 基于 1h ATR 计算 |
| TP1 | 4.0 × ATR(14) | 平仓 25% |
| TP2 | 6.0 × ATR(14) | 平仓 25% |
| 吊灯止损启动 | 2.5 × ATR | 启动后剩余仓位跟随 |
| 吊灯回撤 | 1.5 × ATR | 从最高点回撤触发 |

### 5.2 频率控制（极度收紧）

| 参数 | 数值 | 说明 |
|------|------|------|
| 每日最大交易数 | 1 笔 | 全局限制，不区分币种 |
| 冷却期 | 72 小时 | 同币种冷却，A 级及以上信号才能开仓 |
| 连续亏损暂停 | 3 笔 | 连续亏损 3 笔暂停 2 天 |
| 每日最大亏损 | 3% 总资金 | 触及则当日停止交易 |

### 5.3 仓位管理

| 参数 | 数值 |
|------|------|
| 单笔最大亏损 | ≤ 总资金的 2% |
| 总保证金占用 | ≤ 总资金的 30% |
| 同时持仓品种 | ≤ 1 个（仅允许单一持仓） |
| 杠杆 | S 级 5 倍 |

## 八、总结与展望

### 8.1 达成目标

| 目标 | 达成情况 |
|------|----------|
| 本金保护 | 成功，最大回撤仅 0.15% |
| 避免震荡市亏损 | 成功，震荡市完全禁止交易 |
| 高质量信号 | 成功，仅 S 级信号开仓 |

### 8.2 暴露问题

| 问题 | 严重程度 | 说明 |
|------|----------|------|
| 交易频率过低 | 高 | 3 个月仅 10 笔交易，月均 3.3 笔 |
| 收益率趋近于零 | 高 | +0.01% 几乎无收益，资金利用率极低 |
| 震荡市完全无产出 | 中 | 震荡市占据市场大部分时间，完全空仓浪费机会 |
| 缺乏震荡市策略 | 高 | 需要在震荡市中寻找低风险交易机会 |

### 8.3 为 v6.20 奠定基础

v6.19 证明了"本金保护"策略的可行性，但也暴露了"无交易"困境。v6.20 将在此基础上：

1. **保留 v6.19 的强趋势策略**：作为趋势市的核心策略，不降低标准
2. **新增震荡市策略模块**：在 RANGING 状态下启用独立的震荡市策略
3. **双模式切换**：根据市场状态自动切换策略模式
4. **目标**：在保持本金保护的前提下，将交易频率提升至 60-90 笔/季度，收益率转正
