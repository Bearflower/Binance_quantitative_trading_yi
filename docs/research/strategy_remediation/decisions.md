## 决策 D1：HRS EMM「24h 涨跌幅」输入口径

| 项 | 内容 |
|---|---|
| 选定口径 | **整点 K 线相邻日涨幅**：`close(t) / close(t−24h) − 1`，需要 **25 个连续已关闭 1h 收盘点**，再 **×100 得到百分比数值**（例：`20` 表示 `20%`，不是 `0.20`）。 |
| 拒绝口径 | 交易所 24hr rolling ticker 的 `priceChangePercent`（与整点 K 线窗口不同源，会引入不连续窗口）。 |
| 不可用条件 | 不足 24h、基准价 `close(t−24h)` 为零/缺失、K 线缺口、含未来未收盘 K 线 → **该模式不触发**并记录原因，不得用近似值顶替。 |
| 负责人 | 开发（B1，`python-engineer-local`）；口径确认人：用户 |
| 日期 / 版本 | 2026-10-15；基线 HEAD `94ca3ed` |
| 预期改变哪些交易 | 接通后 **新增** 以前不可达的 EMM / 半 EMM 入场（`entry_mode = emm` / `semi_emm`）。属「新增交易」，测试通过 ≠ 允许扩大实盘暴露。 |
| 验收 | 缺失涨跌幅→EMM 不触发且有原因；2 项满足→半 EMM；3 项满足→EMM；模块关闭→不触发；两方向覆盖；未来数据不改变本次决策。单位用百分比数值（20 非 0.20）。 |

## 决策 D4：市值缺失时 HRS 候选截面处理

| 项 | 内容 |
|---|---|
| 选定口径 | **要求真实、未过期市值**才使用该比率；缺失币**单列 / 跳过**依赖该阈值的新入场路径。**不伪造 0.05、不自动重分权重**。新接口返回 `value, source, as_of, available_at, is_proxy, missing_reason`。 |
| 拒绝口径 | 岂留 `OI×20` 代理混入「真实 OI/市值」截面（会让 `OI/市值` 恒为 0.05）；严禁 `0` 填充冒充缺失。 |
| 负责人 | 开发（B4，`python-engineer-local`）；口径确认人：用户 |
| 日期 / 版本 | 2026-10-15；基线 `shared/market_cap.py` blob `980f850…` |
| 预期改变哪些交易 | 修复后缺失市值币不再进入依赖该因子的入场，**候选池会变化**。先影子比较被排除币与机会变化。 |
| 验收 | 真实/缺失/代理/过期分别测试；三个不同 OI 的代理值不得在真实截面形成 0.05 样本；有效样本数、覆盖率可核对。 |

> **落地状态（2026-10-16 R4 收口补记）**：**已实现（影子，未放行执行）**。开仓侧缺真实市值（`missing`/`oi_proxy`/过期）在 `score()/score_lv_rm()` 入口**显式 veto**（`should_entry=False`，真实 `execute_*` 不发生）；动态阈值改为**逐截面**（funding / OI市值比）有效样本校验，不再以费率样本数冒充。存量退出不受阻（D5）。属影子观察阶段，未改变实盘暴露阈值；参见 [architecture §7.2](architecture_R1-R6_2026-10-16.md)。

### D11：HRS 信号统计口径（RK2，权威定义表见 architecture §6.2）

| 项 | 内容 |
|---|---|
| 触发数 | `status IN ('triggered','resolved')` |
| 超时数 | `resolution = 'timeout'`（R9 后开始落库） |
| 影子数 | `resolution = 'shadow'` **或** `signal_origin IN ('shadow_scoring','empty_pool')` |
| 真实执行数 | `resolution = 'executed'`（**不自动等于真实成交**） |
| 执行率 | `executed / (executed + conflict + timeout)`（分母不按来源剔除） |
| 未决行 | `status = 'triggered' AND resolution IS NULL` |
| **正交声明** | `conflict`（结果轴）与 `shadow`（来源轴）**非互斥、正交**，同一行可同时计入影子数与冲突数 |
| **红线** | 胜率**必须**取 `trading.trade_records.realized_pnl`（真实成交），**严禁**由 `hrs_signals` 行数推导 |
| 责任方 | 开发；口径锁定人：用户（口径已锁定，零读取方） |
