# 独立网格子账户看板接入与验收

日期：2026-11-12（北京时间）。依据“改用子账号 API 实现网格交易”对话及生产只读核验：ETHUSDT PM 子账户网格执行器与独立通知容器健康，当前执行账本 0 个网格阶段、0 笔自动网格成交，账户空仓、无挂单，执行器风控 `ALLOW`。上线前人工验收交易不属于网格成绩。

## 口径与隔离

原总览仍为**主账户**交易所收入，不混入子账户。页面另设“ETHUSDT 自动网格 · 子账户”区，展示执行器状态、净仓、未成交委托、经网格账本与 PM 成交逐笔核实的成交数与最近成交、当前阶段盈亏及执行器累计盈亏。

阶段和累计盈亏沿用已上线飞书执行报告的口径：本执行器实际成交的 `realizedPnl` 减 USDT 手续费，加 ETHUSDT 资金费与当前净仓未实现盈亏。阶段从最新 `grid_epoch` 开始，累计从首个阶段开始；初始划转和人工验收交易不计入。它们是**实时持仓快照口径**，不会被误标成日/周/月/年净收益、夏普或胜率。

## 数据流与故障行为

新增独立只读采集容器，用现有子账户 PM 凭据查询持仓、挂单、资金费；以只读挂载读取执行器 SQLite 和已部署通知容器逐笔核实的成交事实。每笔执行器成交必须和 PM 事实的订单 ID、成交 ID、方向、数量和价格一致，净仓必须能由成交重建；费用资产必须是 USDT。全部核验后才原子写入不含密钥的 JSON 快照。资金费以交易所 `tranId` 去重，持久保留已核实记录并增量更新。

看板容器只挂载快照目录的只读卷，不持有子账户 API 凭据，也不读写执行器账本。API 校验账户标识、数值和快照时效；缺文件、无效或超过 120 秒时返回明确原因，页面显示不可用而不使用旧数。新采集容器出错只会让快照变旧，不影响交易执行器或原飞书通知。

## 发布验收

CI/CD 仅构建两个固定摘要镜像：`dashboard-api` 和 `grid-dashboard-exporter`。受控脚本核对现有主账户发布 pin、Compose 变更仅为看板镜像及快照只读挂载、执行器/通知容器身份、交易所只读快照与风险策略哈希。先启动新采集容器并等快照健康，再替换看板；失败时恢复原看板并移除采集容器。

上线后验收：`/api/grid-subaccount` 为 `grid_subaccount_pm`、`ETHUSDT`、新鲜且不含密钥；当前无真实网格成交时显示空仓、0 挂单、0 成交、0 阶段及累计盈亏，并明确“尚无自动网格成交”；主账户月度收益和绩效值不因子账户接入改变；原执行器及飞书通知容器身份不变；页面实际静态资源版本更新且可加载。未来首笔真实网格成交再核对交易所成交 ID、费用、资金费、持仓及两项盈亏。

正式 CI 运行与生产数值在部署验收后补记。
