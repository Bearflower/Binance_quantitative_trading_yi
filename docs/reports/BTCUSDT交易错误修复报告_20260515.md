## 问题根源分析

### 错误1根源: USDT金额未转换为币数量

**问题所在**:
- `_calculate_position_size` 方法返回的是**USDT金额**(比如100U)
- 但币安API下单时需要的是**币的数量**(比如0.001 BTC)
- 策略直接使用USDT金额作为数量下单,导致数量为0

**代码位置**:
- [strategy.py:764-833](file:///Users/yl/vscode/Binance_quantitative_trading/strategies/btc_eth/strategy.py#L764-833) - 仓位计算返回USDT金额
- [strategy.py:1084-1089](file:///Users/yl/vscode/Binance_quantitative_trading/strategies/btc_eth/strategy.py#L1084-1089) - 直接使用USDT金额下单

**正确做法**:
```python
# 错误的做法
quantity = position_size_usdt  # 100 USDT

# 正确的做法
quantity = position_size_usdt / current_price  # 100 / 104321.5 = 0.000958 BTC
```

### 错误2根源: 未进行精度调整

**问题所在**:
- 计算出的数量和价格可能不符合币安的精度要求
- 币安要求数量必须是 `stepSize` 的整数倍
- 币安要求价格必须是 `tickSize` 的整数倍
- 策略没有获取和调整精度信息

**代码位置**:
- 没有调用 `get_symbol_info` 获取精度信息
- 没有对数量和价格进行精度截断

**正确做法**:
```python
# 获取精度信息
symbol_info = await binance.get_symbol_info('BTCUSDT')
step_size = symbol_info['stepSize']  # '0.001'
tick_size = symbol_info['tickSize']  # 0.1

# 调整数量精度（向下取整到stepSize的整数倍）
quantity = (raw_quantity // Decimal(step_size)) * Decimal(step_size)

# 调整价格精度（向下取整到tickSize的整数倍）
price = (raw_price // tick_size) * tick_size
```

```python
async def _get_symbol_precision(self, symbol: str) -> Dict:
    """
    获取交易对精度信息（带缓存）
    
    Args:
        symbol: 交易对
    
    Returns:
        精度信息字典，包含 quantityPrecision, pricePrecision, stepSize 等
    """
    if symbol not in self.symbol_precision:
        try:
            precision_info = await self.binance.get_symbol_info(symbol)
            self.symbol_precision[symbol] = precision_info
            logger.info(
                f"{symbol} 精度信息已缓存",
                quantity_precision=precision_info.get('quantityPrecision'),
                price_precision=precision_info.get('pricePrecision'),
                step_size=precision_info.get('stepSize'),
                tick_size=precision_info.get('tickSize')
            )
        except Exception as e:
            logger.error(
                f"{symbol} 获取精度信息失败",
                error=str(e)
            )
            # 使用默认精度
            self.symbol_precision[symbol] = {
                'quantityPrecision': 3,
                'pricePrecision': 2,
                'stepSize': '0.001',
                'tickSize': Decimal('0.01')
            }
    
    return self.symbol_precision[symbol]
```

### 3. 实现精度调整函数

**新增方法**: [strategy.py:952-1002](file:///Users/yl/vscode/Binance_quantitative_trading/strategies/btc_eth/strategy.py#L952-1002)

```python
def _adjust_quantity_precision(
    self,
    quantity: Decimal,
    step_size: str
) -> Decimal:
    """
    调整数量精度（向下取整到stepSize的整数倍）
    
    Args:
        quantity: 原始数量
        step_size: 步长（如 '0.001'）
    
    Returns:
        调整后的数量
    """
    if not step_size or step_size == '0':
        return quantity
    
    step = Decimal(step_size)
    # 向下取整到stepSize的整数倍
    adjusted = (quantity // step) * step
    
    return adjusted

def _adjust_price_precision(
    self,
    price: Decimal,
    tick_size: Decimal
) -> Decimal:
    """
    调整价格精度（向下取整到tickSize的整数倍）
    
    Args:
        price: 原始价格
        tick_size: 价格步长
    
    Returns:
        调整后的价格
    """
    if not tick_size or tick_size == 0:
        return price
    
    # 向下取整到tickSize的整数倍
    adjusted = (price // tick_size) * tick_size
    
    return adjusted
```

## 注意事项

### 1. BTCUSDT的最小下单金额

由于BTC价格较高(约104,000 USDT),最小下单金额5 USDT对应的最小数量约为:
```
最小数量 = 5 / 104000 = 0.000048 BTC
```

但BTCUSDT的stepSize通常是0.001 BTC,因此实际最小下单金额约为:
```
实际最小金额 = 0.001 * 104000 = 104 USDT
```

**建议**: 策略配置中的最小保证金应设置为至少200 USDT,确保有足够的资金进行交易。

### 2. 精度调整策略

采用**向下取整**策略,确保:
- 数量不会超过实际可用数量
- 价格不会超过实际市场价格
- 符合币安的精度要求

### 3. 错误处理

修复后增加了多层检查:
1. USDT金额转换为币数量
2. 精度调整
3. 最小下单金额检查
4. 精度调整后数量检查

任何一步失败都会提前返回,避免发送无效订单到币安。
