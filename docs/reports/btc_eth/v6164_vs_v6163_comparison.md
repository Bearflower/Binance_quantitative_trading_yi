# v6.16.4 vs v6.16.3 回测对比报告

## 一、版本差异

### v6.16.4 核心改进（相对于v6.16.3）

1. **提高B级评分阈值到75分**
   - v6.16.3：B级 ≥ 70分
   - v6.16.4：B级 ≥ 75分（实际上取消B级，只保留S/A/C三级）

2. **BNB特殊过滤规则**
   - 评分要求：A级≥80分（从75提高），C级≥60分（从55提高）
   - ATR%要求：≥ 0.4%（从0.3%提高）
   - ADX要求：≥ 18（从15提高）

3. **保留C级信号优化**
   - 低波动市场（ATR% < 0.5%）拒绝C级信号
   - 正常波动市场接受C级信号

## 八、下一步优化建议

### 1. 进一步提升胜率

**问题**：整体胜率41.67%，距离目标45%还有差距

- 对C级信号增加额外的动量确认条件
- 考虑在低波动市场完全禁止交易

### 2. 改善S级信号表现

**问题**：S级信号胜率仅42.86%，低于预期

**建议**：
- 加强S级信号的额外过滤条件
- 提高S级信号的ADX要求（从25提高到28）
- 增加多时间框架确认

### 3. 优化止盈止损

**问题**：止损次数过多（18次），吊灯止损表现良好（13次盈利）

**建议**：
- 考虑放宽止损距离（从1.8×ATR提高到2.0×ATR）
- 优化吊灯止损参数
- 增加移动止盈机制

### 4. 币种策略差异化

**问题**：不同币种表现差异大

**建议**：
- 为每个币种设置独立的过滤参数
- BTC：加强成交量过滤
- ETH：保持现有策略
- BNB：继续使用特殊过滤规则
- XRP：保持现有策略（表现最好）
