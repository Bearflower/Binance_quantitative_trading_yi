# 现金流调整投资收益率：数据契约与验收门槛

日期：2026-11-10（北京时间）。本页针对整改编号 7；目前只完成只读现状核查和实施契约，**未发布新的 ROI 数值**。

## 当前事实

- 看板 `/account/returns` 使用 `public.equity_snapshot` 的期初净资产和当前 PM `accountEquity` 计算净值变化率；接口明示 `cashflow_adjusted=false`、`metric_basis=unadjusted_equity_change`。`equity_snapshot` 每个北京时间日期 UPSERT 一次，没有现金流发生前后的权益锚点。
- 2026-11-10 15:12 北京时间对生产 `public`、`trading` schema 只读查询，未发现名称包含 `deposit`、`withdraw`、`transfer`、`cashflow` 或 `valuation` 的表。现有交易所收入事件用于已实现盈亏、手续费、资金费核对，不能代替入金、出金和跨账户划转的完整现金流账。
- 因此目前不能由“期末权益－期初权益”推断投资收益；新数值应保持不可用，既有净值变化率继续清楚标注其口径。

## 需建立的不可变事实

1. 固定账户边界：明确 PM 账户和被纳入的子账户/币种。每笔外部入金、出金、内部划转、资产转换分别保留交易所原始 ID、源/目标账户、资产、原币数量、方向、交易所时间和抓取水位。边界内互转净额为零；穿过边界的划转才计入外部现金流。
2. 保留逐币种估值事实：现金流发生时的交易所余额、负债和未实现盈亏，折算币种、价格源、价格时间、原值及 USDT 折算值。缺价格或同一 ID 有矛盾时拒绝发布该段收益率，不用零或最近价静默补齐。
3. 保留账户权益锚点：期初、每笔外部现金流前后、期末的 PM `accountEquity`、交易所 `updateTime`、抓取时间、账户状态及来源响应哈希。当前按日 UPSERT 的快照可用于趋势展示，不能独自证明现金流发生时的估值。
4. 抓取器只读、按交易所 ID 幂等补录；分页窗口、重叠窗口及延迟到达事件都要有完成水位。原始事件不可改写；人工纠错写追加式分类和审计记录。历史查询覆盖不足时公开标注缺口。

## 计算与发布

- 首先逐日做权益桥接：`期末权益－期初权益－外部现金流净额`，并与同边界的交易收入、费用、资金费、利息及未实现盈亏变动逐项核对。桥接差额超过事前固定容差时不发布。
- 有每笔现金流前后权益锚点时，按现金流切分子区间，计算各段 `(期末权益－本段外部现金流)/期初权益－1`，再几何连乘得到时间加权收益率。期初权益非正、子区间缺锚点或现金流分类不全时，该周期显示“未知”。若将来提供估算口径（如 Modified Dietz），必须单列名称、误差边界和覆盖率，不能冒称精确时间加权收益率。
- 看板新增独立字段与标题“现金流调整投资收益率”；保留现有“账户净值变动率”字段和 `cashflow_adjusted=false` 兼容语义。返回周期、账户边界、起止水位、现金流笔数、覆盖率、桥接差额、计算方法及 `unavailable_reasons`；缺证据时 `yield=null`、不可用标记为 true。
- 策略级 ROI 还须有策略资本占用、跨策略划转和持仓估值归属；账户 ROI 即使完成，也不自动变成策略 ROI 或资金分配依据。

## 验收顺序

1. 在生产只读采集所有相关交易所资金流水和权益锚点，核实历史最早可用日与分页终点；用至少两个含真实外部现金流的周期建立金样本。
2. 测试同 ID 重放、延迟流水、币种折算缺价、内部互转、跨边界划转、负/零期初权益、跨日时区及 API 分页缺页；任一不完整输入须返回未知。
3. 对金样本逐事件核对外部现金流净额，并使权益桥接在冻结容差内守恒；独立复算时间加权收益率与看板值一致。
4. 先影子输出，与当前净值变化率并列核对至少一个完整月；经审阅后再启用新字段。只有策略资本/归属事实也齐全，才考虑把策略 ROI 交给 AI Tuner 排名。

此项依赖交易所历史资金流水及现金流时点权益事实；生产目前没有相应事实表或采集作业。安全的下一项代码工作是只读抓取与水位审计，随后再建不可变表和影子桥接，不应先改前端公式。
