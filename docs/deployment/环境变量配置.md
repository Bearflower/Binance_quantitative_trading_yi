## 1. 环境变量概述

### 1.1 文档目的

本文档详细说明统一交易系统的环境变量配置,包括环境变量的分类、配置方法、安全管理和最佳实践,确保系统能够安全、灵活地运行在不同环境中。

### 1.2 环境变量分类

```
环境变量
├── 核心配置
│   ├── 数据库配置
│   ├── API配置
│   └── 服务配置
├── 策略配置
│   ├── 交易配置
│   ├── 评分配置
│   └── 风控配置
├── 日志配置
│   ├── 日志级别
│   ├── 日志路径
│   └── 日志格式
└── 安全配置
    ├── 密钥管理
    ├── 加密配置
    └── 访问控制
```

### 1.3 配置优先级

环境变量的优先级从高到低:

1. **系统环境变量**: 通过 `export` 设置的环境变量
2. **Docker环境变量**: docker-compose.yml 中的 `environment` 配置
3. **.env文件**: 项目根目录下的 `.env` 文件
4. **默认值**: 代码中的默认值

## 2. 核心配置

### 2.1 数据库配置

#### 2.1.1 环境变量说明

| 变量名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| `DATABASE_URL` | string | 是 | - | PostgreSQL连接字符串 |
| `DATABASE_POOL_SIZE` | int | 否 | 10 | 连接池大小 |
| `DATABASE_MAX_OVERFLOW` | int | 否 | 20 | 最大溢出连接数 |
| `DATABASE_POOL_TIMEOUT` | int | 否 | 30 | 连接池超时时间(秒) |
| `DATABASE_POOL_RECYCLE` | int | 否 | 3600 | 连接回收时间(秒) |

#### 2.1.2 配置示例

**.env文件**:

```bash
# PostgreSQL 数据库配置
DATABASE_URL=postgresql://trading_user:your_password@postgres-db:5432/trading_platform
DATABASE_POOL_SIZE=10
DATABASE_MAX_OVERFLOW=20
DATABASE_POOL_TIMEOUT=30
DATABASE_POOL_RECYCLE=3600
```

**Docker Compose配置**:

```yaml
services:
  btc-eth-strategy:
    environment:
      - DATABASE_URL=postgresql://trading_user:your_password@postgres-db:5432/trading_platform
      - DATABASE_POOL_SIZE=10
      - DATABASE_MAX_OVERFLOW=20
```

#### 2.1.3 连接字符串格式

```
postgresql://[user[:password]@][netloc][:port][/dbname][?param1=val1&param2=val2]
```

**示例**:

```bash
# 基本格式
DATABASE_URL=postgresql://trading_user:password@postgres-db:5432/trading_platform

# 带Schema参数
DATABASE_URL=postgresql://trading_user:password@postgres-db:5432/trading_platform?schema=trading

# 带SSL参数
DATABASE_URL=postgresql://trading_user:password@postgres-db:5432/trading_platform?sslmode=require

# 带连接池参数
DATABASE_URL=postgresql://trading_user:password@postgres-db:5432/trading_platform?pool_size=10&max_overflow=20
```

| `FEISHU_WEBHOOK_NEW_COIN` | string | 否 | - | 新币做空策略专属飞书Webhook URL |

**配置示例**:

```bash

NOTIFICATION_SERVICE_URL=http://notification-service:8766/api/v1
NOTIFICATION_PROJECT=trading_system
NOTIFICATION_TIMEOUT=10

# 飞书Webhook多项目分离配置（2026-05-09新增）
FEISHU_WEBHOOK_GRID=https://open.feishu.cn/open-apis/bot/v2/hook/xxxx-grid
FEISHU_WEBHOOK_BTC_ETH=https://open.feishu.cn/open-apis/bot/v2/hook/xxxx-btc
FEISHU_WEBHOOK_NEW_COIN=https://open.feishu.cn/open-apis/bot/v2/hook/xxxx-newcoin
FEISHU_WEBHOOK=https://open.feishu.cn/open-apis/bot/v2/hook/xxxx-default
```

**Webhook 路由说明**:
- NotificationClient 初始化时通过 `_load_webhook_mapping()` 方法加载所有 `FEISHU_WEBHOOK_*` 环境变量
- 调用 `send(project="grid")` 时自动路由到 `FEISHU_WEBHOOK_GRID`
- 调用 `send(project="btc_eth")` 时自动路由到 `FEISHU_WEBHOOK_BTC_ETH`
- 调用 `send(project="new_coin")` 时自动路由到 `FEISHU_WEBHOOK_NEW_COIN`
- 如果 project 未找到匹配的专属 Webhook，回退到 `FEISHU_WEBHOOK`
- 如果也未配置通用通知服务 URL，则使用 `NOTIFICATION_SERVICE_URL`

## 5. 安全配置

### 5.1 密钥管理

#### 5.1.1 环境变量加密

**使用加密工具**:

```bash
# 安装加密工具
pip install cryptography

# 加密脚本
cat > encrypt_env.py << 'EOF'
from cryptography.fernet import Fernet
import os

# 生成密钥
key = Fernet.generate_key()
cipher = Fernet(key)

# 加密环境变量
api_key = "your_api_key_here"
encrypted = cipher.encrypt(api_key.encode())
print(f"加密后的API Key: {encrypted.decode()}")

# 解密
decrypted = cipher.decrypt(encrypted)
print(f"解密后的API Key: {decrypted.decode()}")
EOF

python encrypt_env.py
```

#### 5.1.2 使用密钥管理服务

**AWS Secrets Manager示例**:

```python
import boto3
import base64
from botocore.exceptions import ClientError

def get_secret():
    secret_name = "trading/binance_api_key"
    region_name = "us-west-2"

    # 创建Secrets Manager客户端
    client = boto3.client(
        service_name='secretsmanager',
        region_name=region_name
    )

    try:
        get_secret_value_response = client.get_secret_value(
            SecretId=secret_name
        )
    except ClientError as e:
        raise e

    # 解密密钥
    if 'SecretString' in get_secret_value_response:
        secret = get_secret_value_response['SecretString']
    else:
        secret = base64.b64decode(get_secret_value_response['SecretBinary'])

    return secret
```

#### 6.2.2 配置文件加载

**Python代码加载配置**:

```python
import os
import yaml
from typing import Dict, Any

class ConfigLoader:
    """配置加载器"""

    def __init__(self, config_path: str = None):
        self.config_path = config_path or os.getenv('CONFIG_PATH', 'config.yaml')
        self.config = self._load_config()

    def _load_config(self) -> Dict[str, Any]:
        """加载配置文件"""
        with open(self.config_path, 'r', encoding='utf-8') as f:
            config = yaml.safe_load(f)

        # 用环境变量覆盖配置
        config = self._override_with_env(config)

        return config

    def _override_with_env(self, config: Dict[str, Any]) -> Dict[str, Any]:
        """用环境变量覆盖配置"""
        # 数据库配置
        if os.getenv('DATABASE_URL'):
            config.setdefault('database', {})['url'] = os.getenv('DATABASE_URL')

        # API配置
        if os.getenv('BINANCE_API_KEY'):
            config.setdefault('binance', {})['api_key'] = os.getenv('BINANCE_API_KEY')
        if os.getenv('BINANCE_SECRET_KEY'):
            config.setdefault('binance', {})['secret_key'] = os.getenv('BINANCE_SECRET_KEY')

        # 日志配置
        if os.getenv('LOG_LEVEL'):
            config.setdefault('logging', {})['level'] = os.getenv('LOG_LEVEL')

        return config

    def get(self, key: str, default: Any = None) -> Any:
        """获取配置值"""
        keys = key.split('.')
        value = self.config

        for k in keys:
            if isinstance(value, dict):
                value = value.get(k)
            else:
                return default

        return value if value is not None else default
```

## 7. 配置管理

### 7.1 配置验证

#### 7.1.1 配置验证脚本

创建 `validate_config.py`:

```python
#!/usr/bin/env python3
"""
配置验证脚本
验证所有必要的环境变量是否已配置
"""

import os
import sys
from typing import List, Tuple

# 必需的环境变量
REQUIRED_ENV_VARS = [
    'DATABASE_URL',
    'BINANCE_API_KEY',
    'BINANCE_SECRET_KEY',
    'KLINE_SERVICE_URL',
    'NOTIFICATION_SERVICE_URL',
]

# 可选的环境变量及其默认值
OPTIONAL_ENV_VARS = {
    'LOG_LEVEL': 'INFO',
    'TRADING_LEVERAGE': '20',
    'MAX_POSITIONS': '2',
}


def validate_env_vars() -> Tuple[bool, List[str]]:
    """验证环境变量"""
    errors = []

    # 检查必需的环境变量
    for var in REQUIRED_ENV_VARS:
        if not os.getenv(var):
            errors.append(f"❌ 缺少必需的环境变量: {var}")

    # 检查可选的环境变量
    for var, default in OPTIONAL_ENV_VARS.items():
        if not os.getenv(var):
            print(f"⚠️  环境变量 {var} 未设置,使用默认值: {default}")

    return len(errors) == 0, errors


def validate_database_url(url: str) -> bool:
    """验证数据库连接字符串"""
    if not url.startswith('postgresql://'):
        return False

    # 检查格式
    try:
        from urllib.parse import urlparse
        parsed = urlparse(url)
        return all([parsed.scheme, parsed.netloc, parsed.path])
    except Exception:
        return False


def main():
    """主函数"""
    print("=" * 60)
    print("配置验证开始")
    print("=" * 60)

    # 验证环境变量
    is_valid, errors = validate_env_vars()

    if errors:
        print("\n❌ 配置验证失败:")
        for error in errors:
            print(f"  {error}")
        sys.exit(1)

    # 验证数据库连接字符串
    db_url = os.getenv('DATABASE_URL')
    if db_url and not validate_database_url(db_url):
        print(f"❌ 数据库连接字符串格式错误: {db_url}")
        sys.exit(1)

    print("\n✅ 配置验证通过")
    print("=" * 60)


if __name__ == '__main__':
    main()
```

**执行验证**:


### 8.2 环境切换

#### 8.2.1 切换脚本

创建 `switch_env.sh`:

```bash
#!/bin/bash

# ============================================
# 环境切换脚本
# ============================================

ENV=$1

if [ -z "$ENV" ]; then
    echo "用法: ./switch_env.sh <environment>"
    echo "环境: development, testing, production"
    exit 1
fi

ENV_FILE=".env.${ENV}"

if [ ! -f "$ENV_FILE" ]; then
    echo "❌ 环境文件不存在: $ENV_FILE"
    exit 1
fi

echo "============================================="
echo "切换到 $ENV 环境"
echo "============================================="

# 备份当前配置
if [ -f ".env" ]; then
    cp .env ".env.backup.$(date +%Y%m%d_%H%M%S)"
fi

# 复制环境文件
cp $ENV_FILE .env

# 验证配置
python validate_config.py

if [ $? -eq 0 ]; then
    echo "✅ 环境切换成功"
    echo "当前环境: $ENV"
else
    echo "❌ 环境切换失败"
    exit 1
fi

echo "============================================="
```

**使用方法**:

```bash
# 切换到开发环境
```
