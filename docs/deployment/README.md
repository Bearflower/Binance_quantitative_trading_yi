## 常用命令速查

### 部署命令

```bash
# 一键部署
./one_click_deploy.sh

# 手动部署
./auto_package.sh              # 打包
./upload_to_server.sh          # 上传
ssh trading-prod "..."         # 部署
```

### 容器管理

```bash
# 启动服务
docker-compose up -d

# 停止服务
docker-compose down

# 重启服务
docker-compose restart

# 查看日志
docker-compose logs -f

# 进入容器
docker-compose exec btc-eth-strategy /bin/bash
```

### 监控命令

```bash
# 查看容器状态
docker-compose ps

# 查看资源使用
docker stats

# 查看健康状态
docker inspect --format='{{.State.Health.Status}}' btc-eth-strategy
```
