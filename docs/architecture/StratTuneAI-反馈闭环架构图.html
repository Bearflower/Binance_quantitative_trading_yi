StratTuneAI 反馈闭环系统架构图

EffectTracker · ContextEnhancer · LearningSignal 模块依赖与数据流

EffectTracker

  • • 读取 .active 版本文件 → 查找上上周已生效记录
  • • 复用 adapter.collect(week_offset=-1) 计算上周绩效
  • • 幂等性校验：post_* 已填充则跳过
  • • 回填 post_win_rate / post_total_pnl / effect_notes
  • • 异常降级：任何异常不阻断主流程

ContextEnhancer

  • • 接收 EffectSummary → 生成 Markdown 对比表格
  • • 展示调优前 vs 调优后指标对比
  • • 生成定性评价（良好/一般/较差/数据不足）
  • • 注入到 User Prompt 的 feedback_context 插值
  • • 与现有 ContextBuilder 合并输出

LearningSignal

  • • L1: 效果驱动的决策方向（评级→指令）
  • • L2: 避免过度优化（连续方向检测）
  • • L3: 零交易处理（<3笔不参考）
  • • L4: 连续不变触发（3次后强制调整）
  • • 注入到 System Prompt 的 learning_instructions 插值
