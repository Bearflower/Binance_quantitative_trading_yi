② 策略通用运行循环（BaseStrategy 骨架）共性

⑦ StratTuneAI 调优闭环（ai-tuner · v1.0）AI 调参

每周日 23:55 自动采集各策略周度表现，DeepSeek 生成调参建议，飞书卡片人工审批后经覆盖层生效；安全兜底自动回滚。调参建议不入库改码，只改 config 覆盖层（tuning_overrides）。
