## 1. 概述

### 1.1 文档目的

本文档详细描述了统一交易系统的数据库设计，包括数据库架构、表结构设计、索引设计、数据迁移策略等内容，为开发人员提供数据库开发的详细指导。

### 1.2 数据库选型

**PostgreSQL 14+**

**选择理由**:
- 成熟稳定，性能优越
- 支持复杂查询和事务
- 支持JSON数据类型
- 开源免费，社区活跃
- 已有现成服务，无需额外部署

### 1.3 设计原则

- **规范化**: 遵循数据库设计范式，减少数据冗余
- **性能优先**: 合理设计索引，优化查询性能
- **可扩展性**: 预留扩展字段，支持未来需求
- **数据完整性**: 使用约束保证数据完整性
- **安全性**: 敏感数据加密存储

## 3. 表结构设计

### 3.1 K线数据表 (klines)

**用途**: 存储历史K线数据，支持多交易对、多周期

```sql
CREATE TABLE trading.klines (
    id              BIGSERIAL PRIMARY KEY,
    symbol          VARCHAR(20) NOT NULL,              -- 交易对，如 'BTCUSDT'
    interval        VARCHAR(10) NOT NULL,              -- K线周期，如 '1m', '5m', '1h'
    open_time       BIGINT NOT NULL,                   -- 开盘时间戳(毫秒)
    close_time      BIGINT NOT NULL,                   -- 收盘时间戳(毫秒)
    open_price      DECIMAL(20, 8) NOT NULL,           -- 开盘价
    high_price      DECIMAL(20, 8) NOT NULL,           -- 最高价
    low_price       DECIMAL(20, 8) NOT NULL,           -- 最低价
    close_price     DECIMAL(20, 8) NOT NULL,           -- 收盘价
    volume          DECIMAL(20, 8) NOT NULL,           -- 成交量
    quote_volume    DECIMAL(20, 8) NOT NULL,           -- 成交额
    trades_count    INTEGER NOT NULL,                  -- 成交笔数
    taker_buy_volume DECIMAL(20, 8),                   -- 主动买入成交量
    taker_buy_quote_volume DECIMAL(20, 8),             -- 主动买入成交额
    created_at      TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at      TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    -- 唯一约束：同一交易对、周期、时间只能有一条记录
    CONSTRAINT uk_klines_symbol_interval_time UNIQUE (symbol, interval, open_time)
);

-- 注释
COMMENT ON TABLE trading.klines IS 'K线数据表';
COMMENT ON COLUMN trading.klines.symbol IS '交易对，如BTCUSDT';
COMMENT ON COLUMN trading.klines.interval IS 'K线周期，如1m, 5m, 1h, 1d';
COMMENT ON COLUMN trading.klines.open_time IS '开盘时间戳(毫秒)';
COMMENT ON COLUMN trading.klines.close_time IS '收盘时间戳(毫秒)';
```

**索引设计**:
```sql

-- 唯一约束索引（自动创建）

-- 查询索引：按交易对和时间范围查询
```

### 3.2 订单表 (orders)

**用途**: 存储所有订单记录，支持多策略、多交易对

```sql
CREATE TABLE trading.orders (
    id              BIGSERIAL PRIMARY KEY,
    order_id        BIGINT NOT NULL,                   -- 交易所订单ID
    client_order_id VARCHAR(50),                       -- 客户端订单ID
    strategy        VARCHAR(50) NOT NULL,              -- 策略名称
    symbol          VARCHAR(20) NOT NULL,              -- 交易对
    side            VARCHAR(10) NOT NULL,              -- 买卖方向：BUY, SELL
    order_type      VARCHAR(20) NOT NULL,              -- 订单类型：LIMIT, MARKET, STOP_LOSS等
    status          VARCHAR(20) NOT NULL,              -- 订单状态：NEW, FILLED, CANCELED等
    price           DECIMAL(20, 8),                    -- 委托价格
    quantity        DECIMAL(20, 8) NOT NULL,           -- 委托数量
    executed_qty    DECIMAL(20, 8) DEFAULT 0,          -- 已成交数量
    cumulative_qty  DECIMAL(20, 8) DEFAULT 0,          -- 累计成交数量
    avg_price       DECIMAL(20, 8),                    -- 平均成交价
    stop_price      DECIMAL(20, 8),                    -- 止损价格
    time_in_force   VARCHAR(10),                       -- 有效方式：GTC, IOC, FOK
    create_time     BIGINT NOT NULL,                   -- 创建时间戳
    update_time     BIGINT,                            -- 更新时间戳
    transact_time   BIGINT,                            -- 交易时间戳
    commission      DECIMAL(20, 8),                    -- 手续费
    commission_asset VARCHAR(20),                      -- 手续费资产
    is_working      BOOLEAN DEFAULT TRUE,              -- 是否在工作
    created_at      TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at      TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    -- 唯一约束：同一订单ID只能有一条记录
```

### 3.3 成交记录表 (trades)

**用途**: 存储所有成交记录，关联订单

```sql
CREATE TABLE trading.trades (
    id              BIGSERIAL PRIMARY KEY,
    trade_id        BIGINT NOT NULL,                   -- 交易所成交ID
    order_id        BIGINT NOT NULL,                   -- 关联订单ID
    strategy        VARCHAR(50) NOT NULL,              -- 策略名称
    symbol          VARCHAR(20) NOT NULL,              -- 交易对
    side            VARCHAR(10) NOT NULL,              -- 买卖方向
    price           DECIMAL(20, 8) NOT NULL,           -- 成交价格
    quantity        DECIMAL(20, 8) NOT NULL,           -- 成交数量
    quote_qty       DECIMAL(20, 8) NOT NULL,           -- 成交额
    commission      DECIMAL(20, 8),                    -- 手续费
    commission_asset VARCHAR(20),                      -- 手续费资产
    transact_time   BIGINT NOT NULL,                   -- 成交时间戳
    is_buyer        BOOLEAN NOT NULL,                  -- 是否买方
    is_maker        BOOLEAN NOT NULL,                  -- 是否挂单方
    created_at      TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    -- 唯一约束：同一成交ID只能有一条记录
    CONSTRAINT uk_trades_trade_id UNIQUE (trade_id),

    -- 外键约束：关联订单表
    CONSTRAINT fk_trades_order FOREIGN KEY (order_id)
        REFERENCES trading.orders(order_id)
        ON DELETE CASCADE
);

-- 注释
COMMENT ON TABLE trading.trades IS '成交记录表';
COMMENT ON COLUMN trading.trades.trade_id IS '交易所成交ID';
COMMENT ON COLUMN trading.trades.order_id IS '关联订单ID';
```

### 3.9 统一交易记录表 (trade_records) -- 新增

**用途**: 存储所有策略的统一交易成交记录，通过 TradeLogger 在 BinanceClient 层面自动记录

```sql
CREATE TABLE IF NOT EXISTS trading.trade_records (
    id              SERIAL PRIMARY KEY,
    strategy        VARCHAR(50) NOT NULL,              -- 策略名称（如 "MTPCS策略"、"网格交易策略"、"新币做空策略"）
    symbol          VARCHAR(20) NOT NULL,              -- 交易对，如 'BTCUSDT'
    order_id        VARCHAR(100),                      -- 币安订单ID
    side            VARCHAR(10) NOT NULL,              -- 买卖方向：BUY, SELL
    order_type      VARCHAR(20) NOT NULL,              -- 订单类型：MARKET, LIMIT, STOP_MARKET 等
    quantity        DECIMAL(20,8) NOT NULL DEFAULT 0,  -- 成交数量
    price           DECIMAL(20,8) NOT NULL DEFAULT 0,  -- 成交均价
    commission      DECIMAL(20,8) NOT NULL DEFAULT 0,  -- 手续费
    status          VARCHAR(20) NOT NULL DEFAULT 'NEW',-- 订单状态
    executed_at     TIMESTAMP NOT NULL DEFAULT NOW(),  -- 成交时间（北京时间，UTC+8）
    realized_pnl    DECIMAL(20,8)                       -- 已实现盈亏（USDT，平仓时回写，开仓为NULL）
);

-- 注释
COMMENT ON TABLE trading.trade_records IS '统一交易记录表（所有策略共用）';
COMMENT ON COLUMN trading.trade_records.strategy IS '策略名称';
COMMENT ON COLUMN trading.trade_records.symbol IS '交易对';
COMMENT ON COLUMN trading.trade_records.order_id IS '币安订单ID';
COMMENT ON COLUMN trading.trade_records.executed_at IS '成交时间（北京时间）';
COMMENT ON COLUMN trading.trade_records.realized_pnl IS '已实现盈亏（平仓时回写，盈利为正、亏损为负）';
```

**索引设计**:
```sql
-- 主键索引（自动创建）

-- 策略+日期联合索引（日报按策略按日期查询）
CREATE INDEX IF NOT EXISTS idx_trade_records_strategy_date 
    ON trading.trade_records(strategy, executed_at);

-- 日期索引（日报按日期跨策略汇总）
CREATE INDEX IF NOT EXISTS idx_trade_records_date 
    ON trading.trade_records(executed_at);
```

**设计原则**:
- **统一存储**: 所有策略的交易记录集中存储，取代各策略私有 trades 表
- **自动记录**: 通过 TradeLogger 在 BinanceClient 的 `place_order()` / `place_conditional_order()` 返回前自动写入
- **零侵入**: 新增策略无需任何额外代码，只要通过 BinanceClient 下单即可自动记录
- **北京时间**: `executed_at` 存储北京时间（无时区），与日报统计时区一致

### 3.10 月度资金分配表 (capital_allocation) -- 新增

**用途**: 记录每月末各策略资金分配结果，用于历史回溯和审计

```sql
CREATE TABLE IF NOT EXISTS public.capital_allocation (
    id              SERIAL PRIMARY KEY,
    month_date      DATE NOT NULL,                       -- 分配月份（如 2026-07-31）
    strategy_id     VARCHAR(50) NOT NULL,                -- 策略ID
    strategy_name   VARCHAR(100) NOT NULL,               -- 策略名称
    rank            INTEGER NOT NULL,                    -- 本月排名
    monthly_pnl     DECIMAL(20, 8) NOT NULL DEFAULT 0,   -- 本月已实现 PnL
    monthly_return  DECIMAL(10, 6) NOT NULL DEFAULT 0,   -- 本月收益率
    allocated_ratio DECIMAL(5, 4) NOT NULL,              -- 下月分配比例
    allocated_amount DECIMAL(20, 8) NOT NULL DEFAULT 0,  -- 下月分配金额（USDT）
    created_at      TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(month_date, strategy_id)                      -- 每月每策略一条记录
);

COMMENT ON TABLE public.capital_allocation IS '月度资金分配记录表';
COMMENT ON COLUMN public.capital_allocation.month_date IS '分配月份';
COMMENT ON COLUMN public.capital_allocation.strategy_id IS '策略ID';
COMMENT ON COLUMN public.capital_allocation.monthly_pnl IS '本月已实现 PnL（USDT）';
COMMENT ON COLUMN public.capital_allocation.monthly_return IS '本月收益率 = monthly_pnl / 月初分配资金';
COMMENT ON COLUMN public.capital_allocation.allocated_ratio IS '下月分配比例（占总资金百分比）';
COMMENT ON COLUMN public.capital_allocation.allocated_amount IS '下月分配金额（USDT）';

-- 索引
CREATE INDEX IF NOT EXISTS idx_capital_allocation_month
    ON public.capital_allocation(month_date);
CREATE INDEX IF NOT EXISTS idx_capital_allocation_strategy
    ON public.capital_allocation(strategy_id);
```

**设计原则**:
- **幂等性**: `UNIQUE(month_date, strategy_id)` 确保每月每策略仅一条记录
- **历史可追溯**: 所有历史分配记录保留，支持审计和趋势分析
- **运行时配置分离**: 分配结果同时写入 ai_tuner/config.yaml 供各策略实时读取，数据库仅用于历史回溯

```python
import psycopg2
from datetime import datetime

def migrate_klines(source_db, target_db, symbol, start_date, end_date):
    """迁移K线数据"""
    source_conn = psycopg2.connect(source_db)
    target_conn = psycopg2.connect(target_db)

    source_cursor = source_conn.cursor()
    target_cursor = target_conn.cursor()

    # 查询源数据
    query = """
        SELECT * FROM klines
        WHERE symbol = %s
        AND open_time >= %s
        AND open_time < %s
        ORDER BY open_time
    """

    start_timestamp = int(start_date.timestamp() * 1000)
    end_timestamp = int(end_date.timestamp() * 1000)

    source_cursor.execute(query, (symbol, start_timestamp, end_timestamp))

    # 批量插入目标表
    batch_size = 1000
    batch = []

    for row in source_cursor:
        batch.append(row)

        if len(batch) >= batch_size:
            insert_batch(target_cursor, batch)
            batch = []

    # 插入剩余数据
    if batch:
        insert_batch(target_cursor, batch)

    target_conn.commit()

    source_cursor.close()
    target_cursor.close()
    source_conn.close()
    target_conn.close()

def insert_batch(cursor, batch):
    """批量插入数据"""
    insert_query = """
        INSERT INTO trading.klines (
            symbol, interval, open_time, close_time,
            open_price, high_price, low_price, close_price,
            volume, quote_volume, trades_count,
            taker_buy_volume, taker_buy_quote_volume
        ) VALUES (%s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s)
        ON CONFLICT (symbol, interval, open_time) DO NOTHING
    """

    cursor.executemany(insert_query, batch)
```

### 7.2 连接池配置

```python
import psycopg2
from psycopg2 import pool

# 创建连接池
connection_pool = psycopg2.pool.ThreadedConnectionPool(
    minconn=5,
    maxconn=20,
    host='localhost',
    database='trading_db',
    user='postgres',
    password='password'
)

# 获取连接
def get_connection():
    return connection_pool.getconn()

# 释放连接
def release_connection(conn):
    connection_pool.putconn(conn)
```

### 7.3 批量操作优化

```python
# 批量插入K线数据
def batch_insert_klines(klines):
    conn = get_connection()
    cursor = conn.cursor()

    try:
        insert_query = """
            INSERT INTO trading.klines (
                symbol, interval, open_time, close_time,
                open_price, high_price, low_price, close_price,
                volume, quote_volume, trades_count
            ) VALUES (%s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s)
            ON CONFLICT (symbol, interval, open_time) DO UPDATE SET
                close_price = EXCLUDED.close_price,
                volume = EXCLUDED.volume,
                updated_at = CURRENT_TIMESTAMP
        """

        cursor.executemany(insert_query, klines)
        conn.commit()
    except Exception as e:
        conn.rollback()
        raise e
    finally:
        cursor.close()
        release_connection(conn)
```
