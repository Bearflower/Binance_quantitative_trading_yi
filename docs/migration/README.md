## 共享模块架构

所有策略共享以下核心模块：

```
shared/
├── __init__.py
├── kline_service.py      # K线服务
├── notification.py       # 通知服务
├── binance_api.py        # Binance API 客户端
├── database.py           # 数据库服务
├── indicators.py         # 技术指标计算
└── utils.py              # 工具函数
```

### 共享模块说明

| 模块 | 功能 | 说明 |
|------|------|------|
| `kline_service.py` | K线数据获取、缓存、技术指标计算 | 支持通用K线服务和API直连 |
| `notification.py` | 多渠道通知（飞书、Telegram） | 支持项目隔离和消息级别 |
| `binance_api.py` | Binance REST API 封装 | PM账户专用，单例模式 |
| `database.py` | PostgreSQL 数据库操作 | 连接池管理，CRUD封装 |
| `indicators.py` | 技术指标计算 | MA、RSI、MACD、ATR等 |
| `utils.py` | 通用工具函数 | 时间处理、格式转换等 |

## 风险管理

### 共同风险

| 风险 | 应对措施 |
|------|----------|
| 数据不一致 | 编写数据迁移脚本，进行数据校验 |
| 功能缺失 | 建立功能清单，逐项核对 |
| API兼容性 | 保持接口兼容，添加适配层 |
| 部署失败 | 准备详细部署文档，本地预演 |

### 回滚方案

每个策略都保留原有项目作为备份，可随时回滚：

1. 停止新系统
2. 启动原系统
3. 数据恢复
4. 验证原系统
