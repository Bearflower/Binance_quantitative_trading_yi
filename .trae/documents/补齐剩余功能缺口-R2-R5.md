## 第二轮：#38 动态仓位计算

### 需求

每笔最大亏损 = 账户总资金 × 2%，仓位 = 最大亏损 / 止损幅度

### 修改文件

**`strategies/new_coin/executor.py`**

1. **`_calculate_position_size()` (L218-243)** — 从固定保证金改为动态计算：
   ```python
   def _calculate_position_size(self, balance: Decimal, current_price: float, stop_loss_ratio: float = None) -> Decimal:
       risk_config = self.config.get('trading', {}).get('risk_control', {})
       max_loss_percent = Decimal(str(risk_config.get('max_loss_percent', 0.02)))
       
       # 如果有实际止损幅度，使用实际值；否则使用配置的止损百分比
       if stop_loss_ratio and stop_loss_ratio > 0:
           sl_ratio = Decimal(str(stop_loss_ratio))
       else:
           sl_ratio = self.stop_loss_percent
       
       # 最大亏损 = 账户余额 × 2%
       max_loss = balance * max_loss_percent
       # 开仓价值 = 最大亏损 / 止损幅度
       position_value = max_loss / sl_ratio
       # 保证金 = 开仓价值 / 杠杆
       margin = position_value / self.leverage
       
       # 安全检查：保证金不超过可用余额的50%
       max_margin = balance * Decimal('0.5')
       margin = min(margin, max_margin)
       
       quantity = (margin * self.leverage) / Decimal(str(current_price))
       return quantity
   ```

2. **`execute_short()` (L87-197)** — 传入止损幅度：
   - 在调用 `_calculate_position_size` 之前，先计算 ATR 和止损幅度
   - 将止损幅度传入 `_calculate_position_size(balance, current_price, stop_loss_ratio)`

**`strategies/new_coin/config.yaml`** — 无需修改，`risk_control.max_loss_percent: 0.02` 已存在

### 测试要点

- 账户余额 500U，止损5% → 保证金 = (500×0.02/0.05)/2 = 100U
- 止损幅度为0时兜底到固定5%
- 保证金不超过可用余额50%

### #42 最大回撤熔断

**需求**：累计亏损 ≥ 15% 暂停一周

**修改文件：**

1. **`strategies/new_coin/strategy.py`**：
   - `__init__()` — 新增 `self.cumulative_pnl = Decimal('0')`、`self.peak_equity = None`、`self.drawdown_pause_until = None`
   - `_execute_cycle()` (L405) — 周期开始前检查回撤熔断：
     ```python
     # 检查回撤熔断状态
     if self.drawdown_pause_until:
         if datetime.now(timezone.utc) < self.drawdown_pause_until:
             logger.warning(f"回撤熔断中，暂停至 {self.drawdown_pause_until}")
             return
         else:
             logger.info("回撤熔断期已结束，恢复交易")
             self.drawdown_pause_until = None
     ```
   - 新增 `_check_max_drawdown()` — 每次平仓后调用：
     ```python
     async def _check_max_drawdown(self, pnl: float):
         self.cumulative_pnl += Decimal(str(pnl))
         # 获取当前账户净值
         balance = await self.trading_executor._get_account_balance()
         current_equity = balance + self.cumulative_pnl
         if self.peak_equity is None or current_equity > self.peak_equity:
             self.peak_equity = current_equity
         if self.peak_equity > 0:
             drawdown = (self.peak_equity - current_equity) / self.peak_equity
             dd_config = self.config.get('trading', {}).get('max_drawdown', {})
             threshold = Decimal(str(dd_config.get('threshold', 0.15)))
             pause_days = dd_config.get('pause_days', 7)
             if drawdown >= threshold:
                 self.drawdown_pause_until = datetime.now(timezone.utc) + timedelta(days=pause_days)
                 logger.warning(f"触发回撤熔断: 回撤{float(drawdown):.1%} >= {float(threshold):.1%}")
                 await self.notification_client.send(...)
     ```
   - `_monitor_positions()` (L647) — 完全平仓后调用 `_check_max_drawdown(pnl)`
   - `_restore_state()` — 恢复 `cumulative_pnl`、`peak_equity`、`drawdown_pause_until`
   - `_save_state()` — 保存上述状态

### 测试要点

- 单日开仓2次后拒绝第3次
- 跨 UTC 日期自动重置计数
- 回撤超15%触发熔断
- 熔断期内跳过整个周期
- 熔断到期自动恢复
