## 第一轮：P0 紧急止损 + 最终止损MAX

### 功能点

- **#30 紧急止损**：开仓后15分钟内价格反向超1.5%立即平仓
- **#29 ATR动态止损**：止损价 = 开仓价 + 2.5×ATR(14)
- **#32 最终止损取MAX**：最终止损 = MAX(ATR止损, 紧急止损, 最小绝对止损5%)

### 实现方案

**修改文件：**

1. `strategies/new_coin/config.yaml` — 新增 `atr_stop_multiplier: 2.5` 配置项（`trading` 段）
2. `strategies/new_coin/executor.py`：
   - `execute_short()` — 开仓后记录入场时间到 `position_tracking`
   - `check_position_management()` — 新增紧急止损检查调用
   - 新增 `_check_emergency_stop(symbol)` — 检查15分钟内是否反向1.5%
   - `_set_batch_take_profit()` — 修改止损逻辑：计算三种止损价取最大值
   - `_set_stop_loss_take_profit()` — 同上，传统模式也需修改

**关键逻辑：**
```python
# 最终止损 = MAX(ATR止损, 紧急止损, 最小绝对止损)
atr_stop = entry_price * (1 + atr_stop_multiplier * atr / entry_price)  # 开仓价 + 2.5×ATR
emergency_stop = entry_price * (1 + trigger_percent)  # 开仓价 * 1.015
min_stop = entry_price * (1 + stop_loss_percent)  # 开仓价 * 1.05
final_stop = max(atr_stop, emergency_stop, min_stop)
```

### 测试要点

- 紧急止损15分钟内触发
- 15分钟后紧急止损不触发
- 三种止损取最大值
- ATR计算为0时兜底

**关键逻辑：**
```python
# 最大亏损 = 账户总资金 × 2%
max_loss = account_balance * risk_control.max_loss_percent
# 止损幅度 = 当前止损百分比（默认5%，来自上面计算的最佳止损）
stop_loss_ratio = final_stop_price / entry_price - 1
# 开仓价值 = 最大亏损 / 止损幅度
position_value = max_loss / stop_loss_ratio
# 保证金 = 开仓价值 / 杠杆
margin = position_value / leverage
```

## 第三轮：P0 单日开仓限制 + 最大回撤熔断

### 功能点

- **#40 单日开仓限制**：每日最多开仓2个币种
- **#42 最大回撤熔断**：累计亏损≥15%暂停一周

### 实现方案

**修改文件：**

1. `strategies/new_coin/config.yaml` — 新增 `daily_trade_limit: 2` 配置项
2. `strategies/new_coin/strategy.py`：
   - `__init__()` — 新增 `daily_trade_count`、`last_trade_date`、`cumulative_pnl`、`peak_equity`、`drawdown_pause_until` 变量
   - `_execute_cycle()` — 周期开始前检查回撤熔断状态
   - `execute_signal()` — 开仓前检查每日开仓限制
   - 新增 `_check_max_drawdown()` — 检查并触发回撤熔断
   - `_monitor_positions()` — 平仓后更新 `cumulative_pnl` 和 `peak_equity`
   - `_restore_state()` — 恢复新增状态变量
   - `_save_state()` — 保存新增状态变量

**关键逻辑：**
```python
# 单日开仓限制：检查 UTC 日期是否重置
today = datetime.now(timezone.utc).date()
if today != last_trade_date:
    daily_trade_count = 0
    last_trade_date = today
if daily_trade_count >= daily_trade_limit:
    return  # 跳过，不执行交易

# 最大回撤熔断：检查是否在熔断期
if drawdown_pause_until and datetime.now(timezone.utc) < drawdown_pause_until:
    return  # 熔断中，跳过整个周期
# 检查回撤
current_equity = get_account_balance() + cumulative_pnl
if current_equity > peak_equity:
    peak_equity = current_equity
drawdown = (peak_equity - current_equity) / peak_equity
if drawdown >= max_drawdown.threshold:
    drawdown_pause_until = now + timedelta(days=max_drawdown.pause_days)
```

### 测试要点

- 单日开仓2次后拒绝第3次
- 跨日期自动重置计数
- 回撤超15%触发熔断
- 熔断期内跳过所有交易
- 熔断到期自动恢复
