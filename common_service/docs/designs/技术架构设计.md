## 1. 架构概述

### 1.1 架构目标

- **高可用**: 服务可用性 ≥ 99.5%
- **高性能**: API 响应时间 < 500ms
- **易扩展**: 支持水平扩展
- **易维护**: 模块化设计，清晰边界

### 1.2 设计原则

- **单一职责**: 每个服务专注一个业务领域
- **接口隔离**: 清晰的 API 边界
- **依赖倒置**: 面向接口编程
- **配置分离**: 配置与代码独立

### 1.3 架构视图

## 3. 技术架构

### 3.1 技术栈选型

#### 3.1.1 后端框架

**FastAPI** (选择理由):
- ✅ 高性能（Starlette + Pydantic）
- ✅ 异步支持（async/await）
- ✅ 自动 API 文档（Swagger/OpenAPI）
- ✅ 类型安全（Type Hints）
- ✅ 与你现有技术栈一致

**替代方案**: Flask（性能略低，无原生异步）

#### 3.1.2 数据库

**PostgreSQL 14+** (选择理由):
- ✅ 强大的 SQL 功能
- ✅ 分区表支持（按时间/币种分区）
- ✅ JSON 字段支持（存储指标）
- ✅ 时区数据处理
- ✅ 成熟稳定，社区活跃

**替代方案**: 
- TimescaleDB（时序优化，但增加复杂度）
- MongoDB（灵活但事务支持弱）

#### 3.1.3 消息队列

**Redis 7+** (选择理由):
- ✅ 高性能（内存操作）
- ✅ List 结构适合队列
- ✅ 持久化支持（RDB/AOF）
- ✅ 发布订阅模式
- ✅ 与 FastAPI 集成良好

**替代方案**:
- RabbitMQ（功能更强但更重）
- Kafka（过度设计）

#### 3.1.4 定时任务

**APScheduler** (选择理由):
- ✅ 轻量级
- ✅ 支持 Cron 表达式
- ✅ 与 FastAPI 集成
- ✅ 支持分布式（Redis 后端）

**替代方案**: Celery（过重，适合复杂任务）

#### 3.3.2 消息队列设计

```python
# notification_service/queue/message_queue.py
import aioredis
import json
from typing import Dict, Any

class MessageQueue:
    def __init__(self, redis_url: str):
        self.redis = aioredis.from_url(redis_url)
        self.queue_name = "notification_queue"
    
    async def enqueue(self, message: Dict[str, Any]) -> bool:
        """消息入队"""
        try:
            await self.redis.lpush(self.queue_name, json.dumps(message))
            return True
        except Exception as e:
            logger.error(f"消息入队失败：{e}")
            return False
    
    async def dequeue(self, timeout: int = 5) -> Optional[Dict[str, Any]]:
        """消息出队"""
        try:
            result = await self.redis.brpop(self.queue_name, timeout=timeout)
            if result:
                return json.loads(result[1])
            return None
        except Exception as e:
            logger.error(f"消息出队失败：{e}")
            return None
    
    async def size(self) -> int:
        """队列长度"""
        return await self.redis.llen(self.queue_name)
```

#### 3.3.3 异步 Worker 设计

```python
# notification_service/workers/notification_worker.py
import asyncio
from typing import List

class NotificationWorker:
    def __init__(self, queue: MessageQueue, sender: FeishuSender):
        self.queue = queue
        self.sender = sender
        self.running = False
    
    async def start(self):
        """启动 Worker"""
        self.running = True
        while self.running:
            message = await self.queue.dequeue(timeout=5)
            if message:
                await self.process_message(message)
    
    async def process_message(self, message: Dict[str, Any]):
        """处理单条消息"""
        max_retries = 3
        for attempt in range(max_retries):
            try:
                success = await self.sender.send(message)
                if success:
                    logger.info(f"消息发送成功：{message['project']}")
                    return
            except Exception as e:
                logger.warning(f"消息发送失败 (尝试 {attempt+1}/{max_retries}): {e}")
                if attempt < max_retries - 1:
                    await asyncio.sleep((attempt + 1) * 2)  # 递增延迟
        
        logger.error(f"消息发送失败，已放弃：{message['project']}")
    
    def stop(self):
        """停止 Worker"""
        self.running = False
```

#### 4.1.1 K 线数据表

```sql
-- 主表：klines
CREATE TABLE klines (
    id BIGSERIAL PRIMARY KEY,
    symbol VARCHAR(20) NOT NULL,          -- 币种：BTCUSDT
    interval VARCHAR(10) NOT NULL,         -- 周期：15m, 1h, 4h, 1d
    open_time TIMESTAMP NOT NULL,          -- 开盘时间
    close_time TIMESTAMP NOT NULL,         -- 收盘时间
    open NUMERIC(20, 8) NOT NULL,          -- 开盘价
    high NUMERIC(20, 8) NOT NULL,          -- 最高价
    low NUMERIC(20, 8) NOT NULL,           -- 最低价
    close NUMERIC(20, 8) NOT NULL,         -- 收盘价
    volume NUMERIC(30, 8) NOT NULL,        -- 成交量
    quote_volume NUMERIC(30, 8) NOT NULL,  -- 成交额
    trades_count INTEGER NOT NULL,         -- 交易笔数
    created_at TIMESTAMP DEFAULT NOW(),    -- 入库时间
    updated_at TIMESTAMP DEFAULT NOW(),    -- 更新时间
    
    -- 唯一索引：防止重复数据
    UNIQUE(symbol, interval, open_time)
) PARTITION BY LIST (symbol, interval);

-- 创建分区表（示例）
CREATE TABLE klines_btcusdt_15m PARTITION OF klines
    FOR VALUES IN ('BTCUSDT', '15m');

CREATE TABLE klines_ethusdt_15m PARTITION OF klines
    FOR VALUES IN ('ETHUSDT', '15m');

-- 索引
CREATE INDEX idx_klines_time ON klines (open_time DESC);
CREATE INDEX idx_klines_symbol_interval ON klines (symbol, interval);
```

#### 8.1.1 结构化日志

```python
import logging
import json

# 配置 JSON 格式日志
class JSONFormatter(logging.Formatter):
    def format(self, record):
        log_data = {
            "timestamp": self.formatTime(record),
            "level": record.levelname,
            "logger": record.name,
            "message": record.getMessage(),
            "module": record.module,
            "function": record.funcName,
            "line": record.lineno
        }
        if record.exc_info:
            log_data["exception"] = self.formatException(record.exc_info)
        return json.dumps(log_data)

# 使用
handler.setFormatter(JSONFormatter())
logger.addHandler(handler)
```
