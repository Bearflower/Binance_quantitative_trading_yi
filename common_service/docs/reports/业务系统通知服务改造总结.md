## 🔧 技术改造要点

### 1. 统一接口
所有系统都使用相同的通用通知服务接口：
```python
POST http://43.156.242.184:8766/api/v1/send
Content-Type: application/json

{
    "project": "项目标识",
    "message": "消息内容",
    "type": "text",
    "level": "info|warning|error"
}
```

### 2. 通知级别
- **info**: 普通通知（日常报告、状态更新）
- **warning**: 警告通知（重要事件、需要关注）
- **error**: 错误通知（紧急事件、需要立即处理）

### 3. 兼容性处理
- 保持原有函数签名和调用方式
- 内部实现改为调用通用服务
- 旧代码无需修改或只需少量调整

### 4. 错误处理
- 所有通知模块都有完善的异常捕获
- 发送失败不影响主业务流程
- 详细的错误日志记录
