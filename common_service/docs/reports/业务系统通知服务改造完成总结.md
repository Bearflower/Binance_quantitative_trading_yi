## 🔧 技术改造详情

### 统一的 API 接口
所有系统都使用相同的通用通知服务接口：
```python
POST http://43.156.242.184:8766/api/v1/send
Content-Type: application/json

{
    "project": "项目标识",
    "message": "消息内容",
    "type": "text",
    "level": "info|warning|error"
}
```

### 通知级别分类
- **info**: 普通通知（日常报告、状态更新）
- **warning**: 警告通知（重要事件、需要关注）
- **error**: 错误通知（紧急事件、需要立即处理）

### 改造方式
1. **保持接口兼容**: 所有系统保持原有函数签名和调用方式
2. **内部实现替换**: 内部改为调用通用通知服务
3. **向后兼容**: 旧代码无需修改或只需少量调整
4. **完善错误处理**: 所有模块都有异常捕获和日志记录
