## 🚀 业务系统改造指南

### 改造步骤

1. **修改 K 线数据获取**
   ```python
   # 改造前：直接从币安 API 获取
   from binance.client import Client
   client = Client()
   klines = client.get_klines(symbol="BTCUSDT", interval="1h")
   
   # 改造后：从 K 线服务 API 获取
   import requests
   response = requests.get(
       "http://43.156.242.188:8765/api/v1/klines/latest",
       params={"symbol": "BTCUSDT", "interval": "1h", "limit": 100}
   )
   klines = response.json()["data"]
   ```

2. **修改通知发送**
   ```python
   # 改造前：直接发送飞书
   import requests
   requests.post(webhook_url, json={"msg_type": "text", "content": {"text": message}})
   
   # 改造后：调用通知服务
   import requests
   requests.post(
       "http://43.156.242.188:8766/api/v1/send",
       json={
           "project": "btc_eth",  # 根据项目配置
           "message": message,
           "type": "text",
           "level": "info"
       }
   )
   ```

3. **配置项目标识**
   ```python
   # 在业务系统配置文件中添加
   COMMON_SERVICE_URL = "http://43.156.242.188:8765"
   NOTIFICATION_SERVICE_URL = "http://43.156.242.188:8766"
   PROJECT_NAME = "btc_eth"  # 或 "new_coin", "grid", "inspection", "stock"
   ```

## 📝 注意事项

1. **安全性**
   - 数据库密码已配置为强密码
   - 建议配置防火墙规则，只开放必要端口
   - 生产环境建议启用 HTTPS

2. **性能优化**
   - K 线服务使用定时任务自动采集
   - 通知服务使用异步队列处理
   - Redis 用于消息缓存和频率限制

3. **监控告警**
   - 所有服务都有健康检查接口
   - 建议配置 Prometheus + Grafana 监控
   - 配置日志收集系统（ELK）

4. **备份策略**
   - PostgreSQL 数据定期备份
   - 配置文件版本管理
   - Docker 镜像定期更新
