# 股票筛选系统 - 通用模块使用说明

## 📦 已提取的通用模块

### 1. 通知服务模块

**原位置**: `output/feishu.py`  
**通用服务**: `common_service/notification_service`  
**改造后**: `output/feishu_v2.py` (已替换为 v2 版本)

**调用方式**:
```python
from output.feishu_v2 import StockNotifier

notifier = StockNotifier()

# 发送单个股票信号
notifier.send_stock_signal(stock_info)

# 发送每日汇总
notifier.send_daily_summary(signals)

# 发送持仓更新
notifier.send_position_update(positions)
```

**API 端点**: `http://43.156.242.184:8766/api/v1/send`  
**项目标识**: `stock`

**优势**:
- ✅ 统一管理飞书 webhook
- ✅ 支持异步发送（消息队列）
- ✅ 频率限制防止轰炸
- ✅ 统一日志记录
- ✅ 向后兼容，接口不变

### 2. 飞书推送脚本

**原脚本**: `feishu_push.py`  
**新脚本**: `feishu_push_v2.py` (已替换为 v2 版本)

**使用方式**:
