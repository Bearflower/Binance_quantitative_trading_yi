## 🎯 核心需求概览

### 形态检测需求
- **四步检测流程**: 大跌→缩量→放量→回踩
- **股票池过滤**: 剔除 ST、科创板、创业板等
- **流动性过滤**: 日均成交额≥3000 万

### 自动化需求
- **每日扫描**: T 日 15:30 自动运行
- **飞书推送**: T+1 日 08:00 推送信号
- **数据同步**: 每日收盘后同步 K 线数据

### 回测验证需求
- **回测周期**: 2019-2026 年（7 年数据）
- **回测样本**: 3,026 只股票
- **交易成本**: 扣除 0.35%（佣金 + 印花税 + 滑点）
