## 📋 V2.1 核心配置

### 形态参数

```yaml
pattern:
  drop_threshold: 0.12          # 跌幅 12%
  limit_up_threshold: 0.05      # 放量涨幅 5%
  min_volume_ratio: 1.5         # 量比 1.5 倍
  max_volume_ratio: 12.0        # 量比 12 倍
  flat_days: 0                  # 取消缩量走平
  post_surge_check_days: 5      # 启动后观察 5 天
```

### 交易参数

```yaml
trading:
  trailing_stop_ratio: 0.08     # 移动止盈 8%
  hard_stop_loss: 0.10          # 硬止损 10%
  min_avg_volume: 30000000      # 日均成交额≥3000 万
  skip_high_open_threshold: 0.05  # 高开>5% 跳过
```

## 🎯 实施方案

### 方案 A: 放宽参数
- **目标**: 增加信号数量
- **方法**: 降低形态检测阈值
- **效果**: 信号数量 +520%

### 方案 B: 取消缩量走平
- **目标**: 简化检测流程
- **方法**: 改为启动后观察 5 天
- **效果**: 提高信号质量

### 方案 A+B: 综合优化
- **目标**: 信号充足 + 收益稳定
- **方法**: 放宽参数 + 取消缩量走平
- **效果**: 年均 5.6 个信号，胜率 67.9%
