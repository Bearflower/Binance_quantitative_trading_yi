## 🔧 监控工具

### 1. 实时监控脚本（推荐）

**文件：** `sync_monitor.py`

**功能：**
- ✅ 实时查询数据库统计
- ✅ 数据完整性分析
- ✅ 进度跟踪
- ✅ 异常检测

**使用方法：**
```bash
# 手动运行一次
python3 sync_monitor.py

# 每 5 分钟运行一次
watch -n 300 python3 sync_monitor.py
```

### 2. 定时监控脚本

**文件：** `monitor_sync.sh`

**功能：**
- ✅ 每 10 分钟自动检查
- ✅ 分析最近日志
- ✅ 计算失败率
- ✅ 发送告警通知

**使用方法：**
```bash
# 启动监控（后台运行）
chmod +x monitor_sync.sh
./monitor_sync.sh &

# 查看监控日志
tail -f logs/sync_monitor.log
```

### 3. 容器健康检查

**Docker 内置健康检查：**
```bash
# 查看容器状态
docker ps -f name=stockfilter-app --format '{{.Status}}'

# 期望输出：Up X minutes (healthy)
```

### 核心指标

| 指标 | 正常范围 | 告警阈值 | 说明 |
|------|---------|---------|------|
| **同步进度** | 持续增长 | 5 分钟无进展 | 有数据的股票数量 |

## 📋 常见问题处理

### 问题 1：bigint out of range 错误

**现象：**
```
同步失败：bigint out of range
```

**原因：** 成交量或成交额超出 bigint 范围

**解决方案：**
```sql
-- 修改数据库字段类型
ALTER TABLE klines 
  ALTER COLUMN volume TYPE BIGINT,
  ALTER COLUMN amount TYPE NUMERIC(20,2);
```

**修复脚本：**
```bash
ssh root@43.156.242.184 "docker exec stockfilter-app psql -U stockfilter_user -d stockfilter -c 'ALTER TABLE klines ALTER COLUMN volume TYPE BIGINT;'"
```

### 问题 2：同步任务停止

**检查步骤：**
1. 查看容器状态：`docker ps`
2. 查看最近日志：`docker logs stockfilter-app --tail 50`
3. 检查进程：`docker exec stockfilter-app ps aux | grep python`

**重启任务：**
```bash
ssh root@43.156.242.184 "docker exec -d stockfilter-app python3 /app/sync_kline_history.py"
```

### 问题 3：数据不一致

**检查方法：**
```bash
# 查询每只股票的数据量
docker exec stockfilter-app python3 -c "
from data.database import DatabaseManager
import pandas as pd
db = DatabaseManager()
df = pd.read_sql('SELECT code, COUNT(*) as cnt FROM klines GROUP BY code ORDER BY cnt DESC', db.conn)
print(df.to_string())
db.close()
"
```

## 🔄 定时任务配置

### 方案 1：Systemd Timer（推荐）

**创建服务文件：** `/etc/systemd/system/sync-monitor.service`
```ini
[Unit]
Description=K 线数据同步监控
After=docker.service

[Service]
Type=simple
ExecStart=/root/stockfilter/monitor_sync.sh
Restart=always
User=root

[Install]
WantedBy=multi-user.target
```

**创建定时器：** `/etc/systemd/system/sync-monitor.timer`
```ini
[Unit]
Description=Run sync monitor every 10 minutes

[Timer]
OnBootSec=1min
OnUnitActiveSec=10min
Unit=sync-monitor.service

[Install]
WantedBy=timers.target
```

**启用服务：**
```bash
sudo systemctl daemon-reload
sudo systemctl enable sync-monitor.timer
sudo systemctl start sync-monitor.timer
```

### 方案 2：Crontab

```bash
# 每 10 分钟运行一次监控
*/10 * * * * /root/stockfilter/monitor_sync.sh >> /var/log/sync_monitor.log 2>&1
```
