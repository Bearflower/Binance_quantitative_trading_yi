## 📊 监控内容

### 实时监控项

1. **同步进度**
   - 有 K 线数据的股票数量
   - 数据完整性分布
   - 4 月每日数据覆盖情况

2. **任务状态**
   - 最近 5 分钟是否有成功记录
   - 最近 30 分钟失败率统计
   - 容器健康状态

3. **错误检测**
   - bigint out of range 错误
   - 数据库连接错误
   - 网络超时错误

### 告警阈值

| 指标 | 正常 | 警告 | 严重 |
|------|------|------|------|
| 失败率 | <5% | >10% | >20% |
| 进度停滞 | <5 分钟 | >10 分钟 | >30 分钟 |
| 容器状态 | healthy | running | stopped |

## 🚨 故障处理

### 失败率过高（>10%）

**可能原因：**
- 数据库字段溢出（bigint out of range）
- 网络问题导致连接超时
- 数据源 API 限流

**处理步骤：**
1. 查看详细错误日志
2. 统计错误类型分布
3. 针对性修复（如修改字段类型）

### 任务停止

**检查步骤：**
1. 查看容器是否运行：`docker ps`
2. 查看进程是否存在：`docker exec stockfilter-app ps aux | grep python`
3. 查看最近日志：`docker logs stockfilter-app --tail 100`

**重启任务：**
```bash
ssh root@43.156.242.184 "docker exec -d stockfilter-app python3 /app/sync_kline_history.py"
```
