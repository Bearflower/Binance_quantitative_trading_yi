# 启动飞书监控（快速指南）

## 🚀 一键启动监控

### 方法 1：前台运行（推荐初次使用）

```bash
cd /Users/yl/vscode/stockfilter
./monitor_sync.sh
```

**说明：**
- ✅ 每 10 分钟自动检查一次
- ✅ 异常时立即发送飞书告警
- ✅ 日志保存在 `logs/sync_monitor.log`
- ❌ 关闭窗口会停止监控

### 方法 2：后台运行（推荐）

```bash
cd /Users/yl/vscode/stockfilter
nohup ./monitor_sync.sh > /dev/null 2>&1 &
echo "监控已启动，PID: $!"
```

**说明：**
- ✅ 后台持续运行
- ✅ 关闭窗口不影响
- ✅ 可以随时查看日志

### 方法 3：Systemd 服务（最稳定）

```bash
# 1. 上传服务文件到服务器
ssh root@43.156.242.184 "mkdir -p /etc/systemd/system"
scp docs/monitoring/sync-monitor.* root@43.156.242.184:/etc/systemd/system/

# 2. 启用服务
ssh root@43.156.242.184 "systemctl daemon-reload && systemctl enable sync-monitor.timer && systemctl start sync-monitor.timer"

# 3. 查看状态
ssh root@43.156.242.184 "systemctl status sync-monitor.timer"
```

**说明：**
- ✅ 开机自启动
- ✅ 系统级守护进程
- ✅ 最稳定可靠

## 📱 飞书告警说明

### 告警类型

| 级别 | 颜色 | 触发条件 | 示例 |
|------|------|---------|------|
| 🔵 信息 | 蓝色 | 监控启动 | "监控服务已启动" |
| 🟠 警告 | 橙色 | 失败率>10% | "失败率过高：15%" |
| 🔴 错误 | 红色 | 5 分钟无进展 | "同步任务可能已停止" |
| 🟣 严重 | 紫色 | 容器停止 | "容器状态异常" |

### 告警示例

**收到飞书消息：**
```
🔔 K 线同步监控告警

告警级别：WARNING

失败率过高：15%（阈值：10%）

成功：45 只
失败：8 只

时间：2026-04-09 10:00:00
服务器：43.156.242.184
```

## 📋 配置说明

### 监控脚本配置

编辑 `monitor_sync.sh` 可以修改：

```bash
# 检查间隔（秒）
CHECK_INTERVAL=600  # 10 分钟

# 飞书 Webhook
FEISHU_WEBHOOK="https://open.feishu.cn/open-apis/bot/v2/hook/955aced6-5b07-42a6-a714-4c5f4726b003"

# 服务器配置
SERVER_HOST="43.156.242.184"
SERVER_USER="root"
```

### 告警阈值

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 检查间隔 | 10 分钟 | 多久检查一次 |
| 进度停滞阈值 | 5 分钟 | 多久无进展算异常 |
| 失败率阈值 | 10% | 超过多少失败率告警 |
