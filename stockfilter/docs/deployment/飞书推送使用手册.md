# 飞书推送系统使用手册

## 📋 系统概述

本系统实现**T 日收盘后扫描形态，T+1 日开盘前飞书推送**的自动化流程。

### 工作流程

| 时间 | 动作 | 脚本 | 说明 |
|------|------|------|------|
| **T 日 15:30** | 形态扫描 | `daily_scan.py` | 自动运行，扫描全市场 |
| **T 日 20:00** | 准备推送 | - | 信号文件已生成 |
| **T+1 日 08:00** | 飞书推送 | `feishu_push.py` | 自动发送卡片消息 |
| **T+1 日 9:15-9:25** | 手动买入 | - | 根据推送决策 |
| **买入后** | 设置条件单 | 券商 APP | 自动止盈止损 |

### 1. 安装与配置

```bash
# 1. 运行安装脚本
chmod +x setup_feishu.sh
./setup_feishu.sh

# 2. 按提示输入飞书 Webhook URL
# 3. 确认添加到 crontab
```

### 2. 获取飞书 Webhook

1. 打开飞书群聊
2. 点击右上角设置 → 机器人 → 添加机器人
3. 选择"自定义机器人"
4. 复制 Webhook 地址（格式：`https://open.feishu.cn/open-apis/bot/v2/hook/xxxx`）

### 3. 测试系统

```bash
# 测试形态扫描
python3 daily_scan.py

# 测试飞书推送
python3 feishu_push.py
```

## 🎯 实盘操作流程

### T 日（信号日）

1. **15:30** - 形态扫描自动运行
2. **15:35** - 查看扫描日志
   ```bash
   tail -f logs/daily_scan.log
   ```
3. **20:00** - 确认信号文件生成
   ```bash
   ls -la signals/
   ```

### T+1 日（买入日）

1. **08:00** - 飞书推送自动发送
2. **08:05** - 查看飞书消息
3. **9:15-9:25** - 集合竞价观察
   - 检查是否高开>5%
   - 检查是否涨停开盘
   - 若否，准备买入

4. **9:30** - 开盘买入
   - 按建议买入价（开盘价）下单
   - 若高开>5%，放弃该信号

5. **买入后** - 设置条件单
   - **止损单**: 价格 ≤ 止损价（支撑位×0.97）
   - **移动止盈**: 从最高价回撤 8% 卖出

### 持仓期间

**无需手动监控**，条件单自动执行：
- 触及止损 → 自动卖出
- 回撤 8% → 自动止盈

**每日检查**（可选）:
- 14:55 查看持仓股票
- 确认条件单是否正常

## 🔧 故障排查

### 问题 1：无信号生成

**检查**:
```bash
# 查看扫描日志
tail -f logs/daily_scan.log

# 手动运行扫描
python3 daily_scan.py
```

**可能原因**:
- 数据目录不存在
- 当日无符合形态的股票
- 配置文件错误

### 问题 2：飞书推送失败

**检查**:
```bash
# 查看推送日志
tail -f logs/feishu_push.log

# 手动测试推送
python3 feishu_push.py
```

**可能原因**:
- Webhook URL 配置错误
- 信号文件不存在
- 网络连接问题

### 问题 3：crontab 未执行

**检查**:
```bash
# 查看 crontab
crontab -l

# 查看 cron 日志（macOS）
log show --predicate 'process == "cron"' --last 1h
```

**解决**:
```bash
# 重新添加 crontab
crontab -e
# 添加任务，保存退出
```

## 💡 最佳实践

### 1. 严格执行纪律

- ✅ 高开>5% 坚决放弃
- ✅ 触及止损立即卖出
- ✅ 不主观判断，相信信号

### 2. 合理仓位管理

- 单只股票：≤20% 仓位
- 同时持仓：≤5 只
- 总仓位：根据市场情况调整

### 3. 使用条件单

**强烈建议**使用券商条件单功能：
- **止损单**: 自动执行，避免手动
- **移动止盈**: 券商 APP 一般叫"跟踪止损"或"回落卖出"

### 4. 定期复盘

- **每周**: 查看本周信号表现
- **每月**: 统计月度收益
- **每季**: 评估策略有效性

### 常见问题

**Q: 为什么今天没有信号？**
A: 可能当日确实没有符合形态的股票，这是正常的。策略月均 2-3 只信号，不是每天都有。

**Q: 高开 5% 放弃后，第二天还能买吗？**
A: 不建议。形态的最佳买入时机是回踩确认次日，错过就放弃。

**Q: 条件单怎么设置？**
A: 不同券商 APP 操作不同，一般路径：交易→条件单→止损止盈→设置价格。
