# V2.4 策略优化完成报告

## 📋 优化背景

### V2.1 存在的问题

**问题 1: 2020 年后信号稀少**
- V2.1 排除 2019 年后信号非常少
- 每月仅约 0.5 个信号，远低于目标（每月 2-3 个）
- 实盘可操作性低

**问题 2: 时间窗口过严**
- 缩量到放量仅 10 天窗口
- 很多符合形态的股票被遗漏
- 无法捕捉中长线技术底部

**问题 3: 参数过于严格**
- 跌幅要求 12%，涨幅要求 5%
- 量比要求 1.5-12 倍
- 流动性要求 3000 万

### 优化目标

1. **信号充足**: 排除 2019 年后，每月 2-3 个信号
2. **收益稳健**: 保持良好的风险调整收益
3. **实盘可行**: 确保流动性，避免无法买入

---

## 🔄 优化过程

### V2.1 → V2.2（首次放宽）

**调整参数**:
- 时间窗口：10 天 → 25 天
- 其他参数不变

**回测结果**:
- 总形态数：478 个（+120%）
- 2020-2025 年：47 个
- 月均信号：0.78 个

**结论**: ❌ 仍未达标（目标 2-3 个/月）

---

### V2.2 → V2.3（再次放宽）

**调整参数**:
- 时间窗口：25 天 → 40 天
- 跌幅：12% → 10%
- 涨幅：5% → 4%
- 量比：1.5 → 1.3
- 缩量：60% → 70%

**回测结果**:
- 总形态数：1,152 个
- 2020-2025 年：96 个
- 月均信号：1.33 个

**结论**: ❌ 接近但仍不达标

---

### V2.3 → V2.4（最终版本）

**调整参数**:
- 时间窗口：40 天 → **60 天**
- 跌幅：10% → **8%**
- 涨幅：4% → **3%**
- 量比：1.3 → **1.2**
- 缩量：70% → **80%**
- 流动性：3000 万 → **2000 万**

**回测结果**:
- 总形态数：**3,031 个**
- 2020-2025 年：**161 个**
- 月均信号：**2.24 个**✅

**结论**: ✅ **达到目标！**

## 🎯 关键发现

### 1. 时间窗口是关键参数

**发现**:
- 时间窗口从 10 天放宽到 60 天，信号数量增加 1297%
- 60 天已是最优平衡点
- 继续放宽可能引入过多噪音

**建议**: 保持 60 天时间窗口

### 2. 信号数量与质量平衡

**发现**:
- V2.4 参数最宽松，但收益质量最好
- V2.5 收紧参数后，信号质量反而下降
- 说明适度宽松的参数能捕捉更多机会

**建议**: 保持 V2.4 的激进参数

### 3. 流动性过滤效果

**发现**:
- 从 3000 万降低到 2000 万，增加信号覆盖
- 对收益质量影响不大
- 提高实盘可操作性

**建议**: 保持 2000 万流动性要求

### 4. 全方位收益分析重要性

**发现**:
- 传统对比只关注信号数量
- 全方位分析包括：收益、回撤、夏普、索提诺、卡尔玛
- V2.4 在所有维度上都优于 V2.5

**建议**: 建立全方位收益分析框架

## 📝 技术说明

### 回测器改进

**V2.4 回测器核心代码**: `backtester_v24.py`

**关键参数**:
```python
self.drop_threshold = 0.08          # 跌幅 8%
self.surge_price_ratio = 0.03       # 放量涨幅 3%
self.min_volume_ratio = 1.2         # 量比 1.2
self.max_volume_ratio = 15.0        # 量比 15

self.shrink_to_surge_days = 60      # 时间窗口 60 天
self.min_avg_volume = 20_000_000    # 流动性 2000 万
```

### 全方位收益分析方法

**计算框架**: `comprehensive_analysis_v24_v25.py`

**核心指标**:
1. **累计收益曲线**: 模拟投资组合每日价值
2. **回撤分析**: 计算最大回撤和平均回撤
3. **夏普比率**: 年化收益 / 收益波动率
4. **索提诺比率**: 年化收益 / 下行波动率
5. **卡尔玛比率**: 年化收益 / 最大回撤
6. **胜率**: 盈利交易数 / 总交易数
7. **盈亏比**: 平均盈利 / 平均亏损

### 信号质量评分

**质量评分系统**（满分 80 分）:
1. 跌幅评分（8-20 分）：跌幅越大得分越高
2. 时间评分（10-40 分）：缩量到放量时间适中得分高
3. 回踩速度评分（10-20 分）：回踩确认越快得分越高
