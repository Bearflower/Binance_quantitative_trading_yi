# 股票形态筛选系统技术架构文档 V2.1

## 1. 系统概述

### 1.1 系统定位
基于"大跌企稳、缩量见底、放量启动、回踩确认"形态的自动化股票筛选系统，通过技术形态识别 + 量化回测 + 自动化推送，为投资者提供交易决策支持。

### 1.2 核心功能
- ✅ **自动化扫描**: 每日收盘后自动扫描全市场股票
- ✅ **形态检测**: 四步检测流程（大跌→缩量→放量→回踩）
- ✅ **股票池过滤**: 自动剔除 ST、北交所、退市、科创板、创业板
- ✅ **流动性过滤**: 日均成交额≥3000 万（20 日统计）
- ✅ **高开过滤**: 涨停/高开>5% 跳过，避免追高
- ✅ **飞书推送**: T+1 日 08:00 自动推送到飞书
- ✅ **回测验证**: 完整历史回测（2019-2026）

### 1.3 技术栈
- **开发语言**: Python 3.9+
- **数据存储**: PostgreSQL + CSV 文件
- **数据源**: AKShare（K 线）、AData/Baostock（股票列表）
- **部署方式**: Docker 容器化部署
- **通知系统**: 飞书机器人 Webhook
- **定时任务**: systemd timer / crontab

## 3. 核心模块设计

### 3.1 形态检测模块（PatternDetector）

**位置**: [`strategy/pattern_detector.py`](file:///Users/yl/vscode/stockfilter/strategy/pattern_detector.py)

**职责**: 实现"大跌→缩量→放量→回踩"四步检测流程

**核心方法**:
```python
class PatternDetector:
    def check_pattern(self, df: pd.DataFrame) -> Tuple[bool, Dict]:
        """形态检测主流程"""
        # 步骤 1: 大跌后支撑检测
        result, detail = self._check_drop_support(df, p)
        
        # 步骤 2: 缩量见底检测
        result, shrink_detail = self._check_volume_shrink(df, p)
        
        # 步骤 3: 放量大涨检测
        result, surge_detail = self._check_surge(df, p)
        
        # 步骤 4: 回踩确认检测
        result, retrace_detail = self._check_retrace(df, p, detail)
```

**检测流程**:
1. **大跌后支撑**: 20-30 交易日内累计跌幅 > 12%
2. **缩量见底**: 成交量低于过去 20 日均量的 50%-60%
3. **放量大涨**: 涨幅≥5%，量比 1.5-12 倍
4. **回踩确认**: 从放量阳线收盘价回落不超过实体一半，缩量

**V2.1 优化**:
- 取消缩量走平要求，改为启动后观察 5 天
- 启动后 5 天内最低价格不低于启动价的 97%

### 3.2 回测引擎（BacktesterWithRules_AB）

**位置**: [`backtester_scheme_ab.py`](file:///Users/yl/vscode/stockfilter/backtester_scheme_ab.py)

**职责**: 策略回测、信号生成、收益计算

**核心功能**:
```python
class BacktesterWithRules_AB:
    def check_liquidity(self, df, retrace_idx):
        """流动性过滤（V2.1 新增）"""
        
    def check_pattern_single(self, df, stock_code, stock_name):
        """单只股票形态检测"""
        
    def check_all_patterns(self, df, stock_code, stock_name):
        """检测所有形态（修复遗漏问题）"""
```

**V2.1 重要修复**:
- **问题**: 实盘代码只检测每只股票的第一个形态，遗漏后续相同形态
- **修复**: 使用 `check_all_patterns()` 代替 `check_pattern_single()`
- **效果**: 同一只股票在不同时间出现形态，每次都会发出通知

```python
def filter_stock_list(df: pd.DataFrame) -> pd.DataFrame:
    # 剔除 ST 股票
    df = df[~df['name'].str.contains('ST')]
    
    # 剔除北交所股票（代码 8 开头）
    df = df[~df['code'].str.startswith('8')]
    
    # 剔除退市股票
    df = df[~df['name'].str.contains('退')]
    
    # 剔除科创板股票（代码 688 开头）
    df = df[~df['code'].str.startswith('688')]
    
    # 剔除创业板股票（代码 300/301 开头）
    df = df[~df['code'].str.startswith(('300', '301'))]
```

**过滤效果**:
- 原始股票：约 5,505 只
- 过滤后股票：约 3,026 只（深市主板 1,375 只 + 沪市主板 1,651 只）

**执行流程**:
```python
def scan_daily_signals(config: dict):
    # 1. 从数据库获取过滤后的股票列表
    stock_list_df = db.get_stock_list()
    
    # 2. 遍历股票列表
    for stock in stock_list_df:
        # 3. 从数据库获取 K 线数据
        kline_df = db.get_kline_history(code, days=120)
        
        # 4. 检测所有形态（不只第一个）
        all_patterns = backtester.check_all_patterns(kline_df)
        
        # 5. 检查回踩确认日是否是今天或昨天
        for pattern in all_patterns:
            if pattern['retrace_date'] in [today, yesterday]:
                signals.append(pattern)
                break  # 每只股票当天只发一个信号
    
    # 6. 保存信号到 JSON 文件
    save_to_json(signals, f'signals/signals_{today}.json')
```

**运行时间**: 每个交易日 15:30

## 4. 数据流程

### 4.1 实时扫描流程（T 日）

```
15:30 收盘后:
  ↓
1. daily_scan.py 启动
  ↓
2. 从 PostgreSQL 读取过滤后的股票列表（3,026 只）
  ↓
3. 遍历每只股票:
   3.1 从数据库获取最近 120 天 K 线
   3.2 PatternDetector 执行四步形态检测
   3.3 Backtester 检查流动性、高开过滤
   3.4 如果符合形态，记录信号
  ↓
4. 保存信号到 signals/signals_YYYY-MM-DD.json
  ↓
5. 日志记录到 logs/daily_scan.log
```

### 4.2 飞书推送流程（T+1 日）

```
08:00 开盘前:
  ↓
1. feishu_push.py 启动
  ↓
2. 读取昨日信号文件 signals/signals_YYYY-MM-DD.json
  ↓
3. 格式化飞书卡片消息
  ↓
4. 发送到飞书 Webhook
  ↓
5. 用户收到推送，准备交易
```

### 4.3 数据同步流程

```
每日定时:
  ↓
1. sync_kline_daily.py 启动
  ↓
2. 从 PostgreSQL 读取股票列表
  ↓
3. 调用 AKShare API 获取最新 K 线数据
  ↓
4. 更新到 PostgreSQL klines 表
  ↓
5. 导出 CSV 到 data/backtest/baostocks_full/
  ↓
6. sync_monitor.py 监控同步进度
```

## 8. 性能优化

### 8.1 数据库优化

**索引设计**:
```sql
-- K 线表索引

CREATE INDEX idx_klines_date ON klines(date);
CREATE INDEX idx_klines_code_date ON klines(code, date);

```

**查询优化**:
- 使用连接池管理数据库连接
- 批量插入 K 线数据（每次 1000 条）
- 使用分页查询避免内存溢出

### 8.2 扫描优化

**并行处理**:
```python
from concurrent.futures import ProcessPoolExecutor

def scan_parallel(stock_list):
    with ProcessPoolExecutor(max_workers=4) as executor:
        results = executor.map(check_single_stock, stock_list)
    return results
```

**缓存策略**:
- 股票列表缓存到内存
- K 线数据缓存最近 N 天
- 避免重复查询数据库

### 8.3 存储优化

**CSV 压缩**:
- 使用 gzip 压缩 CSV 文件
- 压缩率：约 70%
- 读取时自动解压

**数据分区**:
- 按股票代码分区存储
- 按年份归档历史数据
- 定期清理无用数据
