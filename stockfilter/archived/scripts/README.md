# 历史脚本归档

本目录存放历史版本的脚本文件,仅供参考。

## 文件分类

### 回测脚本
- `backtest_v21*.py`: V2.1版本回测脚本
- `backtest_v22*.py`: V2.2版本回测脚本
- `backtest_v23.py`: V2.3版本回测脚本
- `backtest_v24_full.py`: V2.4版本全量回测脚本
- `backtest_v25_full.py`: V2.5版本全量回测脚本

### 对比脚本
- `compare_v21_v22.py`: V2.1 vs V2.2对比
- `compare_v24_v25*.py`: V2.4 vs V2.5对比

### 分析脚本
- `analyze_*.py`: 各种分析脚本
- `check_*.py`: 各种检查脚本

## 注意事项

1. 这些脚本已不再使用,仅供参考
2. 新功能开发请使用 `scripts/` 目录下的脚本
