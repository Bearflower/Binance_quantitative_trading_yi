# 历史回测器归档

本目录存放历史版本的回测器代码,仅供参考。

## 文件说明

- `backtester_v22.py`: V2.2版本回测器
- `backtester_v23.py`: V2.3版本回测器
- `backtester_v24_reference.py`: V2.4版本回测器(参考)
- `backtester_v25.py`: V2.5版本回测器
- `backtester_v25_relaxed.py`: V2.5放宽版回测器
- `backtester_scheme_ab.py`: 方案AB回测器
- `backtester_with_rules.py`: 带规则的回测器

## 注意事项

1. 这些文件已不再使用,仅供参考
2. 如需查看历史版本逻辑,请参考这些文件
3. 新功能开发请使用 `core/backtester.py`
