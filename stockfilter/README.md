# 股票形态筛选系统 V2.1

基于"大跌企稳、缩量见底、放量启动、回踩确认"形态的自动化股票筛选系统。

**最新版本**: V2.1（最终版）  
**回测数据**: 2019-2026 年（7 年历史数据）  
**核心文档**: [查看完整文档索引](docs/README.md)

## 🎯 V2.1 核心成果

### 回测表现（2020-2025 年，重点关注）
- **检测股票**: 3,317 只
- **总信号数**: 28 个
- **年均信号**: **5.6 只/年**（约**每月 0.5 只**）
- **平均收益**: **3.28%**（已扣除 0.35% 交易成本）
- **胜率**: **67.9%** (19 个盈利 / 28 个)
- **最高收益**: 20.24%

### V2.1 核心优化
- ✅ **方案 A+B**: 放宽参数 + 取消缩量走平（信号数量 +520%）
- ✅ **流动性过滤**: 日均成交额≥3000 万（20 日统计）
- ✅ **股票池过滤**: 自动剔除科创板/创业板
- ✅ **高开过滤**: 涨停/高开>5% 跳过，避免追高
- ✅ **全形态检测**: 修复遗漏问题，检测所有形态

## 🚀 快速开始

### 1. 环境准备

```bash
# 创建虚拟环境
python -m venv venv
source venv/bin/activate  # Mac/Linux

# 安装依赖
pip install -r requirements.txt
```

### 2. 配置数据库和飞书

```bash
# 配置环境变量
cp .env.example .env
# 编辑 .env 填入数据库配置和飞书 Webhook
```

### 3. 运行扫描

```bash
# 执行形态扫描（读取数据库数据）
python3 daily_scan.py

# 发送飞书推送
python3 feishu_push.py
```

## 💡 核心功能

### 形态检测（四步流程）
1. **大跌后支撑**: 20-30 交易日内累计跌幅 > 12%
2. **缩量见底**: 成交量低于过去 20 日均量的 50%-60%
3. **放量大涨**: 涨幅≥5%，量比 1.5-12 倍
4. **回踩确认**: 从放量阳线收盘价回落不超过实体一半，启动后 5 天不破支撑

### 自动化流程
- **T 日 15:30**: 自动扫描全市场股票
- **T+1 日 08:00**: 飞书推送买入信号
- **T+1 日 09:30**: 观察集合竞价，择机买入
- **买入后**: 设置条件单（止损 + 移动止盈）

### 股票池过滤
- ✅ 剔除 ST、北交所、退市股票
- ✅ 剔除科创板（688 开头）
- ✅ 剔除创业板（300/301 开头）
- ✅ 流动性过滤：日均成交额≥3000 万
- **过滤后**: 约 3,026 只（深市主板 1,375 只 + 沪市主板 1,651 只）

## 🔧 技术栈

- **开发语言**: Python 3.9+
- **数据存储**: PostgreSQL + CSV 文件
- **数据源**: AKShare（K 线）、AData/Baostock（股票列表）
- **部署方式**: Docker 容器化部署
- **通知系统**: 飞书机器人 Webhook
- **定时任务**: systemd timer / crontab

## ⚠️ 风险提示

1. **历史回测不代表未来表现**: 回测结果仅供参考，不构成投资建议
2. **市场风险**: 极端行情下策略可能失效
3. **流动性风险**: 虽然已过滤低成交额股票，但仍需注意市场流动性变化
4. **技术风险**: 系统故障、数据错误等可能导致信号遗漏或错误

**建议**:
- 先用模拟盘验证 3 个月
- 严格执行止损纪律
- 控制单笔仓位（建议不超过总资金的 10%）
- 使用券商条件单自动执行止盈止损
