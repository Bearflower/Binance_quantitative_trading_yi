# 上下文交接存档（入口）

**完整技能文档（必读）**：`skills/context-handoff/SKILL.md`

触发本技能时，先完整阅读上述文档，再按其中结构执行。

## 关键要点速查

- **存放目录**：`docs/handoffs/`（已 gitignore，不入 git、不被部署范围分析误判）
- **命名**：`<任务名>_<YYYY-MM-DD>.md`；当天文件存在 → 增量追加，不存在 → 新建
- **结构**：终极目标 / 已完成事项（固化）/ 进行中未完成（必写卡点）/ 最新代码快照 / 关键路径 / 给新对话的启动指令
- **触发时机**：用户手动要求、上下文偏高（约 70%）、或每完成一次重构/需求落地/部署验证等关键里程碑

## 边界

- 只记录**当前任务**的任务级状态，不写全局/话题级长期记忆（Claude 的用户级/项目级长期事实写入其记忆体系，二者分工不同）
