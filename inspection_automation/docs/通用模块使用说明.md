## 📦 已提取的通用模块

### 1. 通知服务模块

**原脚本**: `server_check.sh` (直接调用飞书 webhook)  
**通用服务**: `common_service/notification_service`  
**改造后**: `server_check_v2.sh` (已替换为 v2 版本)

**调用方式**:
```bash
#!/bin/bash

# 在 server_check_v2.sh 中
NOTIFICATION_SERVICE_URL="http://43.156.242.184:8766/api/v1"
NOTIFICATION_PROJECT="inspection"

send_notification() {
    local message="$1"
    local level="${2:-info}"
    
    python3 << PYEOF
import requests

url = "${NOTIFICATION_SERVICE_URL}/send"
data = {
    "project": "${NOTIFICATION_PROJECT}",
    "message": """${message}""",
    "type": "text",
    "level": "${level}"
}

response = requests.post(url, json=data, timeout=10)
print(f"通知服务响应：{response.text}")
PYEOF
}

# 使用示例
send_notification "服务器巡检完成" "info"
```

**API 端点**: `http://43.156.242.184:8766/api/v1/send`  
**项目标识**: `inspection`

**优势**:
- ✅ 统一管理飞书 webhook
- ✅ 支持异步发送（消息队列）
- ✅ 频率限制防止轰炸
- ✅ 统一日志记录
- ✅ Shell 脚本也能使用
