# 自适应趋势网格策略 - 产品需求文档

## 项目概述
基于趋势识别的自适应网格交易策略，用于币安永续合约市场。

## 核心目标
- 在震荡行情中通过传统网格获利
- 在趋势行情中通过自适应参数减少回撤
- 实现全自动的风险管理和状态切换

## 功能需求

### 1. 市场状态识别
- **指标计算**: ADX(14), EMA(20), EMA(50), ATR(14)
- **状态分类**:
  - 震荡：ADX < 20
  - 弱趋势/过渡区：20 ≤ ADX < 25（维持前一状态）
  - 上升趋势：ADX ≥ 25 且 快 EMA > 慢 EMA
  - 下降趋势：ADX ≥ 25 且 快 EMA < 慢 EMA
- **多时间框架确认**: 4H 和 1H 趋势一致才行动
- **确认机制**: ADX 连续 3 个巡检周期上升且>23

### 2. 网格参数自适应
- **基础区间**: 价格 ± (2 × ATR)
- **趋势偏移**:
  - 上升趋势：下边界 = 价格 - 1.5×ATR, 上边界 = 价格 + 4×ATR
  - 下降趋势：下边界 = 价格 - 4×ATR, 上边界 = 价格 + 1.5×ATR
- **网格数量**: 基准网格数 × (基准 ATR / 当前 ATR)，限制在 [20, 50]
- **网格方向**:
  - 震荡：双向（多空）
  - 上升趋势：只做多
  - 下降趋势：只做空
- **非对称分配**: 根据趋势强度系数 k 调整多空网格比例
- **可调整参数**（6 个，通过币安 API 直接修改，无需终止网格）:
  - 网格价格范围（上边界/下边界）
  - 网格数量
  - 停止上移价格
  - 停止下移价格
  - 网格终止最低价格（硬止损线）
  - 网格终止最高价格（硬止盈线）
- **调整触发条件**:
  - 平滑 ATR 变化超过 ±20%（相对于上次调整时的值）
  - 市场状态发生变化（震荡↔趋势）
  - 价格已运行到当前网格边缘附近（距上/下边界 < 0.5×ATR）
  - 价格连续突破网格层数≥3 层（5 分钟内）
  - ADX > 25（确认趋势）
  - 盈利状态变化（用于终止价格调整）

### 3. 风险管理
- **硬止损**: 总亏损 ≥ 初始保证金 × 8%
- **移动止盈**: 
  - 启动阈值：总盈利 ≥ 初始保证金 × 15%
  - 回撤保护：价格从 peak_price 回撤 50% 时触发
  - 记录机制：启动移动止盈后记录最高价 peak_price
- **动态仓位**: 名义本金 / (ATR × 系数)
- **紧急暂停**: 5 分钟内价格突破 3 层网格
- **滑点保护**: 限价单 (3s) → 对手方最优价 (2s) → 市价单

### 4. 执行监控
- **巡检间隔**: 每小时一次（固定间隔，避开整点高峰）
- **参数调整**: 
  - 可直接修改的参数：6 个可调整参数通过币安 API 直接更新
  - 状态改变或 ATR 变化超过±20% 时触发调整
- **订单管理**: 本地订单薄镜像，WebSocket 实时同步
- **数据维护**: K 线数据获取，指标计算

### 5. 监控报警
- **报警渠道**: 钉钉/Telegram 机器人
- **报警内容**: 状态变更、风险事件、异常情况、参数调整
- **日志记录**: 详细的操作日志和性能指标

## 非功能需求

### 性能需求
- 24 小时不间断运行
- 巡检响应时间 < 10 秒
- WebSocket 延迟容忍度 < 2 秒
- 断线后自动重连

### 可靠性需求
- API 调用失败重试机制
- 状态持久化存储
- 进程异常重启
- 数据一致性校验

### 安全性需求
- API 密钥加密存储
- 最小权限原则
- 敏感信息脱敏日志
- 操作审计追踪

### 可维护性需求
- 模块化设计，清晰接口
- 详细日志和监控
- 配置文件驱动
- 完善的文档

## 用户界面需求
- 命令行界面（CLI）
- 配置文件（YAML 格式）
- 日志文件输出
- 监控报警接口

## 部署需求
- 支持 Linux 服务器部署
- 依赖 Python 3.8+ 环境
- 数据库使用 SQLite
- 支持后台进程运行

## 约束条件
- 必须使用币安官方 API
- 仅支持永续合约
- 需要稳定的网络连接
- 遵守 API 调用频率限制
