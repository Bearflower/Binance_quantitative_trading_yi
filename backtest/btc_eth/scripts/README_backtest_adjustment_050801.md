# 调整方案050801回测脚本使用说明

## 脚本位置
`/Users/yl/vscode/Binance_quantitative_trading/backtest/btc_eth/scripts/backtest_adjustment_050801.py`

## 功能概述

该脚本实现了基于调整方案050801的完整回测功能，包含以下核心特性：

### 1. 止盈止损参数
- **止损**：2.0×ATR
- **TP1**：3.5×ATR（平仓25%）
- **TP2**：5.5×ATR（平仓25%）
- **吊灯启动**：3.0×ATR
- **吊灯回撤**：2.0×ATR
- **时间止损**：72小时未达TP1平仓50%

### 2. 前置过滤器
- **ADX趋势强度**：≥ 15
- **成交量放大**：≥ 1.2倍平均成交量
- **ATR%范围**：1.5%-6.0%
- **趋势确认**：4小时EMA21与日线EMA21方向一致
- **RSI过滤**：多头时RSI>40，空头时RSI<60

### 3. 评分系统
- **趋势强度**：30分（满分）
- **形态质量**：45分（满分）
- **动量背离**：25分（满分）
- **等级阈值**：
  - S级：≥80分
  - A级：≥70分
  - B级：≥60分
  - C级：≥50分

### 4. 市场状态识别
- 当过去5根4小时K线的ATR低于过去20根ATR均值的80%时，判定为震荡市，禁止开仓

## 核心类和方法

### Position类
持仓信息管理类，包含：
- 入场信息（时间、价格、方向）
- 止盈止损价格
- 持仓状态跟踪

### BacktestEngine类
回测引擎主类，核心方法：

#### `run_backtest()`
运行完整回测流程

#### `_check_and_open_position()`
检查开仓条件，包括：
1. ADX过滤
2. 成交量过滤
3. ATR%范围过滤
4. 市场状态识别
5. 评分计算
6. 趋势方向一致性过滤
7. RSI过滤

#### `_check_and_close_position()`
检查平仓条件，包括：
1. 止损检查
2. TP1/TP2触发检查
3. 吊灯止损检查
4. 时间止损检查

#### `_calculate_score()`
计算信号评分，包含三个维度：
- 趋势强度（30分）
- 形态质量（45分）
- 动量背离（25分）

## 评分逻辑详解

### 趋势强度（30分）
1. **MA21与MA55关系**（10分）
   - MA21 > MA55：多头趋势
   - MA21 < MA55：空头趋势

2. **ADX强度**（10分）
   - ADX ≥ 25：10分
   - ADX ≥ 20：7分
   - ADX ≥ 15：5分

3. **多时间框架趋势一致性**（10分）
   - 4小时和日线趋势方向一致

### 形态质量（45分）
1. **MACD形态**（15分）
   - MACD > Signal且柱状图>0：多头形态
   - MACD < Signal且柱状图<0：空头形态

2. **布林带位置**（15分）
   - 根据MACD柱状图判断动能

3. **成交量确认**（15分）
   - 成交量 ≥ 1.5倍：15分
   - 成交量 ≥ 1.2倍：10分
   - 成交量 ≥ 1.0倍：5分

### 动量背离（25分）
1. **RSI位置**（15分）
   - 40 < RSI < 60：中性区域，适合交易
   - 30 < RSI ≤ 40 或 60 ≤ RSI < 70：次优
   - RSI ≤ 30 或 RSI ≥ 70：极端区域

2. **MACD柱状图动能**（10分）
   - 柱状图增长：动能增强
   - 柱状图减少：动能减弱

5. **按平仓原因统计**：不同平仓原因的表现
